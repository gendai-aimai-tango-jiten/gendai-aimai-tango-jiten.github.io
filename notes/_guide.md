# 言葉を書くときの決めごと（公開しない作業メモ）

定期タスクも Claude Code も、言葉を足す前にこのファイルを全部読み、そのとおりに書く。黒田さんが直したことは、いちばん下の「黒田さんの直しから学んだこと」に1行ずつ足す。

## 選ぶ言葉
- 対象：最近の若者言葉・ネット流行語／流行の心理・ビジネス語／昔からある誤用されやすい語。「流行っている、または広く使われているのに、意味が人によってずれる」ことが条件。
- 選ばない：差別語、性的な語、特定の人や集団をおとしめるための語。からかう程度の語（ドパガキ、陰キャなど）は、注意点を書いて載せてよい。
- 出典が2つ以上見つからない語は載せない。見つからなければ notes/queue.md の「見送り」に理由と一緒に移す（例：優勝、情緒、上振れ、秒で）。
- すでにある語（data/words/ のファイル名と word）と重ならないこと。

## 調べ方
- WebSearch で、語源・初出・広まった経緯・調査の数字（文化庁「国語に関する世論調査」、三省堂「今年の新語」、新語・流行語大賞、JC・JK流行語大賞など）を確かめる。
- 数字や年は、検索で確かめられたものだけ書く。確かめられないものは「〜とされる」「〜と報じられている」と書くか、書かない。
- 出典はURLが開ける記事を選ぶ。個人ブログやまとめサイトは避ける。
- 出典には、確かな情報源を1つ以上入れる（2026-11-08 黒田さんの方針）。辞書（コトバンク、ジャパンナレッジ、goo辞書、imidas など）、文化庁などの公的機関、大学・学会、論文のデータベース（J-STAGE、CiNii、機関リポジトリ）。どのサイトが当てはまるかは config/trusted_sources.json。解説記事（Oggi、Precious、DIME、マイナビニュースなど）だけで出典をそろえない。

## ファイルの形
- data/words/<slug>.json。slug は英小文字のローマ字（例：kaerukagensho）。既存のファイルをお手本にする。
- 項目：slug, word, reading, pos, emoji, catch, oneliner, tldr（3つ）, tags, origin_date, peak, added, updated, meters, definition, usages, etymology, timeline, misuses, perspectives, who_where, related, sources。
- meters は 曖昧度・誤用度・通用度 の3つ（1〜5）。トゲ度は使わない。
- メーターの目盛り（2026-11-08 に決めて、全語の曖昧度を付け直した）。迷ったら、例の語のページと比べてそろえる。
  - 曖昧度（人によってその言葉の意味がどれだけ変わるか）
    - 5：3つ以上の意味が広く使われ、文脈がないとどれか分からない。または、正反対の意味がほぼ半々で使われている（例：ヤバい、エモい、多様性、役不足、気が置けない）
    - 4：2〜3の意味が広く使われ、取り違えが起きやすい。または、反対の意味で受け取る人が3割以上いる（例：メロい、界隈、失笑、潮時）
    - 3：中心の意味は共有されているが、広がった使い方やニュアンスに差がある（例：映え、炎上、推し、爆笑）
    - 2：意味はほぼ1つで、ずれは言い方の形や細部にとどまる（例：的を射る、汚名返上、それな、推し活）
    - 1：意味が1つに定まっていて、ずれはほとんどない（この辞典ではまず使わない）
  - 誤用度（本来の意味とずれた使われ方が多いか）
    - 5：本来と違う意味で使う人が多数派（文化庁の調査などで過半数）（例：破天荒、確信犯、姑息、役不足）
    - 4：本来と違う意味がかなり広まっている（3〜5割ほど）。または辞書が新しい意味を載せ始めた（例：おもむろに、煮詰まる、一姫二太郎）
    - 3：本来とずれた使い方が目立つが少数派（例：自己肯定感、心理的安全性、コスパ）
    - 2：一部にずれた使い方がある（例：メロい、界隈、チル）
    - 1：ずれた使い方はほとんどない。新しい言葉で「本来」がまだ固まっていないものも含む（例：推し、それな、横転）
  - 通用度（他の世代や別の界隈にも通じるか）
    - 5：世代や界隈を問わず、ほぼ誰にでも通じる（例：ヤバい、炎上、役不足）
    - 4：多くの人に通じるが、一部の世代では知らない、または意味が違う（例：エモい、推し、チル）
    - 3：若い世代やSNSをよく使う人、特定の業界では通じるが、それ以外では説明が要る（例：メロい、インプレ、リスキリング）
    - 2：特定の界隈・業界の言葉で、外では通じにくい（例：同担拒否、横転、パーパス）
    - 1：ごく狭い界隈でしか通じない
  - 3にばかり寄せない。迷ったときは、例の語より上か下かで決める。
- usages の type は 原義／拡張／誤用寄り のどれか。
- added と updated は書いた日（日本時間、2026-11-08 の形）。
- emoji は Noto Emoji のコードポイント（例：1f438）。`python3 tools/fetch_emoji.py` で画像を取る。ほかの語と同じ絵文字はなるべく避ける。
- tags は既存のタグから選ぶ（ネットスラング、SNS・動画、推し文化、恋愛、心理学由来、ビジネス、社会、誤用の定番、意味が変わった言葉、オノマトペ由来、脳科学っぽい言葉、「20XX年流行」）。新しいタグは作らない。
- examples と paraphrase は使わない（サイトに出さない）。sources の note も出さないので書かない。

## 文章
- yomiyasu スキルがあれば使う。です・ます調。AIっぽい比喩、大げさな言葉、コピー調を避ける。
- catch は30字前後の一言。見出し語の意味のズレが一目で分かるように。
- definition は2〜3段落。最後の段落で「何と何がずれているか」を **太字** で示す。
- 断定できないことは断定しない。誰かを評価・批判しない。

## 公開まで
1. `python3 tools/fetch_emoji.py`
2. `python3 tools/check_words.py --links --only <今回の語のslug> --strict-sources`（「リンク」の行が出たら、config/linkcheck.json の refusing_hosts にあるサイト以外は出典を差し替える）
3. `python3 build.py`
4. `python3 tools/make_og.py`（Pillow が必要。macOS のヒラギノ角ゴシックを使う）
5. data/words/、assets/emoji/、tools/emoji512/、docs/、notes/ をコミットして push する
