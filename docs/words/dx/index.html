曖昧メーター

曖昧度4/5

通用度4/5

どういう意味？

「DX」はデジタルトランスフォーメーション（digital transformation）の略です。デジタル大辞泉は、情報技術が社会のあらゆる領域に広がることで起こる変革のことと説明しています。日本では、とくに企業や役所がデジタルの技術を使って変わることを指して使われます。

経済産業省は2018年12月のガイドラインで、DXを、データとデジタル技術を使って製品やサービス、ビジネスモデルを変えるとともに、業務や組織、プロセス、企業文化・風土まで変えて、競争で優位に立つことと定義しました。道具を入れ替えるだけでなく、仕事の進め方や会社のあり方まで作り直す、という大きな意味の言葉です。

ところが現場では、「書類をPDFにした」「会議をオンラインにした」「古いシステムを入れ替えた」といった、デジタル化の一歩を「DX」と呼ぶことがよくあります。総務省の情報通信白書（2021年版）も、DXの定義は厳密には一致しておらず、使い方も人や場面によってまちまちだと書いています。仕事や組織そのものを変える「変革」なのか、紙や手作業をデジタルに置き換える「デジタル化」なのか。どこまでをDXと呼ぶかが人によってずれています。

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    デジタル技術で社会や暮らしが変わること

    技術が社会の隅々に入り込むことで、人々の暮らしや社会のしくみが変わっていく、という大きな流れを指す使い方です。辞書の説明はこちらに近いです。

  2. 原義もともとの意味

    事業や組織を作り直すこと

    「DXで新しい事業を立ち上げる」のように、データやデジタル技術を使って、商品やサービス、仕事の進め方、組織や企業文化まで変えることです。経済産業省の定義に沿った使い方です。

  3. 誤用寄り出典から離れた使い方

    紙や手作業をデジタルにすること

    「ハンコをやめてDX」「勤怠管理をアプリにしてDX」のように、今ある作業をデジタルの道具に置き換えることを指す使い方です。変革の入口ではありますが、定義の中心とはずれています。

  4. 拡張広がった使い方

    分野ごとのデジタル化

    「医療DX」「教育DX」「自治体DX」のように、分野の名前を前に付けて、その分野のデジタル化の取り組み全体を指す使い方です。

語源・成り立ち

英語の digital transformation を縮めた言葉です。デジタル大辞泉によると、2004年にスウェーデンのE・ストルターマンが唱えたとされます。英語では trans- を X と書く略し方があるため、「DT」ではなく「DX」と書くとされています。

日本で広まったきっかけは、経済産業省が2018年9月に出した「DXレポート」です。古くなって複雑になった社内のシステムを放っておくと、2025年以降に最大で年12兆円の経済損失が生じるおそれがあると試算し、「2025年の崖」と名づけました。同じ年の12月にはDXの定義を示したガイドラインが出され、企業の経営の言葉として一気に広まりました。

広まった経緯

  1. 2004年

    スウェーデンのストルターマンがデジタルトランスフォーメーションを唱えたとされる（デジタル大辞泉）。

  2. 2018年9月

    経済産業省の研究会が「DXレポート」をまとめ、「2025年の崖」という言葉が知られるようになる。

  3. 2018年12月

    経済産業省が「DX推進ガイドライン」でDXの定義を示す。

  4. 2020年12月

    経済産業省の「DXレポート2」が、先のレポートが「DX＝レガシーシステム刷新」のような本質ではない解釈を生んだと指摘する。

  5. 2021年

    総務省の情報通信白書が、DXの定義は厳密には一致しておらず、使い方も人や場面によってまちまちだと記す。

  6. 2020年代

    「医療DX」「自治体DX」など、分野の名前を付けた使い方が広がる。

ズレのポイント

デジタル化＝DX ではない

紙をPDFにする、会議をオンラインにする、といったことは、デジタル化の一歩です。経済産業省の定義では、その先で仕事のやり方や組織、事業のしくみまで変えることをDXと呼んでいます。

システムの入れ替えだけではない

「DXレポート」が古いシステムの問題を大きく取り上げたため、DXを「システムを新しくすること」と受け取る人が出ました。2020年の「DXレポート2」はこの受け取り方を本質ではないものとして挙げ、2025年の経済産業省の委員会のレポートも、DXは古いシステムの刷新にとどまるものではないとしています。

IT部門だけの仕事ではない

定義には企業文化や組織の変革まで含まれるため、IT担当者だけでは進みません。経営や現場の仕事の見直しが一緒に要る、という点が抜け落ちやすい言葉です。

多様な観点

行政から

経済産業省は、レポートやガイドライン、「DX銘柄」の選定などを通して、企業にDXを進めるよう促してきました。総務省の情報通信白書は、紙の作業をデジタルに置き換える「デジタイゼーション」、仕事の流れ全体をデジタルにする「デジタライゼーション」と、DXを分けて説明しています。

企業の現場から

現場では、まず紙や手作業を減らすことから始めるのがふつうです。その取り組みを「DX」と呼ぶことで、予算や人を集めやすくなる面もあります。

働く人から

「DX推進」と言われても、新しいツールを覚えることなのか、仕事の進め方が変わることなのかが分からない、と感じる人もいます。言葉の大きさと、実際に変わることの大きさが合っていないときに戸惑いが生まれます。

使用シーン

企業の経営計画やニュース、役所の政策、ITの会社の広告でよく使われます。働く人の間でも、社内の取り組みの名前として広く聞かれる言葉です。

関連語

  • リスキリングDXに必要な技能を身につけ直すことを指して、一緒に語られることの多い言葉。
  • パーパス企業の変革を語るときに使われる、意味の広い経営の言葉。
  • エビデンスデータを使って判断する、という話の中でよく並ぶ言葉。
