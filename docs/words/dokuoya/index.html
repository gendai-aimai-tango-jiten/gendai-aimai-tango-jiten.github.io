曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

子どもの人生を支配したり、心や体に害を与え続けたりして、子どもが大人になっても悪い影響を残す親のことです。

アメリカの心理療法家スーザン・フォワードが1989年に出版した『Toxic Parents（毒になる親）』から広まった言葉です。日本では2010年代に、母と娘の関係をテーマにした本や報道をきっかけに、一般に知られるようになりました。

医学的な診断名や学術用語ではなく、どこからが毒親かの線引きはありません。深刻な虐待やネグレクトを受けてきた人が自分の経験を説明する言葉であると同時に、口うるさい親、考え方の合わない親への不満を言う言葉としても使われています。

あなたはどの意味派？

あなたは「毒親」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    子どもの人生を支配し害を与える親

    暴力、暴言、過干渉、ネグレクトなどで、子どもに長く続く心の傷を残す親を指します。フォワードの本で示された意味です。

  2. 拡張広がった使い方

    過干渉・支配的な親

    進路や結婚に口を出す、子どもを自分の思い通りにしようとする親を指す使い方です。日本では母と娘の関係で語られることが多くあります。

  3. 誤用寄り出典から離れた使い方

    ちょっと嫌な親への不満

    門限が厳しい、小言が多い、といった程度のことで「うちの親、毒親だわ」と言う使い方です。深刻な経験を持つ人の言葉を軽くしてしまうことがあります。

語源・成り立ち

英語の toxic parents（有害な親）の訳語です。スーザン・フォワードが1989年の著書で使った言葉で、学術用語として作られたものではありません。

日本では本の邦訳が出版されたあと、2000年代後半から母と娘の関係をテーマにした本が多く出版され、2010年代前半にはメディアを通じて「毒親」という言葉が広まりました。

広まった経緯

  1. 1989年

    スーザン・フォワードが『Toxic Parents』を出版する。

  2. 1999年ごろ

    日本語訳『毒になる親』が出版される。

  3. 2000年代後半〜2010年代前半

    母と娘の関係を扱った本が相次いで出版され、「毒親」という言葉がメディアを通じて広まる。

  4. 2010年代後半〜

    当事者の体験記や漫画、SNSでの発信が増え、日常的な言葉になる。

ズレのポイント

定義がないので、言った人の感覚で決まる

毒親には医学的な基準がないため、ある人にとっての「普通の厳しさ」が、別の人にとっての「毒」になることがあります。同じ言葉でも、指している経験の重さがまったく違います。

軽い使い方が深刻な経験を薄める

ちょっとした不満で「毒親」と言うことが増えると、本当に苦しんできた人の言葉が軽く受け取られてしまうおそれがあります。

親を責める言葉だけではない

毒親という言葉は、親を非難するためだけでなく、自分の苦しみの原因を理解し、回復の出発点にするための言葉としても使われてきました。

多様な観点

心理学から

子ども時代の親との関係が、大人になってからの対人関係や自己評価に影響することは、心理学でも研究されてきました。毒親という言葉は、そうした影響を当事者が自分の言葉で語るきっかけになりました。

家族の文化から

日本では「親を悪く言うものではない」という考えが根強く、親子の問題は表に出にくいとされてきました。毒親という言葉は、その沈黙を破る役割を果たした一方で、強い言葉ゆえの反発も生んでいます。

メディアから

当事者の体験を描いた漫画やエッセイが多く出版され、SNSでも共感を集めています。ドラマやニュースで取り上げられることで、言葉の意味は広がり続けています。

使用シーン

20代から50代を中心に、SNS、書籍、カウンセリング、ニュースなどで使われます。親子関係に悩む人の発信や、子育ての話題でもよく見かけます。

関連語

  • ガスライティング相手に自分の感覚を疑わせる心理的な支配。毒親の行動の説明に使われることがある。
  • 生きづらさ社会の中で感じる息苦しさ。子ども時代の経験と結びつけて語られることがある。
