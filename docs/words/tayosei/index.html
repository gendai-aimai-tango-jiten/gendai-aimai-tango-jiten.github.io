曖昧メーター

曖昧度5/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

さまざまな種類や性質のものが、共にあることです。もとは「生物多様性」のように、自然や生物の世界で使われることも多い言葉でした。

いまは、性別、年齢、国籍、人種、障害の有無、性的指向、価値観、働き方など、違いを持つ人々が共に生き、働くことを指す言葉として、企業や社会で広く使われています。英語の diversity（ダイバーシティ）の訳語でもあります。

ところが、企業では「多様性＝女性の管理職を増やすこと」のように狭く受け取られたり、逆に「何でも認めること」「批判してはいけないこと」のように広く受け取られたりしがちです。違う人がいるだけなのか、違いを活かせているのかで、多様性の意味は大きく変わります。

あなたはどの意味派？

あなたは「多様性」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    さまざまなものが共にあること

    種類や性質の違うものが一緒に存在していることです。「生物多様性」「文化の多様性」のように使います。

  2. 拡張広がった使い方

    違いを持つ人々が共にいること

    職場や社会に、性別、年齢、国籍などの違う人々がいることを指します。企業の「ダイバーシティ経営」の中心となる意味です。

  3. 誤用寄り出典から離れた使い方

    女性を増やすこと

    多様性の取り組みを、女性の採用や管理職登用だけと考える使い方です。女性活躍は多様性の一部ですが、すべてではありません。

  4. 誤用寄り出典から離れた使い方

    何でも認める・批判しない

    「多様性の時代だから何をしても自由」「多様性なので批判は禁止」のように使う例です。本来は、違いを尊重し合うことで、何でも許されるという意味ではありません。

語源・成り立ち

「多様（いろいろな様子）」に「性（性質）」を付けた言葉です。英語の diversity の訳語として、生物学や社会学、経営学などで使われてきました。

日本の企業では2000年代から「ダイバーシティ」という言葉が使われ始め、2010年代に女性活躍推進法などとともに広まりました。最近では、違いを持つ人が力を発揮できる状態を表す「インクルージョン（包摂）」と合わせて語られることが多くなっています。

広まった経緯

  1. 昔から

    「生物の多様性」「文化の多様性」のように、さまざまなものが共にあることを表す言葉として使われる。

  2. 2000年代

    日本の企業で「ダイバーシティ」という言葉が使われ始める。

  3. 2010年代

    女性活躍推進や働き方改革とともに、多様性が企業や社会の重要なキーワードになる。

  4. 2020年代

    「ダイバーシティ＆インクルージョン」として、違いを活かすことまで含めて語られるようになる。

ズレのポイント

女性活躍だけではない

多様性には、性別のほか、年齢、国籍、障害、性的指向、価値観など、さまざまな違いが含まれます。女性の比率だけを指標にすると、本来の意味が狭くなります。

「いるだけ」では足りない

違う人がいても、その人たちが意見を言えず、力を発揮できなければ、多様性を活かせているとは言えません。そのため、インクルージョンという考え方が重視されています。

何でも許すことではない

多様性は、違いを尊重し合うことであって、他人を傷つける言動まで許すことではありません。「多様性」を盾に批判を封じる使い方は、本来の意味からずれています。

多様な観点

経営から

さまざまな背景を持つ人が集まることで、ものの見方が多様になり、新しいアイデアや健全な判断が生まれやすくなる、と考えられています。

社会から

多様性という言葉が広まったことで、これまで見えにくかった少数派の人々の存在や困りごとに目が向くようになりました。一方で、言葉だけが先行しているという批判もあります。

生物学から

生物の世界では、多様性があるほど、環境の変化に強いとされます。社会や組織の多様性も、変化に対応する力につながるという考え方があります。

使用シーン

世代を問わず、企業、行政、学校、ニュース、SNSなど、あらゆる場面で使われます。
