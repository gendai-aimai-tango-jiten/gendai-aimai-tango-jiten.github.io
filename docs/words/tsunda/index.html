曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

将棋で、相手の王将がどこに動いても次の手で取られてしまい、負けが確定した状態を「詰み」と言います。そこから、物事が行き詰まって、もう挽回する方法がない、という意味で「詰んだ」と言うようになりました。

ゲームの世界で、勝ち目がなくなった状況を指す言葉として広まり、ネットやSNSを通じて、日常のさまざまな場面で使われるようになりました。「終電を逃して詰んだ」「テスト範囲を間違えて詰んだ」のように使います。

本当に打つ手がない深刻な状況なのか、ちょっと困った程度なのか。「詰んだ」は、大げさな自虐として軽く使われることも多い言葉です。

あなたはどの意味派？

あなたは「詰んだ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    将棋で負けが確定する

    相手の王将を逃げ場のない状態に追い込むこと、またはその状態です。将棋の正式な用語です。

  2. 拡張広がった使い方

    打つ手がなく行き詰まる

    「締め切りまでに終わらない、詰んだ」のように、もう挽回できない状況を表します。

  3. 拡張広がった使い方

    ちょっとした失敗を大げさに言う

    「傘を忘れた、詰んだ」のように、軽い困りごとを大げさに、自虐的に言う使い方です。

  4. 拡張広がった使い方

    人生や将来への悲観

    「人生詰んだ」のように、将来に希望が持てない気持ちを表す使い方です。深刻な気持ちが込められていることもあります。

語源・成り立ち

将棋の「詰む」から来ています。将棋では、実際に王将を取るまで指すのではなく、次に王将を取られることが避けられない局面になった時点で勝負がつきます。その状態を「詰み」と言います。

ゲームの攻略で使われていた「詰み」「詰んだ」が、ネットの掲示板やSNSを通じて、日常の絶望的な状況にも使われるようになりました。

広まった経緯

  1. 昔から

    将棋で、王将が逃げられない状態を「詰み」と呼ぶ。

  2. 2000年代

    ゲームやネットの掲示板で、勝ち目がない状況を「詰んだ」と言うようになる。

  3. 2000年代後半〜

    SNSを通じて、日常のさまざまな困りごとに使われる俗語として定着する。

ズレのポイント

深刻さの幅が広すぎる

軽い自虐の「詰んだ」と、本当に追い詰められた人の「詰んだ」は、同じ言葉でも重さがまったく違います。人の「詰んだ」を軽く受け流すと、深刻なサインを見落とすことがあります。

将棋では「詰んでも」投了がある

将棋では、詰みになる前に負けを認める「投了」が一般的です。日常の「詰んだ」も、本当は打つ手が残っていることが多いものです。

改まった場では使わない

俗語なので、仕事の報告などで「詰みました」と言うと軽く聞こえます。

多様な観点

将棋から

将棋の言葉は、日常語にたくさん取り入れられています。「王手」「成金」「高飛車」「待ったなし」なども将棋から来た言葉です。「詰む」もその仲間です。

ゲーム文化から

テレビゲームでは、進行不能な状態に陥ることを「詰み」と言います。ゲームで身についた感覚が、日常の言葉に持ち込まれた例です。

社会から

「人生詰んだ」という言い方は、就職、お金、家族など、若い世代が抱える将来への不安を表す言葉としても使われます。冗談めかしていても、本音が混じっていることがあります。

使用シーン

10代から40代を中心に、SNS、ネットの掲示板、日常会話で広く使われます。

関連語

  • しんどいつらい気持ちを表す言葉。
  • 生きづらさ社会で感じる息苦しさ。「人生詰んだ」と並べて語られることがある。
  • 草笑いを表すネットスラング。「詰んだ、草」のように自虐と一緒に使われる。
