曖昧メーター

曖昧度2/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

通用度5/5

どういう意味？

「定時退社」は、会社が決めた終業の時刻に仕事を終えて帰ることです。デジタル大辞泉は「定時」を「一定の時刻。定刻」と説明しています。会社でいう定時は、就業規則などで決めた所定労働時間の終わりの時刻のことで、残業をしないで帰ることを「定時で帰る」「定時退社」と言います。

言葉の意味ははっきりしていますが、受け取り方は職場によって違います。残業が少ない職場では、定時に帰るのはふつうのことです。一方で、残業が多い職場では、定時退社が「早く帰る」「先に抜ける」ことのように受け取られることがあります。新入社員向けの調査では、今後3年間の働き方として「定時に帰りたい」を選ぶ人が2024年度に48.2％となり、調査を始めた2014年度以来もっとも多くなりました。

「今日は定時で帰ります」と言うとき、言う人は決まりどおりに帰るだけのつもりでも、聞く人は早めに帰る宣言のように受け取ることがあります。決められた時刻に帰るという当たり前のことなのか、ほかの人より早く帰るという特別なことなのか。同じ「定時退社」が、職場の習慣によって、ふつうにも特別にも聞こえるところにズレがあります。

あなたはどの意味派？

あなたは「定時退社」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    決まった終業時刻に帰る

    就業規則などで決まっている終業の時刻に、仕事を終えて帰ることです。残業をしないことを指します。

  2. 拡張広がった使い方

    早めに帰る

    残業が多い職場では、定時に帰ることが「早く帰る」ことと同じ意味で使われることがあります。

  3. 拡張広がった使い方

    働き方の考え方

    「定時退社派」のように、仕事と私生活の時間を分けたいという考え方を表すこともあります。新入社員の調査でも、働き方の希望として「定時に帰りたい」が選ばれています。

語源・成り立ち

「定時」（決められた時刻）と「退社」（会社から帰ること）を合わせた言葉です。精選版日本国語大辞典は「定時」の用例として明治初めの文章を挙げており、「定時」自体は古くからある漢語です。

会社でいう「定時」は、就業規則などで決める所定労働時間の終わりの時刻です。デジタル大辞泉は所定労働時間を、企業が就業規則などで定めた労働時間で、法定労働時間の範囲内なら自由に決められる、と説明しています。

広まった経緯

  1. 2024年度

    ALL DIFFERENTの新入社員調査（4,227人）で、今後3年間の労働時間について「定時に帰りたい」が48.2％となり、2014年度の調査開始以来もっとも多くなる。

  2. 2026年度

    同じ調査で「定時に帰りたい」は43.3％となり、引き続きもっとも多い答えだったが、割合は2024年度をピークに下がったと発表される。

  3. 現在

    デジタル大辞泉が「定時」を「一定の時刻。定刻」と説明している。早いか遅いかの意味は含まない。

ズレのポイント

「早退」とは違う

定時退社は決まりどおりの時刻に帰ることで、早退（終業時刻より前に帰ること）とは別のものです。言い分けると誤解が減ります。

断りを入れるかは職場しだい

定時に帰るのに許可は要らないのが本来ですが、職場によっては一声かける習慣があります。どちらが正しいかではなく、職場の習慣に合わせて伝え方を選ぶと角が立ちません。

フレックスでは「定時」があいまい

フレックスタイム制の職場では、全員に共通の終業時刻がないことがあります。「定時」が何時を指すのかを確かめてから使うと行き違いが起きにくくなります。

多様な観点

辞書の見方から

辞書の「定時」は、決められた時刻のことで、早いか遅いかの意味は含みません。「早く帰る」という受け取り方は、言葉ではなく職場の習慣から生まれています。

新入社員の調査から

ALL DIFFERENTの調査では、「定時に帰りたい」は2020年度を除いて増え続け、2024年度に過去最多になりました。2026年度の発表では、なお最多の答えのまま、割合は少し下がっています。

働き方の変化から

残業が少ない職場が増えれば、定時に帰ることは特別ではなくなります。一方で、フレックスタイム制のように終業の時刻が人によって違う働き方では、「定時」という言葉そのものが当てはまりにくくなります。

使用シーン

会社勤めの人なら世代を問わず通じる言葉です。ただ、「定時に帰る」ことをどう受け取るかは、世代や職場の習慣によって差があります。
