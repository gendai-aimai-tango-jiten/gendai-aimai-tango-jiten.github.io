どういう意味？

もとは、危ない、都合が悪い、まずい、という意味の俗語です。「このままだと締め切りに間に合わなくてヤバい」のように使います。

2000年代ごろから、若い世代を中心に、「このラーメン、ヤバい」「あの演技はヤバかった」のように、すごい、最高、心を動かされたという正反対の意味でも使われるようになりました。文化庁の2014年度の調査では、「とても良い、すばらしい」という意味で使うことがある人が26.9%で、10年前より増えています。

良い意味が加わっても、悪い意味がなくなったわけではありません。「ヤバい」と言われたとき、ほめられたのか、心配されたのかは、文脈や声の調子でしか判断できません。

あなたは「ヤバい」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    危ない・都合が悪い

    「財布を忘れた、ヤバい」のように、危険な状況や、まずい事態を表します。もとの意味です。

  2. 拡張広がった使い方

    すごい・最高

    「この景色、ヤバい」のように、心を動かされるほどすばらしいことを表します。若い世代では、この使い方がとても多くなっています。

  3. 拡張広がった使い方

    程度がはなはだしい

    「ヤバいくらい眠い」「ヤバ寒い」のように、良し悪しに関係なく、程度が極端なことを強調する使い方です。

  4. 拡張広がった使い方

    感情があふれて言葉にならない

    推しの写真を見て「ヤバい……」と言うように、言葉にならない感情をまとめて表す使い方です。

語源・成り立ち

江戸時代の俗語「やば（危険なこと、不都合なこと）」に、形容詞の語尾「い」が付いたものとされています。十返舎一九の『東海道中膝栗毛』にも「やば」の用例があります。

「やば」の語源は、的当て遊びの場「矢場」から来たという説などがありますが、はっきりしていません。明治時代には、盗人などが警察を指す隠語として使っていた記録もあります。

広まった経緯

  1. 江戸時代

    「やば」が、危険や不都合を表す俗語として使われる。

  2. 昭和

    「やばい」が、危ない、まずい、という意味の俗語として一般に広まる。

  3. 2000年代

    若い世代の間で、「すごい」「最高」という肯定的な意味でも使われるようになる。

  4. 2014年度

    文化庁「国語に関する世論調査」で、肯定的な意味で使うことがある人が26.9%となる。

ズレのポイント

ほめ言葉なのに、心配されたと思われる

上の世代には、「ヤバい」は今も悪い意味の言葉です。料理をほめるつもりで「ヤバいですね」と言うと、「まずいのか」と受け取られることがあります。

改まった場では使わない

もともと俗語なので、良い意味でも悪い意味でも、仕事の場や目上の人との会話では使わないのが無難です。

何でも「ヤバい」で済ませると伝わらない

感動、驚き、恐怖、焦りを、すべて「ヤバい」で表すと、何を感じたのか相手には分かりません。語彙が少ない例としてよく挙げられる言葉でもあります。

多様な観点

言語学から

悪い意味の言葉が良い意味にも使われるようになる変化は、ほかの言語にも見られます。英語の awesome や terrific も、もとは「恐ろしい」という意味でした。ヤバいは、そうした意味の反転の分かりやすい例です。

日本語の調査から

文化庁の調査では、肯定的な意味で使う人は若い世代ほど多く、2004年度の調査で10代後半の約75%が使うと答えたと報じられています。世代によって、同じ言葉の意味の中心が違う例です。

感情表現から

「ヤバい」は、良い悪いを決める前の、心が大きく揺さぶられた状態をそのまま表す言葉とも言えます。判断を保留したまま驚きを共有できる、便利な言葉です。

使用シーン

10代から40代を中心に、日常会話やSNSで非常によく使われます。良い意味の「ヤバい」は若い世代ほど多く使います。
