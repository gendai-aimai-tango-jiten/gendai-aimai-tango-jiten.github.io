わーくらいふばらんす【ワークライフバランス】〔名〕

  1. ①

    もともとの意味仕事と生活の調和。仕事と私生活の両方を充実させ、互いによい影響を与え合う状態を目指す考え方です。

  2. ②

    働きやすさの制度。フレックスタイム、育児・介護のための時短、在宅勤務など、会社が整える制度をまとめて指すことがあります。

  3. ③

    出典から離れた使い方仕事を減らすこと。「ワークライフバランス重視なので」と、仕事より私生活を優先する、という意味で使う人もいます。

  4. ④

    出典から離れた使い方仕事と生活を半々にすること。「バランス」という言葉から、時間を半分ずつに分けることだと受け取る人もいます。

→定時退社・ウェルビーイング・静かな退職

曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

「仕事と生活の調和」と訳される言葉です。デジタル大辞泉は「やりがいのある仕事と充実した私生活を両立させるという考え方」と説明しています。2007年12月に政府と経済界・労働界が定めた「仕事と生活の調和（ワーク・ライフ・バランス）憲章」では、やりがいや充実感を感じながら働き、家庭や地域でも人生の段階に応じて多様な生き方を選べる社会を目指すとしています。

ところが日常では、「仕事と私生活を半々にすること」や「仕事を控えめにして私生活を優先すること」の意味で受け取られることがあります。就職や転職の話では「ワークライフバランスがいい会社」が「残業が少なく、休みが取りやすい会社」を指すことも多くあります。

本来は「仕事も生活も、その人の望む形で両立させる」ことですが、「仕事の時間を減らす」「半々に分ける」という意味で受け取る人もいて、話す人によって中身がずれます。

あなたはどの意味派？

あなたは「ワークライフバランス」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    仕事と生活の調和

    仕事と私生活の両方を充実させ、互いによい影響を与え合う状態を目指す考え方です。どちらにどれだけ力を注ぐかは人や時期によって違ってよい、とされます。

  2. 拡張広がった使い方

    働きやすさの制度

    フレックスタイム、育児・介護のための時短、在宅勤務など、会社が整える制度をまとめて指すことがあります。

  3. 誤用寄り出典から離れた使い方

    仕事を減らすこと

    「ワークライフバランス重視なので」と、仕事より私生活を優先する、という意味で使う人もいます。

  4. 誤用寄り出典から離れた使い方

    仕事と生活を半々にすること

    「バランス」という言葉から、時間を半分ずつに分けることだと受け取る人もいます。

語源・成り立ち

英語の work-life balance をそのままカタカナにした言葉で、WLB と略されることもあります。日本大百科全書によると、1990年代に欧米で使われ始めた考え方です。

日本では少子化や働き方の問題を背景に広まり、2007年12月に「仕事と生活の調和（ワーク・ライフ・バランス）憲章」と行動指針が定められました。日本では、仕事と育児の両立や多様な働き方の提供という意味で使われることが多いとされています。

広まった経緯

  1. 1990年代

    欧米で work-life balance という考え方が使われ始める。

  2. 2003年

    次世代育成支援対策推進法が制定され、企業に仕事と育児の両立支援が求められる。

  3. 2007年12月

    「仕事と生活の調和（ワーク・ライフ・バランス）憲章」と行動指針が定められる。

  4. 現在

    就職や転職の場で、残業の少なさや休みの取りやすさを表す言葉としても使われる。

ズレのポイント

「半々」ではない

バランスは「釣り合い」のことで、時間を均等に分けるという意味ではありません。子育て中は生活の比重を大きく、仕事に打ち込みたい時期は仕事を大きく、という選び方も含まれます。

「仕事を減らす」とは限らない

もとの考え方は、仕事も生活も充実させることです。私生活の充実が仕事にもよい影響を与える、という相乗効果を重視する説明もあります。

面接や求人で使うときは中身を具体的に

「ワークライフバランスを重視したい」だけでは、残業のことか、休暇のことか、在宅勤務のことかが伝わりません。何を大事にしたいかを具体的に言うと、すれ違いが減ります。

多様な観点

政策から

憲章は、経済的に自立できること、健康で豊かな生活の時間があること、多様な働き方を選べることの3つを目指す社会の姿として挙げています。

働く人から

人によって「バランスがいい」状態は違います。同じ会社でも、ある人には働きやすく、別の人には物足りないことがあります。

言葉の形から

「バランス」という言葉が天秤を思わせるため、仕事と生活を対立するものとして捉えやすくなります。近年は、仕事と生活を分けずに組み合わせる、という考え方を表す言葉も使われています。

使用シーン

会社の人事制度、求人や面接、政府の資料、ニュースなどで幅広く使われます。世代を問わず通じますが、思い浮かべる中身は人によって違います。

関連語

  • 定時退社ワークライフバランスの話でよく出てくる働き方。
  • ウェルビーイング心身や社会的に満たされた状態を表す言葉。
  • 静かな退職仕事に必要以上の力を注がない働き方。
