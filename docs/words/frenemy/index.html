どういう意味？

英語の friend（友だち）と enemy（敵）を組み合わせた言葉で、友だちのように親しく振る舞いながら、実際には相手を敵視していたり、陰で悪口を言ったり足を引っぱったりする人のことです。

英語では20世紀前半から使われていた言葉で、日本でも以前から知られていましたが、2026年にはショート動画の「あるある」ネタをきっかけに若者の間で再び広まりました。女子高生を対象にした調査では「一番使った流行語」の3位に入っています。

陰で裏切る人なのか、ちょっと張り合ってくる友だちなのか、仲はいいけど本音が見えない人なのか。どこからを「フレネミー」と呼ぶかは、人によって違います。

あなたはどの意味派？

あなたは「フレネミー」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    友だちを装った敵

    表では親しくしながら、陰で悪口を言う、秘密をばらす、足を引っぱるなど、実は敵意を持っている人を指します。

  2. 拡張広がった使い方

    仲がいいライバル

    仲はいいけれど、成績や恋愛で張り合ってしまう友だちを、半分冗談で「フレネミー」と呼ぶ使い方です。

  3. 拡張広がった使い方

    利害でつながる協力相手

    ビジネスでは、競争相手でありながら協力もする企業どうしの関係を指すことがあります。

  4. 誤用寄り出典から離れた使い方

    気に入らない友だちへのレッテル

    ちょっと意見が合わない、嫉妬してしまう相手を、根拠なく「フレネミー」と決めつける使い方です。関係をこじらせることがあります。

語源・成り立ち

英語の friend と enemy を混ぜ合わせた造語（かばん語）です。英語の辞書では20世紀前半から用例があるとされ、別々の書き手が何度か作り出した言葉とも言われています。

日本では、海外ドラマや女性誌を通じて知られるようになり、2010年代にも話題になりました。2026年にはショート動画で「フレネミーの特徴」といった投稿が広まり、若者言葉として再流行しています。

広まった経緯

  1. 20世紀前半

    英語で frenemy という言葉が使われ始める。

  2. 2010年代

    日本でも女性誌やネット記事で「フレネミー」が紹介され、知られるようになる。

  3. 2026年

    ショート動画をきっかけに若者の間で再流行し、JKラボの女子高生調査で「一番使った流行語」の3位（9.6%）に入る。

ズレのポイント

決めつけると関係が壊れる

「あの子はフレネミーだ」と思い込むと、相手のふつうの言動まで悪意に見えてしまうことがあります。動画の「あるある」を自分の人間関係に当てはめすぎると、疑心暗鬼になりがちです。

ライバルとフレネミーは違う

正々堂々と張り合うライバルは、敵意を隠しているわけではありません。表と裏が違うことが、フレネミーの核です。

本人に向けると強い言葉になる

冗談のつもりでも、相手に「フレネミーでしょ」と言うと、「裏切り者」と言われたように受け取られることがあります。

多様な観点

人間関係から

学校や職場など、離れにくい人間関係の中では、表面上は仲よくしながら競い合う関係が生まれやすくなります。フレネミーは、そうした複雑な関係に名前を付けた言葉です。

SNSの文化から

ショート動画では「フレネミーの特徴5選」のような分かりやすい形で紹介され、多くの人が自分の経験と重ねて共有しました。共感しやすい「あるある」として広まった言葉です。

ビジネスから

企業の世界では、競合しながら提携もする関係を「フレネミー」と呼ぶことがあります。同じ言葉でも、個人の人間関係とは違う、前向きな意味で使われます。

使用シーン

10代から20代を中心に、TikTokなどのショート動画、SNS、友人同士の会話で使われます。ビジネスの記事では、企業間の関係を表す言葉として使われます。

関連語

  • 同担拒否同じ推しのファンと距離を置くこと。張り合う関係という点で近い。
