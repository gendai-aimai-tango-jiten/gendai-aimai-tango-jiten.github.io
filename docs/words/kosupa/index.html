曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

「コストパフォーマンス」を縮めた言葉で、かけた費用（コスト）に対して、得られる効果や満足度（パフォーマンス）がどれくらいかを表します。「このランチはコスパがいい」「コスパ重視」のように使います。

もとは、機械やシステムの性能と価格の釣り合いを評価する言葉でしたが、いまは買い物、外食、旅行、人間関係まで、あらゆるものに使われます。

ただし、「安い」と同じ意味で使われることが多いのが、この言葉の落とし穴です。本来は、高い商品でも、それ以上の満足が得られれば「コスパがいい」と言えます。

あなたはどの意味派？

あなたは「コスパ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    費用に対する効果や性能

    機械やサービスの価格に対して、性能や効果が見合っているかを評価する言葉です。

  2. 拡張広がった使い方

    払った分に見合う満足感

    「この店はコスパ最強」のように、値段に比べて満足度が高いことを表します。いちばん多い使い方です。

  3. 誤用寄り出典から離れた使い方

    安いこと

    「コスパがいい＝安い」として、値段の安さだけを指す使い方です。満足度との釣り合いという本来の意味が抜けています。

  4. 拡張広がった使い方

    人間関係や生き方の損得

    「恋愛はコスパが悪い」のように、時間や労力に見合う見返りがあるかを考える使い方です。何でも損得で考える風潮として、批判的に語られることもあります。

語源・成り立ち

英語の cost（費用）と performance（性能、成果）を組み合わせた「コストパフォーマンス」を縮めた言葉です。英語では cost-effectiveness や value for money と言うのが一般的で、cost performance は日常ではあまり使われないため、和製英語に近い言葉です。

その後、時間の効率を表す「タイパ（タイムパフォーマンス）」という言葉も、コスパにならって生まれました。

広まった経緯

  1. 昭和〜

    機械やシステムの性能と価格の釣り合いを表す「コストパフォーマンス」が使われる。

  2. 1990年代〜2000年代

    略語の「コスパ」が、買い物や外食の評価で広く使われるようになる。

  3. 2020年代

    コスパにならって「タイパ」が生まれ、2022年の三省堂「今年の新語」大賞に選ばれる。

ズレのポイント

安い＝コスパがいい、ではない

安くても満足できなければ、コスパは悪いと言えます。逆に、高くても長く使えて満足度が高ければ、コスパはいいのです。

英語では通じにくい

英語で cost performance と言っても、日常会話では伝わりにくいことがあります。「お得」は good value for money などと言います。

何でもコスパで測る息苦しさ

恋愛、友人、趣味まで損得で考えるようになると、「無駄」に見えるものの価値が見えなくなります。「コスパ思考」への疑問もよく語られます。

多様な観点

経済から

長い不況や賃金の伸び悩みの中で、限られたお金で満足を得ようとする消費のスタイルが広がり、コスパという言葉が日常に定着しました。

世代論から

若い世代は、コスパに加えてタイパ（時間の効率）も重視すると言われます。お金も時間も無駄にしたくない、という感覚の表れです。

言語学から

「コスパ」は、「タイパ」「スペパ（スペースパフォーマンス）」など、「〇〇パ」という新しい言葉を生む型になりました。

使用シーン

世代を問わず、買い物、外食、旅行、ビジネスなど、あらゆる場面で使われます。

関連語
