曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

通用度3/5

どういう意味？

もとは、見た目は普通でも、付き合ううちに扱いの難しい面が出てくる人を、踏むと爆発する地雷にたとえた俗語です。

2020年ごろからは、黒やくすんだピンクを基調に、リボン、フリル、厚底の靴、涙袋を強調したメイクなどを組み合わせたファッションの名前として広まりました。「地雷系ファッション」「地雷系メイク」のように使われ、服の系統の一つとして定着しています。

人の性格を指すのか、服装の系統を指すのか。もとの意味が悪口なので、ファッションの名前として使っても、言われた側が性格を決めつけられたと感じることがあります。

あなたはどの意味派？

あなたは「地雷系」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    関わると面倒なことになりそうな人

    最初は普通に見えても、付き合ううちに束縛や情緒の不安定さが出てくる人を、地雷にたとえて言う俗語です。からかいや悪口として使われます。

  2. 拡張広がった使い方

    黒とピンクのファッションの系統

    黒やくすみピンクの服、リボン、フリル、厚底靴などを組み合わせたスタイルの名前です。本人が自分の好きな系統として名乗ることもあります。

  3. 拡張広がった使い方

    地雷系メイク

    赤みのあるアイシャドウや涙袋を強調し、少し泣きはらしたように見せるメイクの名前です。メイク動画の定番のテーマになりました。

  4. 誤用寄り出典から離れた使い方

    服装から性格を決めつける

    地雷系の服を着ている人を、もとの意味の「面倒な人」と同じように見る使い方です。ファッションと性格は別のものです。

語源・成り立ち

「地雷」は、踏むと爆発する兵器です。ネットでは、関わると面倒なことになる人や話題を「地雷」と呼ぶ言い方が以前からありました。

そこに「〇〇系」を付けて、そうした人の雰囲気を指す言葉になり、やがてその雰囲気をイメージしたファッションの名前になりました。ファッションの名前としての広まりは、SNSの記録などから2020年ごろからとされています。

広まった経緯

  1. 2010年代

    ネットで、関わると面倒な人を「地雷」「地雷系」と呼ぶ言い方が使われる。

  2. 2020年ごろ

    黒とピンクを基調にしたファッションが「地雷系」と呼ばれ、SNSで広まる。

  3. 2021〜2023年

    地雷系メイクの動画や、地雷系を名乗るブランド・ショップが増え、ファッションの系統として定着する。量産型との違いも話題になる。

ズレのポイント

服の名前でも、もとは悪口

ファッションの系統名として定着しても、もとの意味は「面倒な人」という悪口です。本人が名乗るのと、他人が「あの子地雷系だよね」と言うのとでは、響きがまったく違います。

量産型とははっきり分けられない

白やパステルピンクが多い「量産型」と、黒が多い「地雷系」は比べて語られますが、境界ははっきりしていません。「量産型地雷系」という言い方もあり、人によって分け方が違います。

見た目で中身を決めつけない

好きな服を着ているだけで、性格まで決めつけられることへの反発もあります。服の系統として使うときは、もとの意味が混ざらないよう気をつける必要があります。

多様な観点

ファッションから

地雷系は、ゴシック、ロリータ、ガーリーなどの要素を組み合わせたスタイルとされます。若い女性向けのブランドやショップが「地雷系」を打ち出し、一つの市場になりました。

言葉の変化から

悪口として生まれた言葉が、言われる側に取り込まれて自分たちの名前になる、という変化の例です。「オタク」なども同じように、からかいの言葉から自称へと変わっていきました。

社会から

流行の背景として、コロナ禍の閉塞感や、明るさより少し陰のあるものを好む空気を挙げる見方もあります。一方で、繁華街に集まる若者の問題と結びつけて報じられることもあり、イメージが一面的になりやすい言葉です。

使用シーン

10代から20代の女性を中心に、TikTok、Instagram、Xで使われます。ファッションやメイクの話題では系統の名前として、ネットの書き込みでは人を指す俗語として使われます。

関連語

  • 量産型白やピンクを基調にした、よく似たファッションの系統。地雷系と比べて語られる。
  • ぴえん泣きそうな気持ちを表す言葉。地雷系のファッションと一緒に語られることがある。
  • 推し活地雷系や量産型のファッションは、推し活の場でもよく見られる。
