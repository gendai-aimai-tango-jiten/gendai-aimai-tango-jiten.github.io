曖昧メーター

曖昧度4/5

誤用度2/5

通用度4/5

どういう意味？

「一本締め」は、宴会や式の終わりに、みんなで手を打って締める「手締め」の一つです。デジタル大辞泉は、まず「3拍、3拍、3拍、1拍のリズムで1回だけ行う」手締めと説明しています。「よーっ」の掛け声のあと、「シャシャシャン、シャシャシャン、シャシャシャン、シャン」と打つ形です。

ところが、「よーっ、パン」と1回だけ手を打つ締め方も、「一本締め」と呼ばれています。こちらの正式な呼び名は「一丁締め」で、「関東一本締め」と呼ぶ人もいます。辞書も二つめの意味に「一丁締めに同じ」と載せていて、どちらも一本締めとして通っています。

そのため、幹事が「一本締めで」と言ったとたん、10回打とうとする人と1回で終わる人に分かれることがあります。「3・3・3・1」の10回なのか、「よーっ、パン」の1回なのか。同じ言葉で、手を打つ回数が10倍違います。

あなたはどの意味派？

あなたは「一本締め」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    3・3・3・1で打つ手締め

    「シャシャシャン」を3回と「シャン」を1回、合わせて10回手を打つ形です。辞書が最初に載せている意味で、これを3回くり返すと三本締めになります。

  2. 拡張広がった使い方

    1回だけ打つ一丁締め

    「よーっ、パン」と1回だけ打つ形です。本来の呼び名は一丁締めですが、辞書も二つめの意味として載せていて、この意味で「一本締め」と言う人も多くいます。

  3. 拡張広がった使い方

    締めのあいさつ全体

    「最後に部長に一本締めをお願いします」のように、手締めの音頭を取るあいさつまで含めて指す使い方です。

語源・成り立ち

「手締め」は、物事が無事に終わったことを祝い、その場にいる人が拍子をそろえて手を打つ習わしです。一本締めは、その中でいちばん基本の形とされます。「3・3・3」で9回打ち、最後の1回を足すと、「九」に点を加えて「丸」になる、だから「丸く収まる」という説明もありますが、言い伝えの一つです。

ジャパンナレッジのコラム「日本語、どうでしょう？」は、一本締めを3回くり返すと三本締めになり、多くの場では三本締めが正式とされている、と書いています。一丁締めは1回だけ打つ形で、全員の音がそろわないと間が抜ける、とも紹介しています。

広まった経緯

  1. 昔から

    宴会や祝いの席の締めくくりに、手締めが行われてきた。

  2. 2010年

    ジャパンナレッジのコラム「日本語、どうでしょう？」が、一本締め・三本締め・一丁締め・大阪締めの違いを紹介する。

  3. 現在

    デジタル大辞泉は「一本締め」に、3・3・3・1の形と「一丁締めに同じ」の二つの意味を載せている。

ズレのポイント

1回だけでも誤りとは言えない

「よーっ、パン」の1回を一本締めと呼ぶのは、正式には一丁締めの形です。ただ、辞書が二つめの意味に載せているので、間違いと決めつけることはできません。

始める前に形をそろえる

幹事や音頭を取る人は、「一本締め、3・3・3・1でお願いします」「一丁締めで、1回だけです」と先に言っておくと、手を打つ回数がばらばらになりません。

三三七拍子とは別もの

応援で使う三三七拍子は、3・3・7のリズムで手を打つもので、手締めではありません。

多様な観点

宴会の幹事から

職場の飲み会では、参加者の年代や出身によって思い浮かべる形が違います。1回で終わると思っていた人が、2打目から取り残されることもあります。

地域の違いから

大阪には「打ちまーしょ」の掛け声で始める大阪締め、福岡には博多手一本があります。土地ごとに締め方が違い、「一本」という呼び方も一つに決まっていません。

辞書の見方から

デジタル大辞泉は、3・3・3・1の形を一つめ、一丁締めを二つめの意味として並べています。広く使われている呼び方を、辞書も受け入れている例です。

使用シーン

会社の宴会、忘年会、祝賀会、式典の終わりなどで使われます。若い世代では、手締めそのものをしたことがない人もいます。

関連語

  • 御の字宴会のあいさつなどで使われ、意味がずれやすい言葉。
  • 潮時お開きの場面で使われ、意味の受け取り方が分かれる言葉。
  • 采配を振る場を仕切る人を表し、言い方がゆれる言葉。
