曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

もとはラテン語で、古典劇の役者がつける仮面を指す言葉です。心理学者のユングはこの言葉を借りて、人が周りの環境に合わせて外に見せている顔をペルソナと呼びました。日本大百科全書は、意識は自我とペルソナからなり、ペルソナは「環境に対処してゆく顔」だと説明しています。

ビジネスの場では、別の意味で使われます。商品やサービスの典型的な利用者を、名前・年齢・職業・暮らしぶりまで決めた一人の架空の人物として描いたもので、これもペルソナと呼びます。1999年にアラン・クーパーがソフトウェア開発の手法としてまとめ、その後マーケティングの手法として広まったとされています。

心理学では「実在する人の外向きの顔」、マーケティングでは「実在しない一人の顧客像」を指します。ビジネスの中でも、年齢や性別だけで区切った「ターゲット」と同じ意味で使う人と、一人の人物像まで描き込んだものだけを指す人がいます。

あなたはどの意味派？

あなたは「ペルソナ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    仮面

    古典劇で役者がつける仮面のことです。英語の person や personality の語源とされます。

  2. 拡張広がった使い方

    人が外に見せる顔（心理学）

    ユング心理学の用語で、職場の顔、親としての顔のように、場面に合わせて見せる社会的な顔を指します。

  3. 拡張広がった使い方

    架空の顧客像（マーケティング）

    「30代、都内勤務、共働き、平日の夕食は15分で作りたい」のように、一人の人物として細かく描いた利用者像です。

  4. 誤用寄り出典から離れた使い方

    ターゲットと同じ意味

    「20代女性」のような大まかな層をペルソナと呼ぶ使い方です。本来のペルソナは、一人の人物像まで描き込んだものを指します。

語源・成り立ち

ラテン語の persona は、古典劇で役者がかぶった仮面を意味しました。そこから「役柄」や「人格」の意味が生まれ、英語の person や personality につながったとされます。

20世紀に入り、ユングが心の構造を説明する言葉としてペルソナを使いました。1999年には、アラン・クーパーが著書の中で、ソフトウェアを設計するときに想定する利用者像をペルソナと呼び、開発の手法としてまとめました。その後、マーケティングの手法として広まりました。

広まった経緯

  1. 古代ローマ

    ラテン語の persona が、古典劇の役者がつける仮面を指す。

  2. 20世紀前半

    ユングが、人が外に見せる社会的な顔をペルソナと呼ぶ。

  3. 1999年

    アラン・クーパーが、ソフトウェア開発で想定する利用者像をペルソナとしてまとめる。

  4. 2000年代以降

    マーケティングや商品開発の手法として、日本の企業にも広まる。

ズレのポイント

ターゲットとの違い

ターゲットは「20代の会社員」のような層を指します。ペルソナは、その層の中の一人を、名前や一日の過ごし方まで決めて描いたものです。会議で使うときは、どちらの意味かをそろえておくと話が食い違いません。

心理学の話と混ぜない

「あの人はペルソナが強い」のように人について使うときは、心理学寄りの意味になります。マーケティングの会議で同じ言葉が出ても、指しているものは別です。

作ったペルソナを実在の顧客と思い込まない

ペルソナは調査をもとにした架空の人物です。描き込むほど本物らしく見えますが、実際の顧客の声で見直す必要があります。

多様な観点

心理学から

ユング心理学では、ペルソナそのものは悪いものではありません。ただ、自我とペルソナがずれると心の負担になると考えられています。

マーケティングから

関係者全員が同じ一人の顧客を思い浮かべられるようにするのが目的です。大勢の平均ではなく、一人に向けて考えるための道具です。

言葉の形から

「仮面」が「人格」になり、さらに「架空の人物」になりました。外から見える顔、という芯は共通しています。

使用シーン

マーケティング、商品開発、デザインの現場でよく使われます。心理学やカウンセリングの話題では、ユングの用語として使われます。ゲームの題名として知っている人もいます。

関連語

  • 自分らしさ外に見せる顔と、本当の自分の違いが話題になる言葉。
  • 解像度顧客像を細かく描くことを「解像度を上げる」と言うことがある。
  • エンゲージメント顧客や社員との結びつきを表すビジネス語。
