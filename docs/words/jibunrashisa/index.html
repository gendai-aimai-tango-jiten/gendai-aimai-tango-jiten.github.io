曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

自分らしさは、その人らしい考え方や振る舞いのことです。「自分らしく生きる」「自分らしい働き方」のように、前向きな意味で広く使われています。

心理学では、自分らしくある感覚を「本来感」と呼んで研究しています。伊藤正哉さんと小玉正博さんの2005年の論文は、本来感を「自分自身に感じる本当らしさの感覚」とし、大学生335人への調査から、7つの項目でこの感覚を測る尺度を作りました。ここでの自分らしさは、無理をせず、本当の自分でいられるという感覚のことです。

一方、日常の会話では、人と違う個性や、自分の好みで選べることを指して使われることもあります。無理をしていない「本当の自分」の感覚と、人と違う「個性」。「自分らしくていいね」と言った人と言われた人で、思い浮かべている自分らしさがずれることがあります。

あなたはどの意味派？

あなたは「自分らしさ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    その人らしさ

    「いかにもあの人らしい」と同じように、その人の考え方や振る舞いの特徴を指します。周りから見たその人の姿です。

  2. 拡張広がった使い方

    無理をしていない感覚

    まわりに合わせすぎず、本当の自分でいられるという内側の感覚を指します。心理学で「本来感」と呼ばれるものに近い使い方です。

  3. 拡張広がった使い方

    人と違う個性

    服装や趣味、生き方で、ほかの人と違うところを指す使い方です。「自分らしさを出す」「自分らしさを表現する」のように使われます。

  4. 拡張広がった使い方

    自分で選べること

    「自分らしい働き方」「自分らしい暮らし」のように、決められた形ではなく、自分の希望で選べることを指す使い方です。

語源・成り立ち

「らしさ」は、「男らしさ」「その人らしさ」のように、ふさわしい様子や特徴を表す言い方です。「自分らしさ」は、それを自分に向けた言葉です。

心理学では、英語の authenticity（本来性）にあたる考え方として研究されてきました。伊藤正哉さんと小玉正博さんの2005年の論文は、自分らしくある感覚を「本来感」と名づけ、自尊感情とあわせて、幸福感とどう関係するかを調べています。この言葉がいつから一般に広く使われるようになったかは、はっきりしていません。

広まった経緯

  1. 2005年

    伊藤正哉さんと小玉正博さんが、自分らしくある感覚（本来感）を測る尺度を作った論文を『教育心理学研究』に発表する。

  2. 2024年9月

    NTTドコモのモバイル社会研究所が、10代男女の4割超が「SNSのほうが自分らしくいられる」と答えたという調査を発表する。

  3. 2025年11月

    健康社会学者の河合薫さんが、「自分らしく」は便利に使われすぎていると論じるコラムを日経BOOKプラスに書く。

  4. 現在

    広告や就職活動、人事の場で「自分らしく」がよく使われ、指す中身は人によって違う。

ズレのポイント

「自分らしく」が重荷になる

「自分らしく働こう」「自分らしさを見つけよう」と言われると、まだ見つかっていない人は、何かが足りないように感じることがあります。自分らしさは、探して見つけるものというより、あとから気づくものだと考える人もいます。

人から見た「らしさ」とずれる

「あなたらしいね」とほめたつもりでも、相手が思う自分らしさと違えば、決めつけられたように感じることがあります。周りから見たその人らしさと、本人が感じる自分らしさは、同じとは限りません。

人と違うことだけが自分らしさではない

個性を出すことを自分らしさだと考えると、目立たない選びかたをする人は「自分らしくない」ように見えてしまいます。心理学の本来感は、人と違うかどうかではなく、本人が無理をしていないと感じられるかを見ています。

多様な観点

心理学から

自分らしくある感覚は「本来感」と呼ばれ、尺度で測る研究があります。伊藤さんと小玉さんの研究では、本来感と自尊感情の両方が、幸福感に関わっていると報告されています。

SNSから

モバイル社会研究所の調査では、10代男女の4割超が「対面で話すより、SNSのほうが自分らしくいられる」と答えました。顔を合わせない場のほうが、無理をしなくてすむと感じる人もいるようです。

働き方から

河合薫さんは、自分らしさを探すことは、会社や社会が用意したリストから選ぶ作業になりがちだと書き、自分らしさ探しはしなくていいと論じています。働き方の話では、自分らしさが会社の側から求められることもあります。

使用シーン

広告のコピー、就職活動の自己分析、会社の人事制度や研修、学校の進路指導、SNSのプロフィールなどで使われます。どの場面でも前向きな言葉として使われるため、中身が問われにくい言葉です。

関連語

  • 自己肯定感自分を受け入れる感覚。自分らしさと一緒に語られることが多い。
  • 多様性一人ひとりの違いを認める考え方。自分らしさを大事にする話と並べて使われる。
  • 生きづらさ社会の中で感じる息苦しさ。自分らしくいられないことと結びつけて語られることがある。
