どういう意味？

「エンゲージメント」は英語の engagement をカタカナにした言葉です。英語では「約束」「婚約」「関わり合い」などの意味がありますが、日本では主にビジネスの言葉として使われ、場面によって指すものが大きく変わります。

人事や働き方の話では、社員が仕事や会社に向ける前向きな気持ちを指します。心理学の研究には「ワーク・エンゲイジメント」という用語があり、仕事に対して活力・熱意・没頭がそろった状態と定義されています。厚生労働省の「令和元年版 労働経済の分析」もこの考え方を取り上げました。一方、企業の調査や研修でいう「従業員エンゲージメント」は、会社への愛着や貢献したい気持ちまで含めることが多く、決まった定義はありません。

SNSやマーケティングでは、投稿への「いいね」やコメント、シェアなどの反応を指します。デジタル大辞泉は、投稿に対して閲覧者がボタンを押したりコメントしたりする割合を「エンゲージメント率」と説明しています。働く人の気持ちのことなのか、会社への結びつきのことなのか、SNSの反応の数のことなのか。会議で「エンゲージメントを上げたい」と言っても、人事と広報で思い浮かべるものが違います。

あなたはどの意味派？

あなたは「エンゲージメント」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    仕事への活力・熱意・没頭

    心理学でいう「ワーク・エンゲイジメント」です。仕事に生き生きと取り組み、やりがいを感じ、集中している状態を指します。研究では決まった尺度で測ります。

  2. 拡張広がった使い方

    会社への愛着や貢献したい気持ち

    「社員のエンゲージメントを高める」のように、仕事そのものへの熱意に加えて、会社への愛着や、会社のために力を尽くしたい気持ちまで含める使い方です。企業ごとに中身が違います。

  3. 拡張広がった使い方

    SNSの投稿への反応

    「この投稿はエンゲージメントが高い」のように、「いいね」やコメント、シェア、クリックなどの反応の数や割合を指します。マーケティングでは、企業と顧客の結びつきの目安として使われます。

  4. 原義もともとの意味

    婚約、約束

    「エンゲージリング」のように、英語のもとの意味の「婚約」「約束」として使われることもあります。ビジネスの場面ではあまり使われません。

語源・成り立ち

英語の engagement は、「約束する、引き込む、関わらせる」という意味の engage から来た言葉です。日本語では古くから「婚約」の意味で入っていて、精選版 日本国語大辞典は1902年の内田魯庵の『社会百面相』を早い例に挙げています。

心理学では、2000年代はじめにオランダのシャウフェリらが「ワーク・エンゲイジメント」の考え方をまとめ、日本では島津明人さんらが研究と尺度の日本語版づくりを進めました。厚生労働省は「令和元年版 労働経済の分析」でワーク・エンゲイジメントを大きく取り上げています。マーケティングでは、SNSの広がりとともに、投稿への反応を表す「エンゲージメント」「エンゲージメント率」が使われるようになりました。

広まった経緯

  1. 1902年

    内田魯庵『社会百面相』に「婚約（者）」の意味の「ヱンゲージメント」が出てくる（精選版 日本国語大辞典）。

  2. 2000年代はじめ

    オランダのシャウフェリらが「ワーク・エンゲイジメント」の考え方をまとめる。

  3. 2010年代

    SNSのマーケティングで、投稿への反応を表す「エンゲージメント」「エンゲージメント率」が使われるようになる。

  4. 2019年

    厚生労働省の「令和元年版 労働経済の分析」が、働き方とワーク・エンゲイジメントを取り上げる。

  5. 2020年代

    人的資本経営の話の中で、企業が「従業員エンゲージメント」を目標や指標として掲げることが増える。

ズレのポイント

「満足度」と同じではない

従業員満足度は、給料や職場の環境に満足しているかを表します。エンゲージメントは、仕事への熱意や会社に貢献したい気持ちを表すもので、満足していても熱意が高いとは限りません。

人によって測っているものが違う

研究のワーク・エンゲイジメントは、仕事への活力・熱意・没頭を決まった尺度で測ります。企業の「エンゲージメント調査」は、会社への愛着や上司との関係まで含むことがあり、数字をそのまま比べられないことがあります。

SNSの数字と混ざる

広報やマーケティングの人が「エンゲージメント」と言うときは、多くの場合、投稿への反応の数のことです。人事の話と同じ会議で出ると、取り違えが起きやすい言葉です。

多様な観点

心理学から

ワーク・エンゲイジメントは、燃え尽きと反対の、仕事に前向きに打ち込んでいる状態として研究されてきました。一時的な気分ではなく、仕事に向けた持続的な気持ちを指す、とされています。

人事から

人手不足や人的資本経営の流れの中で、社員がやりがいを持って長く働けるかを表す指標として使われています。会社によって定義や質問の中身が違うため、何を測っているかを確かめる必要があります。

SNSから

フォロワーの数より、投稿にどれだけ反応があったかを重く見る考え方が広まり、「エンゲージメント率」が投稿のよしあしを測る目安になっています。どの反応を数に入れるかは、サービスや会社によって違います。

使用シーン

人事や経営の会議、働き方の調査、企業の統合報告書でよく使われます。SNSの運用やマーケティングの現場でも毎日のように使われる言葉です。

関連語

  • インプレSNSで投稿が表示された回数。反応の数を表すエンゲージメントと並べて使われる。
  • ウェルビーイング働く人がよい状態でいることを表し、エンゲージメントと一緒に語られることが多い言葉。
  • 心理的安全性職場の働きやすさを表す言葉として、エンゲージメントと並んで使われる。
