曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

自己成長や社会貢献、キャリアへの熱意を、実態以上に大きく見せようとする人を、皮肉を込めて呼ぶ言葉です。カタカナのビジネス用語を多用する、SNSで人脈や活動を誇示する、といった振る舞いが典型とされます。

「意識が高い」は、もともと向上心がある、問題意識を持っている、というほめ言葉です。ところが「系（〜っぽい人）」が付くと、意識が高いふりをしているが中身が伴っていない人という皮肉になります。2012年に人材コンサルタントの常見陽平氏が出版した『「意識高い系」という病』で、広く知られるようになりました。

本当に努力している人なのか、見せかけだけの人なのか。外からは区別しにくいため、挑戦する人全般を冷やかす言葉として使われることもあります。

あなたはどの意味派？

あなたは「意識高い系」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    意識が高い（向上心がある）

    「意識が高い」は、学ぶ意欲や問題意識を持っていることを表す、ほめ言葉です。

  2. 拡張広がった使い方

    意識が高いふりをする人への皮肉

    「意識高い系の学生」のように、熱意をアピールするが実態が伴わない人を皮肉る使い方です。いちばん多い使われ方です。

  3. 誤用寄り出典から離れた使い方

    努力や挑戦をする人への冷やかし

    勉強会に参加する、資格を取る、といった前向きな行動まで「意識高い系」と笑う使い方です。挑戦する人の足を引っぱる言葉になります。

  4. 拡張広がった使い方

    自虐

    「意識高い系みたいで恥ずかしいけど」のように、自分の前向きな行動を照れ隠しで言う使い方もあります。

語源・成り立ち

「意識が高い」に、「〜っぽい人、〜のタイプ」を表す「系」を付けた言葉です。2000年代後半から、就職活動の場やネットで、自己アピールの強い学生などを指して使われ始めました。

2012年に常見陽平氏の『「意識高い系」という病』が出版され、言葉が一気に広まりました。常見氏は、地道な努力をおろそかにして、見せかけのアピールに走る傾向を問題視していました。

広まった経緯

  1. 2000年代後半

    就職活動やネットで、自己アピールの強い人を「意識高い系」と呼ぶ言い方が生まれる。

  2. 2012年

    常見陽平氏の『「意識高い系」という病』が出版され、言葉が広く知られる。

  3. 2010年代

    SNSでの自己アピールを皮肉る言葉として定着し、「意識高い系（笑）」のような使い方も広がる。

ズレのポイント

「意識が高い」と「意識高い系」は違う

「意識が高い」はほめ言葉ですが、「意識高い系」は皮肉です。「意識高いね」と言っただけでも、相手によっては皮肉に聞こえることがあります。

挑戦を冷やかす言葉にしない

前向きに学ぼうとする人を「意識高い系」と笑うと、挑戦しにくい空気を生みます。もともとは、中身のないアピールを問題にした言葉です。

見せかけかどうかは外から分からない

SNSでの発信だけを見て、中身が伴っているかどうかは判断できません。決めつけで使うと、相手に失礼になることがあります。

多様な観点

SNSの文化から

SNSでは、自分の活動や成果を発信することが当たり前になりました。発信すること自体が「意識高い系」と見られやすくなり、発信する側も見る側も、互いの目を気にするようになりました。

日本の職場文化から

目立つことを避け、謙遜を美徳とする文化では、前向きなアピールが冷ややかに見られやすくなります。「意識高い系」という言葉は、そうした空気を映しているとも言えます。

言語学から

「〜系」は、「草食系」「癒やし系」のように、人のタイプを表す便利な接尾語です。「意識高い系」は、ほめ言葉に「系」を付けることで皮肉に変える、という使い方の代表例です。

使用シーン

学生や若手の会社員を中心に、SNS、就職活動、職場の雑談などで使われます。ネットでは「意識高い系（笑）」のように使われることもあります。

関連語

  • マウント自分が上だと示す言動。意識高い系の特徴として語られる。
  • しごでき仕事ができる人をほめる言葉。意識高い系とは逆に素直なほめ言葉。
  • 承認欲求人に認められたい気持ち。意識高い系の背景にあると語られる。
  • パーパスカタカナのビジネス用語。意識高い系がよく使う言葉として皮肉られることがある。
