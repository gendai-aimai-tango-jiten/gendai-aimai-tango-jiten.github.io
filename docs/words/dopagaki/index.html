曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度4/5

通用度3/5

どういう意味？

「ドーパミン中毒のガキ」を縮めたネットスラングです。ショート動画、SNS、スマホゲームのように、すぐに強い刺激が得られるものを次々に消費し、短い時間で満足してすぐ飽きてしまう人をからかう言葉として使われます。

「ガキ」と付いていますが、実際の年齢は問われません。大人が自分のことを「完全にドパガキ」と言う自虐の使い方も多く見られます。

「ドーパミン」という脳の物質の名前が入っているため科学的な言葉に見えますが、医学用語ではなく、診断名でもありません。

あなたはどの意味派？

あなたは「ドパガキ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    刺激を求める受け手を指す皮肉

    初出とされる投稿は、ヒット曲が途中で聞くのをやめられないよう工夫されている点を取り上げ、その作りが想定している聞き手を皮肉るものでした。作り手側の事情を語る文脈から生まれた言葉です。

  2. 拡張広がった使い方

    他人（特に若い世代）への揶揄

    「最近の若い子はドパガキだから」のように、集中力がない人や、すぐ飽きる人をまとめてからかうときに使われます。

  3. 拡張広がった使い方

    自分の視聴習慣への自虐

    「倍速でしか見られない」「気づくとショート動画を1時間見ている」といった自分の習慣を、笑いを込めて言うときに使われます。

  4. 誤用寄り出典から離れた使い方

    病気や特性のように扱う

    ADHDなどの発達特性や、医学的な依存症と同じもののように使う例です。ドパガキは診断の言葉ではないので、こうした使い方は誤解や偏見につながります。

語源・成り立ち

「ドーパミン」＋「中毒」＋「ガキ」を縮めた語です。「ドパ」はドーパミン、「ガキ」は子どもを乱暴に言う言葉です。

ネットでは「〇〇厨」「〇〇ガキ」のように、ある行動をする人を見下して呼ぶ言い方が昔からあり、ドパガキもその系列に入ります。ただし、こうした言葉と同じく、実際の年齢とは関係なく使われます。

もとになった「ドーパミン中毒」という言い方自体も、医学的に定められた言葉ではありません。

広まった経緯

  1. 2024年12月28日

    XユーザーがMrs. GREEN APPLEの楽曲「ライラック」について、途中で聴くのをやめられないよう一定の間隔でメロディーに変化を入れている点を挙げ、「ドーパミン中毒のガキ」向けの商売は大変だという趣旨の投稿をした。これが由来とされる（投稿は現在削除済み）。

  2. 2025年

    略語の「ドパガキ」がSNSで急速に広まり、ニュース記事でも取り上げられるようになる。

  3. 2026年6月

    ニコニコ大百科に「ドパガキ」の記事が作られる。

  4. 2026年10月

    JKラボの女子高生94人への調査で、「一番使った流行語」2位（16.0%）、「SNSで見るけど実際は使わない言葉」1位（17.0%）、「大人には伝わらないと思う言葉」1位（27.7%）になる。

ズレのポイント

ドーパミンは「快楽物質」ではない

ドーパミンは「気持ちよさを生む物質」と説明されることが多いのですが、脳科学では、報酬を予測したり、何かを「欲しい」と思って行動したりすることに関わる物質として説明されるのが一般的です。

「ドーパミンが出るから気持ちいい」という理解は単純化しすぎで、ドパガキという言葉はその単純化の上に成り立っています。

病名や診断ではない

「ドーパミン中毒」という診断名はありません。ショート動画をよく見ることと集中力の関係は研究が進められていますが、原因と結果の関係はまだはっきりしていません。人をドパガキと呼ぶことは、医学的な判断ではなく、からかいです。

若い世代だけの話ではない

スマホで短い刺激を次々に求める習慣は、年齢に関係なく見られます。「ガキ」という語感から若者批判に使われやすいのですが、上の世代が自分のことを言う使い方も多くあります。

批判の向き先がぶれる

初出とされる投稿は、受け手に合わせて作品を作る側の大変さを語っていました。いまは受け手その人をからかう言葉として使われることが多く、作り手を批判しているのか、受け手を批判しているのかが、使う人によって違います。

多様な観点

脳科学から

ドーパミンは、何かを期待したり、手に入れようと動いたりするときに働く神経伝達物質として研究されてきました。報酬が予想より良かったときに強く反応することも知られています。

ショート動画は、次に何が出てくるか分からない状態が続くため、期待と報酬の繰り返しが起きやすい仕組みだとよく説明されます。ただし、それによって脳の働きが長く変わるかどうかは、研究の途中です。

世代論から

「最近の若者は集中力がない」という批判は新しいものではありません。テレビ、漫画、テレビゲームが広まったときにも、同じような言い方で若い世代が批判されてきました。

ドパガキは、その古くからある世代批判に、脳科学の言葉を借りて新しい名前を付けたものとも言えます。

音楽・コンテンツ産業から

動画配信や音楽ストリーミングでは、最初の数秒で離脱されないことが重視されます。イントロを短くする、サビから始める、曲全体を短くするといった傾向は、ストリーミング時代の特徴としてよく指摘されています。

ドパガキという言葉は、こうした作り手側の工夫と、それを求める受け手の両方を指して使われています。

言葉の性質から

JKラボの調査では、ドパガキは「一番使った言葉」の2位でありながら、「SNSで見るけど実際は使わない言葉」では1位でした。調査では理由として、「ガキ」を含むため人に向けると強く聞こえる点が挙げられています。

目にする機会は多いのに、口に出す人は限られる。ネット上の言葉と会話の言葉のずれがよく表れた例です。

海外との比較

英語圏では、ネット上の取るに足らないコンテンツを見すぎて頭の働きが鈍った状態を「brain rot」と言い、オックスフォード英語辞典の出版元が2024年の「今年の言葉」に選びました。スマホなどの強い刺激をしばらく断つ「dopamine detox（ドーパミン断ち）」という言い方も広まっています。

使用シーン

主にX、TikTok、YouTubeのコメント欄など、ネット上の書き込みで使われます。ショート動画の話題や、音楽、ゲームの話題でよく見かけます。

女子高生への調査では「見るけど使わない言葉」とされており、会話よりも文字で見かけることの多い言葉です。
