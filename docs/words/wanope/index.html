曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

「ワンオペレーション」を略した言葉で、一人ですべての作業を担うことを指します。もとは飲食店やコンビニで、店員一人が接客から調理、片づけまでを回す勤務体制の名前でした。2014年には牛丼チェーンの深夜の一人勤務が問題になり、広く知られるようになりました。

その後、夫婦の一方が育児や家事の大半を一人で負担する状態が「ワンオペ育児」と呼ばれるようになります。イミダスの時事用語事典は、店員一人で店を回す状態と似ていることから、この略語が使われていると説明しています。2017年には「ワンオペ育児」が新語・流行語大賞のノミネート語に選ばれました。

いまでは「今日はワンオペで回す」のように、一人で担当することを淡々と言う場面もあれば、「うちはワンオペ育児」のように不満や苦しさを込める場面もあります。一人で回す働き方の名前なのか、負担を一人に押しつけられた状態への不満なのか。同じ言葉でも、込められた気持ちが大きく違います。

あなたはどの意味派？

あなたは「ワンオペ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    店の一人勤務

    飲食店やコンビニで、店員一人が店の業務をすべて担う勤務体制のことです。人手不足や長時間労働の問題として報じられてきました。

  2. 拡張広がった使い方

    ワンオペ育児・家事

    夫婦の一方、多くは妻が、育児や家事の大半を一人で担う状態です。単身赴任や入院で配偶者がいない場合にも使われます。

  3. 拡張広がった使い方

    仕事を一人で担当すること

    「この案件はワンオペ」のように、職場で一人で受け持つことを指す使い方です。必ずしも不満を込めているとは限りません。

  4. 誤用寄り出典から離れた使い方

    少し一人になっただけ

    配偶者が一晩出かけただけのときなどに「今日はワンオペ」と言う使い方です。日常的に負担を抱える人からは、軽く聞こえることがあります。

語源・成り立ち

「ワンオペレーション」を略した言葉です。外食業界で、一人の店員に店の業務を任せる勤務体制を指して使われてきました。

2014年、牛丼チェーン「すき家」で深夜の一人勤務などをめぐる問題が相次いで報じられ、運営会社が設けた第三者委員会が同年7月に調査報告書を出しました。この報道で「ワンオペ」という言葉が広く知られるようになり、やがて育児や家事を一人で担う状態にも当てはめられるようになりました。

広まった経緯

  1. 2014年2〜3月

    牛丼チェーン「すき家」で、人手不足から一部の店が営業できなくなり、深夜の一人勤務が「ワンオペ」問題として報じられる。

  2. 2014年7月

    運営会社が設けた第三者委員会が、労働環境についての調査報告書を公表する。

  3. 2017年11月

    「ワンオペ育児」が、ユーキャン新語・流行語大賞のノミネート語30語に選ばれる。

  4. 2018年

    イミダスの時事用語事典に「ワンオペ育児」が載る。

ズレのポイント

店の言葉と家庭の言葉で重さが違う

店のワンオペは勤務体制の名前ですが、ワンオペ育児は負担の偏りを訴える言葉として使われることが多くあります。同じ「ワンオペ」でも、言う人の気持ちは大きく違います。

一時的な一人と、ふだんの一人

たまに一人で子どもを見ただけの日を「ワンオペ」と呼ぶと、毎日一人で抱えている人には軽く聞こえることがあります。

責める言葉として受け取られることがある

家庭の中で「ワンオペ」と言うと、相手を責めていると受け取られる場合があります。状態を伝えたいのか、分担を見直したいのかを言葉にすると、話が進みやすくなります。

多様な観点

働き方から

外食やコンビニの一人勤務は、人件費をおさえられる一方で、休憩が取りにくい、防犯上の不安があるといった問題が指摘されてきました。2014年の「すき家」の報道は、その問題を広く知らせるきっかけになりました。

家庭から

イミダスは総務省の社会生活基本調査をもとに、6歳未満の子どもがいる夫婦の家事時間のうち、妻の分担が1996年は95％、2016年は86％だったと紹介しています。共働きでも妻の側に負担が偏りやすいことが、ワンオペ育児という言葉の背景にあります。

言葉の働きから

「ワンオペ」という短い言葉ができたことで、一人で抱える負担を説明しやすくなりました。一方で、職場の言葉を家庭に持ち込んだ言い方なので、家族の間では冷たく聞こえることもあります。

使用シーン

子育て中の親を中心に、SNSや育児のメディアでよく使われます。職場でも「ワンオペで回す」のように使われ、飲食や小売りの現場では勤務体制の言葉として今も使われています。

関連語

  • モラハラ家庭の中の関係をめぐる言葉として、並んで話題になることがある。
  • 自己責任負担を一人に負わせる考え方として、ワンオペと並べて語られることがある。
  • ウェルビーイング働き方や暮らしの負担を見直すときに使われる言葉。
