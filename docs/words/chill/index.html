どういう意味？

英語のスラング chill out（落ち着く、くつろぐ）から来た言葉で、リラックスして落ち着いた状態や、まったりした雰囲気のことを指します。「チルな音楽」「チルいカフェ」「家でチルする」のように、名詞、形容詞、動詞として使われます。

2010年代後半から若者の間で広まり、形容詞の「チルい」は2021年の三省堂「今年の新語」の大賞に選ばれました。

ゆったりした音楽の雰囲気なのか、居心地のいい場所なのか、何もしない過ごし方なのか。「チル」が指すものはとても広く、心地よさの中身は人によって違います。

あなたはどの意味派？

あなたは「チル」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    くつろぐ・落ち着く

    「週末は家でチルする」のように、何もせずのんびり過ごすことを指します。英語の chill out に近い意味です。

  2. 拡張広がった使い方

    ゆったりした音楽の雰囲気

    「チルい曲」「チルなプレイリスト」のように、落ち着いたテンポで心地いい音楽を指します。音楽のジャンル「チルアウト」とも重なります。

  3. 拡張広がった使い方

    居心地のいい場所や時間

    「チルいカフェ」「チル旅」のように、雰囲気がよく、ゆっくり過ごせる場所や時間を表します。

  4. 誤用寄り出典から離れた使い方

    おしゃれな雰囲気全般

    照明が暗めでおしゃれ、という程度の意味で「チル」を使う例です。広告や商品名で多く、くつろぎという核から離れることがあります。

語源・成り立ち

英語の chill（冷える、落ち着く）や chill out（くつろぐ）から来ています。英語圏では、ヒップホップやクラブ文化で「落ち着け」「くつろごう」という意味で使われてきました。

日本では、音楽ジャンルの「チルアウト」や、ヒップホップの影響を受けた若者の間で使われ始め、2010年代後半から「チルする」「チルってる」「チルい」など、さまざまな形で使われるようになりました。

広まった経緯

  1. 2010年代後半

    若者の間で「チル」「チルする」が広まる。

  2. 2021年

    コロナ禍で家での過ごし方が注目され、「おうちチル」などの言い方が広がる。

  3. 2021年11月

    三省堂「辞書を編む人が選ぶ『今年の新語2021』」で「チルい」が大賞に選ばれる。

ズレのポイント

英語の chill とは少し違う

英語の chill には「寒気」「冷たさ」という意味もあり、「Chill!」は「落ち着け」と相手をなだめる言葉にもなります。日本語の「チル」のような、おしゃれでまったりした雰囲気という意味は、英語では文脈によります。

何でもチルで済ませると伝わらない

「チルい」は便利な言葉ですが、静かなのか、暖かいのか、雰囲気がいいのか、具体的な中身は伝わりません。お店の紹介などでは、何が心地いいのかを添えると伝わりやすくなります。

宣伝の言葉としても多用される

「チル消費」「チル旅プラン」のように、企業の宣伝で多く使われるようになりました。言葉のゆるさが、商品のイメージづくりに使われています。

多様な観点

音楽から

「チル」は、ローファイ・ヒップホップなど、作業中や休憩中に流す落ち着いた音楽の流行と一緒に広まりました。動画配信サイトの「勉強用BGM」なども、チルの文化の一部です。

社会から

コロナ禍で外出が減り、家で心地よく過ごすことが重視されたことが、チルの広まりを後押ししたとされます。がんばることより、ゆるむことに価値を見いだす空気の表れとも言えます。

マーケティングから

サウナ、キャンプ、アロマ、照明など、「チル」をうたう商品やサービスが増えました。くつろぎを売る市場は「チル消費」とも呼ばれます。

使用シーン

10代から30代を中心に、SNS、音楽、カフェや旅行の紹介などで使われます。広告や雑誌でもよく見かける言葉です。

関連語

  • エモい言葉にならない感情を表す言葉。チルと並んで雰囲気を言う言葉。
  • 映え見た目がSNS向きであること。チルいカフェと映えるカフェは重なることが多い。
  • マインドフルネスいまに意識を向けて心を落ち着ける方法。くつろぎの文脈で並べて語られる。
