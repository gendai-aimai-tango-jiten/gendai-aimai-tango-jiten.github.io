すいこう【推敲】〔名〕

  1. ①

    もともとの意味表現を練り直す。「推敲を重ねて仕上げた小説」のように、言葉の選び方や文の組み立てを考え直して、文章をよくすることを指します。

  2. ②

    書いたものを読み返して直す。「メールを送る前に推敲する」のように、日常の文章を見直す作業全体を指す使い方です。

  3. ③

    出典から離れた使い方誤字脱字のチェック。「推敲＝誤字を直すこと」と受け取る使い方です。

曖昧メーター

曖昧度2/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

通用度4/5

どういう意味？

「推敲」は、詩や文章を作るときに、言葉や言い回しをよく考えて練り直すことです。デジタル大辞泉は「詩文の字句や文章を十分に吟味して練りなおすこと」と説明し、「推敲を重ねる」という例を挙げています。言いたいことが伝わるか、もっと合う言葉はないかを考えて書き直す作業です。

ところが仕事の場では、「提出前に推敲しておいて」が「誤字脱字がないか見ておいて」という意味で使われることがあります。誤字や表記のゆれを正すのは、本来は「校正」の仕事です。Precious.jp の記事も、「推敲」と「校正」の違いを取り上げ、書き手自身が練り直すのが推敲だと説明しています。

頼んだ人は誤字だけ見てほしかったのに、頼まれた人は文の組み立てまで書き直してしまう。その逆も起こります。表現を練り直すことなのか、誤りを見つけて直すことなのか。どこまで手を入れるかの範囲が、人によってずれる言葉です。

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    表現を練り直す

    「推敲を重ねて仕上げた小説」のように、言葉の選び方や文の組み立てを考え直して、文章をよくすることを指します。

  2. 拡張広がった使い方

    書いたものを読み返して直す

    「メールを送る前に推敲する」のように、日常の文章を見直す作業全体を指す使い方です。表現の手直しと誤字の修正を、まとめて言うことが多くなります。

  3. 誤用寄り出典から離れた使い方

    誤字脱字のチェック

    「推敲＝誤字を直すこと」と受け取る使い方です。誤字や表記を正す作業は、本来は「校正」と呼ばれます。

語源・成り立ち

唐の詩人・賈島が、都に向かう途中、ロバの上で「僧は推す月下の門」という句を思いつき、「推す」を「敲く（たたく）」に改めるか迷ったという故事から生まれました。手で押すしぐさとたたくしぐさをくり返すうちに、都の長官だった韓愈の行列にぶつかり、事情を話すと韓愈が「敲く」がよいと答えた、と伝えられています。

この話は『唐詩紀事』などに載っています。精選版 日本国語大辞典は、日本での用例として、14世紀の『鈍鉄集』や、元禄6年（1693年）の芭蕉の書簡を挙げています。

広まった経緯

  1. 9世紀初め（唐）

    賈島が「推す」と「敲く」のどちらにするか迷い、韓愈の助言で「敲く」に決めたと伝えられる。

  2. 1331年ごろ

    詩文集『鈍鉄集』に「推敲」の用例がある（精選版 日本国語大辞典）。

  3. 1693年

    芭蕉の書簡に、二つの句のどちらがよいか「推稿」が定まらない、という用例がある（精選版 日本国語大辞典）。

  4. 現在

    ビジネスマナーの記事で、「推敲」「校正」「添削」の違いがたびたび取り上げられる。

ズレのポイント

頼むときは範囲をはっきり

「推敲して」とだけ頼むと、誤字だけ直す人も、構成から書き直す人もいます。「誤字脱字だけ見てください」「伝わりにくいところは書き直してください」と、手を入れる範囲を言葉にすると行き違いが減ります。

「校正」「添削」との違い

Oggi.jp の記事は、「校正」を、ゲラ刷りを原稿と照らし合わせて誤りを正すこと、「添削」を、他人の文章を直すこと、と整理しています。自分の文章をよくするために練り直すのが「推敲」です。

人の文章に使うときは注意

推敲は、書き手が自分の文章を練り直すことを指すのが基本です。他人の文章に手を入れるときは「添削」「手直し」と言うほうが、立場の違いが伝わります。

多様な観点

故事から

賈島が迷ったのは、誤字ではなく、一字で詩の場面がどう変わるかでした。「推敲」はもともと、表現の良し悪しを考え抜くことを指す言葉です。

出版の仕事から

本や雑誌づくりでは、書き手が推敲し、校正者が誤りや表記をそろえ、校閲者が事実関係を確かめる、と役割が分かれています。日常で「推敲」と言うときは、これらがひとまとめになりがちです。

AIの時代から

文章を整えるツールが増え、「誤字を直す」「言い回しを変える」「構成を組み替える」を一度に頼めるようになりました。どこまで直してほしいのかを言葉にする必要は、むしろ増えています。

使用シーン

学校の作文指導から、仕事のメールや企画書、小説や記事の執筆まで、文章を書く場面で広く使われます。

関連語

  • 割愛文章や話の一部を省くことにまつわる、本来の意味とずれやすい言葉。
  • 言語化考えを言葉にすることを指す、仕事でよく使われる言葉。
  • 解像度物事をどれだけ細かくとらえているかを表す、比喩として広がった言葉。
