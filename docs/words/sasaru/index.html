曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

本来は、とげ、針、矢など、とがったものが突き立つことです。「指にとげが刺さる」のように使います。

そこから、言葉が人の心に強く響くことを表すようになりました。ただし、その響き方には二つの方向があります。一つは、「上司の一言が胸に刺さった」のように、心が痛む、傷つくという意味。もう一つは、「この歌詞、めちゃくちゃ刺さる」のように、深く共感する、心を打たれるという意味です。

共感・感動の意味は2010年代に広まり、2015年の三省堂「今年の新語」で9位に選ばれました。「刺さった」と言われたとき、傷ついたのか、感動したのかは文脈で判断するしかありません。

あなたはどの意味派？

あなたは「刺さる」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    とがったものが突き立つ

    とげや矢などが、物や体に突き立つことです。

  2. 拡張広がった使い方

    言葉が心を傷つける

    「厳しい指摘が胸に刺さった」のように、言われたことが心に痛く響くことを表します。以前からある使い方です。

  3. 拡張広がった使い方

    深く共感する・心に響く

    「このコピー、刺さる」のように、強く共感したり、感動したりすることを表します。2010年代に広まった使い方です。

  4. 拡張広がった使い方

    狙った相手に響く

    「若者に刺さる商品」のように、マーケティングで、狙った層の心をとらえることを表す使い方です。

語源・成り立ち

「刺さる」は、「刺す」の自動詞で、とがったものが突き立つことを表す古くからの言葉です。

言葉が心に「突き刺さる」という比喩は以前からありましたが、多くは傷つく意味でした。2010年代に、共感や感動を表す意味が若い世代を中心に広まり、辞書にも「深く納得したり、共感したりできる」という意味が載るようになりました。

広まった経緯

  1. 昔から

    とがったものが突き立つ意味で使われる。言葉が心に突き刺さって痛む、という比喩も使われる。

  2. 2010年代

    共感や感動を表す「刺さる」が、若い世代やマーケティングの場で広まる。

  3. 2015年12月

    三省堂「辞書を編む人が選ぶ『今年の新語2015』」で、「刺さる」が9位に選ばれる。

ズレのポイント

傷ついたのか、感動したのか

「あの言葉が刺さった」は、文脈によって「傷ついた」とも「感動した」とも受け取れます。誤解を避けたいときは、「痛かった」「響いた」とはっきり言うほうが伝わります。

「胸に」「心に」が付くと傷つく意味になりやすい

「胸に刺さる」「心に刺さる」は傷つく意味、「刺さる」だけなら感動の意味、という傾向があるとも言われます。ただし、それだけでは判断できないことも多くあります。

宣伝の言葉としての「刺さる」

「〇〇層に刺さる」は、マーケティングの決まり文句になりました。人の心を的に見立てる言い方なので、使い方によっては、相手を操作しようとしているように聞こえることもあります。

多様な観点

辞書から

辞書の編集者の間でも、刺さるの二つの意味をどう見分けるかが話題になりました。同じ言葉が、良い意味と悪い意味の両方で同時に使われている例です。

言語学から

「刺さる」は、言葉や表現が心の奥まで届く、という共通のイメージを持っています。届いた結果が痛みか感動かで、意味が分かれるのです。

マーケティングから

広告や商品開発では、「誰に刺さるか」を考えることが大切にされます。多くの人に少し好かれるより、一部の人に強く刺さるほうが、SNSで広まりやすいと言われます。

使用シーン

世代を問わず、日常会話、SNS、作品の感想、マーケティングの話題などで広く使われます。

関連語

  • エモい心が揺さぶられる感情を表す言葉。
  • バズるSNSで一気に話題になること。刺さる投稿はバズりやすい。
