ふにおちない連語（慣用句）

腑に落ちない

『「腑に落ちない」は、納得できない不満か、わけが分からない不思議か。』

誤用の定番意味が変わった言葉
この言葉をシェア

ふにおちない【腑に落ちない】〔連語〕

  1. ①

    もともとの意味納得がいかない。説明や結論を聞いても、自分の中で筋が通らないことです。

  2. ②

    理由が分からず不思議。不満というより、なぜそうなったのか見当がつかない様子です。

  3. ③

    やんわりした反対。職場などで「反対です」と言う代わりに使われることがあります。

  4. ④

    出典から離れた使い方「腑に落ちる」は誤り、という思い込み。打ち消さない「腑に落ちる」を誤りだと考える人もいます。

曖昧メーター

曖昧度2/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

納得がいかない、合点がいかないことを言う言葉です。「腑」ははらわたのことで、転じて考えや分別も指します。言われたことや起きたことが、自分の中にすっと収まらない様子を表します。

デジタル大辞泉は「彼が落選したのは腑に落ちない」という例を挙げ、類語に「不可解」「解せない」「不思議」を並べています。説明を聞いたうえで「その理屈には納得できない」と言う人もいれば、「なぜそうなったのか分からない」という意味で使う人もいます。どちらも辞書の意味の内側ですが、相手が受け取る温度は変わります。

言った人は「理由が分からない」くらいのつもりでも、聞いた人は「説明に不満がある」と受け取ることがあります。

あなたはどの意味派？

あなたは「腑に落ちない」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    納得がいかない

    説明や結論を聞いても、自分の中で筋が通らないことです。「その説明では腑に落ちない」のように使います。

  2. 拡張広がった使い方

    理由が分からず不思議

    不満というより、なぜそうなったのか見当がつかない様子です。「彼が落選したのは腑に落ちない」のように、不可解さを言うときに使われます。

  3. 拡張広がった使い方

    やんわりした反対

    職場などで「反対です」と言う代わりに使われることがあります。言われた側は、遠回しな異議として受け取ります。

  4. 誤用寄り出典から離れた使い方

    「腑に落ちる」は誤り、という思い込み

    打ち消さない「腑に落ちる」を誤りだと考える人もいます。実際には明治時代の文学から使われ、日本国語大辞典やデジタル大辞泉にも載っています。

語源・成り立ち

「腑」は、はらわた（臓腑）のことです。日本国語大辞典は、そこから転じて「考え。了簡。思慮分別」の意味も載せています。考えをしまう場所に話がすとんと落ちる、というたとえです。

古くは「腑に入る」という言い方もありました。日本国語大辞典は、1730年の浄瑠璃『蒲冠者藤戸合戦』の「腑に入ぬ」を挙げ、「多く、下に否定の語を伴って用いる」と説明しています。

広まった経緯

  1. 1730年

    浄瑠璃『蒲冠者藤戸合戦』に「腑に入ぬ」の形が出てくる（日本国語大辞典の用例）。

  2. 1900〜01年

    徳冨蘆花『思出の記』に、打ち消さない「腑に落ちて」が出てくる。

  3. 1915年

    夏目漱石の講演『私の個人主義』に「腑に落ちようが落ちまいが」と、両方の形が出てくる。

  4. 1943年

    織田作之助『わが町』の「腑に落ちた」が、デジタル大辞泉の用例になる。

  5. 2021年

    日本国語大辞典の元編集長の神永曉さんが、辞書ごとに見出しの形が「腑に落ちない」「腑に落ちる」に分かれていると紹介する。

ズレのポイント

不満と受け取られることがある

「腑に落ちない」と言うと、相手の説明が足りないと言っているように聞こえることがあります。分からないだけなら「どうしてそうなったのか、まだ分かっていません」と言うほうが伝わります。

「腑に落ちる」も間違いではない

広辞苑や大辞林は「腑に落ちない」を見出しにしていますが、日本国語大辞典は「腑に落ちる」を見出しにしています。漱石や鏡花の作品にも用例があり、誤りとは言えません。

「腑」を「府」と書かない

はらわたの意味なので「腑」と書きます。

多様な観点

辞書の扱いから

神永曉さんによると、中型以上の辞書では『大辞林』『広辞苑』が「腑に落ちない」、『日本国語大辞典』が「腑に落ちる」、『大辞泉』が両方を見出しにしています。小型の辞書や実際の使用例では、「腑に落ちない」のほうがずっと多いそうです。

職場の会話から

ビジネスでは「腹落ち」という言葉も広まりました。「腑に落ちない」が否定で使われやすいのに対し、「腹落ちした」は肯定で使われることが多い言葉です。

言葉の気持ちから

「納得できない」より柔らかく、「意味が分からない」より改まった響きがあります。そのぶん、どちらの気持ちで言ったのかが伝わりにくくなります。

使用シーン

会議、ニュースの解説、ミステリーの感想、日常の会話まで、世代を問わず使われます。

関連語

  • 腹落ち心から納得すること。肯定で使われることが多い。
  • 忖度相手の気持ちを推し量ること。言わずに察する点でつながる。
  • 微妙はっきり否定しないときに使われる言葉。
