どういう意味？

英語の pending から来たカタカナ語です。英和辞典は pending の形容詞の意味として「〈問題・業務などが〉未決定［未完］の」「係属中の」を挙げています。職場では「この案件はいったんペンディングで」「予算が合わずペンディング中です」のように、物事を保留にするときに使います。

All About ニュースの解説は、ペンディングを「保留」「検討中」の意味とし、あくまで再開を前提にしたもので、完全に取りやめる「キャンセル」とは違うと説明しています。マイナビエージェントのCANVASは、「先送りにします」と言うと「後回しにされた」と感じる人もいるため、角の立たない言い方としてペンディングが使われると説明しています。

ただ、角が立たないぶん、本当の見込みは伝わりにくくなります。All About ニュースは、ペンディングに後ろ向きな印象を持つ人もいるので多用しないこと、保留にしたら必ず後でフォローすることを注意点に挙げています。言う側の「再開を前提にした一時的な保留」と、聞く側の「事実上の見送り」がずれやすく、とくに再開の時期が示されないときに取り違えが起きます。

あなたは「ペンディング」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    未決定・係属中

    英語の pending の意味どおり、まだ決まっていない状態を指します。「ペンディング中の業務」のように使います。

  2. 拡張広がった使い方

    再開を前提にした保留

    職場でいちばん多い使い方です。確認待ちや予算待ちで、いったん作業を止めることを指します。

  3. 誤用寄り出典から離れた使い方

    やんわりした見送り

    再開の予定がないのに「ペンディング」と言って、断りや中止を和らげる使い方です。解説記事は「中止」の意味で使わないよう注意しています。

語源・成り立ち

英語の pending は、「未決定の」「係属中の」という形容詞のほか、「…まで」「…を待つ間」という前置詞としても使われます。英和辞典には pending tray（未決書類の入ったトレー）、pending lawsuit（係争中の訴訟）といった言い方が載っています。

日本語では、決まっていない案件や止まっている作業を指すビジネス用語として使われています。いつごろから使われ始めたかは、確かめられる資料が見つかっていません。

広まった経緯

  1. 不明

    英語の pending を取り入れた「ペンディング」が、職場で「保留」の意味で使われ始める。

  2. 2024年

    All About ニュースが「ペンディング」の意味を解説。キャンセルやリスケとの違い、「中止」の意味で使わない注意を説明する。

  3. 2025年

    マイナビエージェントのCANVASが、「保留」「先送り」の角を和らげる言い方としてペンディングを解説する。

ズレのポイント

再開の目安を添える

「ペンディングで」だけでは、相手は立ち消えになったのかと心配します。「来月の予算が決まったら再開します」のように、何を待っているのかと目安の時期を添えます。

中止なら中止と言う

続ける予定がないのにペンディングと言うと、相手は待ち続けることになります。取りやめるなら「中止」「見送り」とはっきり伝えるほうが親切です。

こちらの都合で止めるときは言い換える

All About ニュースは、自社の都合で取引先に「ペンディングで」と言うのは印象がよくないことがあるとし、「休止をお願いできませんでしょうか」と丁寧な日本語を勧めています。

多様な観点

言う側から

「やめる」と言わずに済み、決めきれない状況を正直に表せる言葉です。保留にした本人は、まだ続けるつもりでいることがほとんどです。

言われる側から

いつ再開するかが分からないまま待つのは負担です。ペンディングが長引くと、事実上の中止だったと後から気づくこともあります。

事務・法律から

英語の pending は、裁判では「係属中」、書類では「未決」を表します。終わっていないが、処理を待っている状態という意味がもとにあります。

使用シーン

会社の会議、プロジェクト管理、取引先とのやりとりでよく使われます。タスク管理の道具で、止まっている作業の状態の名前として使われることもあります。

関連語

  • リスケ日程を組み直すこと。ペンディングと違い、進めることは決まっている。
  • 前向きに検討はっきり断らない言い方。ペンディングと同じく、本当の見込みが読み取りにくい。
  • オンスケ予定どおりに進んでいること。ペンディングの反対の状態。
