曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

エンパワーメントは、英語の empowerment から来た言葉です。デジタル大辞泉は、最初の意味を「権限を与えること」としています。あわせて、人々が協力し、自分のことは自分の意思で決めながら生きる力を身につけていく考え方や、組織でメンバーに権限を委ね、自分から目標を目指してもらう考え方も載せています。

ブリタニカ国際大百科事典によると、この言葉は1980年代の女性の権利を求める運動の中で使われるようになりました。福島県の男女共同参画の用語解説は、「力をつけること」と訳し、社会の中で奪われてきた本来の力を取り戻すことだと説明しています。一方、会社の人事の話では、上司が部下に権限を任せる「権限委譲」の意味で使われることが多くなっています。

同じ言葉でも、会社では上司が部下に「力を与える」話になり、社会の運動では本人が「力をつける」話になります。誰かが権限を「与える」のか、本人が自分で力を「つける」のか。どちらが主語なのかが、使う場面によって入れ替わります。

あなたはどの意味派？

あなたは「エンパワーメント」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    権限を与える

    英語の empower の「権限を与える」「力を持たせる」という意味どおりの使い方です。辞書でも最初に挙げられています。

  2. 拡張広がった使い方

    本来の力を取り戻す

    女性の権利を求める運動や男女共同参画の分野で、差別の中で奪われてきた力を、本人が意識と能力を高めて取り戻すことを指します。

  3. 拡張広がった使い方

    住民が自分で力をつける

    国際協力や開発の分野で、住民が自分たちの力で貧困から抜け出せるようにすることを指します。外から助けるだけでなく、本人の力を育てる考え方です。

  4. 拡張広がった使い方

    部下に任せる

    会社では、上司が持っていた権限を部下に任せ、自分で判断して動けるようにすることを指します。「エンパワーメント型のマネジメント」のように使われます。

語源・成り立ち

英語の empower は、「権限を与える」「力を持たせる」という意味の動詞です。名詞の empowerment が、そのままカタカナで使われています。

ブリタニカ国際大百科事典は、1980年代の女性の権利を求める運動の中で使われるようになった言葉で、対象が広がりつつあると説明しています。企業の経営では従業員が経営に参加して生産性を高める意味で、開発政策では住民自身に貧困から抜け出す力をつけてもらう意味で使われるようになりました。1995年に北京で開かれた第4回世界女性会議では、女性のエンパワーメントが主要な課題になりました。

広まった経緯

  1. 1980年代

    女性の権利を求める運動の中で使われるようになる（ブリタニカ国際大百科事典）。

  2. 1995年

    北京で開かれた第4回世界女性会議で、女性のエンパワーメントが主要な課題になる。

  3. 2010年3月

    国連グローバル・コンパクトなどが「女性のエンパワーメント原則（WEPs）」をまとめる。企業が女性の活躍に取り組むための原則として、日本でも紹介される。

  4. 現在

    人事や経営の場で「権限委譲」の意味で使われる一方、福祉や男女共同参画の場では「力をつけること」の意味で使われている。

ズレのポイント

「任せた」だけでは伝わらない

上司が「エンパワーメントのつもりで任せた」と思っていても、部下は判断の材料も相談先もないまま放っておかれたと感じることがあります。何をどこまで任せるのかを決めておかないと、ずれが起きやすくなります。

「与える」側の言葉になっていないか

男女共同参画や福祉の分野では、本人が自分の力を取り戻すことに重きがあります。「女性をエンパワーしてあげる」のように、上から与える言い方をすると、もともとの考え方と逆の印象を与えることがあります。

女性だけの言葉ではない

女性の権利の運動から広まった言葉ですが、ブリタニカ国際大百科事典は、いまは対象が広がりつつあると説明しています。障害のある人、地域の住民、会社の社員など、誰の力の話なのかを確かめると、ずれが起きにくくなります。

多様な観点

人事・経営から

人事の用語としては、上司の権限を部下に任せ、自分で考えて動いてもらう「権限委譲」の意味で使われます。任せる範囲と責任の線引きが、話の中心になります。

男女共同参画から

女性が自分で意識と能力を高め、政治・経済・社会のさまざまな場で力を持つことを指します。誰かから与えられるものではなく、本人が取り戻すものとして語られます。

国際協力・福祉から

開発や福祉の分野では、支援する側が何でもしてしまうのではなく、住民や利用者が自分で決め、自分で動ける力を育てることを指します。

使用シーン

会社の人事やマネジメントの研修、女性活躍や男女共同参画の計画、国際協力や福祉の現場で使われます。同じ会議の中でも、人事の人と福祉の人では指しているものが違うことがあります。

関連語

  • 心理的安全性組織の中で一人ひとりが動きやすくなる条件として、並べて語られる言葉。
  • 多様性女性の活躍や包摂の話で、エンパワーメントと一緒に使われる言葉。
  • パーパス英語から入り、経営や人事の場で広く使われるようになった言葉。
