『「ひとだんらく」か「いちだんらく」か。片づいたのか、ひと区切りか。』

いちだんらく【一段落】〔名〕

  1. ①

    もともとの意味文章の一つの段落。文章の、まとまった一部分のことです。

  2. ②

    もともとの意味物事が一応かたづくこと。「事件もこれで一段落がついた」のように、ひとまず区切りがついて落ち着くことです。

  3. ③

    すっかり終わること。「案件が一段落したので、次に移ります」のように、完全に終わった意味で受け取られることもあります。

→オンスケ・落としどころ・なる早

曖昧メーター

曖昧度2/5

人によってその言葉の意味がどれだけ変わるか

誤用度4/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

物事が一応かたづくこと、ひと区切りつくことを表す言葉です。「仕事が一段落したらお茶にしよう」のように使います。もとは文章の一つの段落を指し、そこから物事の区切りの意味になりました。

辞書の読みは「いちだんらく」です。デジタル大辞泉は「ひとだんらく」と読むのは誤りだとしたうえで、話し言葉では使われることも多いと書いています。All About ニュースが2023年に500人に聞いたアンケートでは、「ひとだんらく」と読む人が75.2％、「いちだんらく」が24％でした。「一安心」「一苦労」のように「ひと＋漢語」の言葉が多いことが、広まった理由として挙げられています。

意味にも小さなずれがあります。辞書は「一応かたづくこと」と説明しており、続きがあることを含んでいます。話す人は「ひとまず区切りがついた」つもりで言い、聞く人は「もう終わった」と受け取ることがあります。読み方と、どこまで片づいたのかの両方が、人によってずれる言葉です。

あなたはどの意味派？

あなたは「一段落」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    文章の一つの段落

    文章の、まとまった一部分のことです。「第一段落」と同じく、段落を一つと数える使い方です。

  2. 原義もともとの意味

    物事が一応かたづくこと

    「事件もこれで一段落がついた」のように、ひとまず区切りがついて落ち着くことです。

  3. 拡張広がった使い方

    すっかり終わること

    「案件が一段落したので、次に移ります」のように、完全に終わった意味で受け取られることもあります。

語源・成り立ち

「段落」は文章の切れ目やまとまりのことで、「一段落」はその一つ分を指しました。そこから、物事のひと区切りの意味が生まれました。精選版 日本国語大辞典は、織田純一郎訳『花柳春話』（1878〜79年）の「説教将さに一段落ならんとする頃は」を用例に挙げています。夏目漱石の『行人』（1912〜13年）には「一段落（イチダンラク）」とルビを振った例があり、ひとまとまりの時間という意味で使われています。

「ひとだんらく」という読みについて、ジャパンナレッジの連載「日本語、どうでしょう？」（2011年）は、話し言葉で次第に増えてきていると書いています。『明鏡国語辞典』は初版で「ひとだんらく」を同義語として載せましたが、第2版（2010年）では「『いち段落』が本来」とする書き方に改めました。同じ連載は、新聞や放送では「ひとだんらく」を認めていないとも説明しています。

広まった経緯

  1. 1878〜79年

    『花柳春話』（織田純一郎訳）に「一段落」が、物事の区切りの意味で使われる（日本国語大辞典）。

  2. 1912〜13年

    夏目漱石『行人』に「一段落（イチダンラク）」とルビ付きで出てくる。

  3. 2010年

    『明鏡国語辞典』第2版が、初版で同義語としていた「ひとだんらく」の扱いを改め、「いち段落」が本来とする。

  4. 2011年

    ジャパンナレッジの連載が、「ひとだんらく」と言う人が増えていると取り上げる。

  5. 2023年

    All About ニュースの500人アンケートで、「ひとだんらく」派が75.2％になる。

ズレのポイント

改まった場では「いちだんらく」

会話で「ひとだんらく」と言っても通じますが、辞書の見出しは「いちだんらく」です。アナウンスや面接、人前での発表では「いちだんらく」と読むほうが安心です。

「一段落ついた」はまだ続きがある

辞書の説明は「一応かたづくこと」です。仕事を完全に終えたことを伝えたいなら「完了しました」「終わりました」と言うほうが、相手に誤解されません。

「ひと段落」と書くこともある

話し言葉の読みに合わせて「ひと段落」と書く例も見かけます。辞書の書き方ではないので、文書では「一段落」と書くのが無難です。

多様な観点

辞書から

デジタル大辞泉は「ひとだんらく」の項目を立て、「いちだんらく」の誤読と書いています。誤りとしながらも見出しに載せているのは、それだけ多くの人がそう読むからです。

読み方の決まりから

音読みの熟語に「一」が付くと「いち」と読むのが基本で、「一大事」「一目散」も「いち」です。ただ「一安心」「一工夫」のように「ひと」と読む言葉も多く、迷いやすくなっています。

職場から

「一段落したら連絡します」は、相手によって「少し手が空いたら」とも「全部終わったら」とも聞こえます。急ぎの用件なら、いつごろかを添えると行き違いが減ります。

使用シーン

職場の会話やメール、家事や子育ての話など、世代を問わず日常的に使われます。読み方は、会話では「ひとだんらく」、ニュースや改まった場では「いちだんらく」と分かれやすい言葉です。

関連語

  • オンスケ予定どおりに進んでいること。仕事の進み具合を伝える点で近い。
  • 落としどころ話し合いをまとめる着地点。区切りをつける場面で使う。
  • なる早なるべく早く。「一段落したら」と並んで、時期のあいまいな言い方の代表。
