曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度5/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

「さわり」は、話や曲の中でいちばんの見どころ・聞きどころを指す言葉です。辞書では、話や文章の中で最も感動的な部分、印象的な部分と説明されています。「話のさわりだけ聞かせる」は、本来は「話の肝心なところだけを聞かせる」という意味になります。

ところが、いまは「話の最初の部分」「出だし」の意味で使う人のほうが多くなっています。文化庁の「国語に関する世論調査」では、2016年度（平成28年度）に「最初の部分」を選んだ人が53.3%、本来の「要点」を選んだ人は36.1%でした。

「さわりだけ話すね」と言われて、相手は冒頭だけで終えるつもりなのか、いちばん大事なところを話すつもりなのか。本来の「聞かせどころ・要点」と、広まった「出だし」。同じ言い方で、話の別の場所を指しています。

あなたはどの意味派？

あなたは「さわり」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    曲の聞かせどころ

    義太夫節などで、一曲の中のいちばんの聞きどころを指します。そこから、芸能の見どころ・聞きどころ全般に使われるようになりました。

  2. 拡張広がった使い方

    話の要点・山場

    「小説のさわりを読んで聞かせる」のように、話や文章の中心になる部分、心に残る部分を指す使い方です。辞書が載せている意味です。

  3. 誤用寄り出典から離れた使い方

    話の出だし

    「さわりだけ説明します」を「最初のほうだけ説明します」の意味で使う言い方です。調査では、この意味で受け取る人が多数派になっています。

語源・成り立ち

動詞「触る（さわる）」から来た言葉です。もとは義太夫節の用語で、義太夫節以外の流派の節（ふし）に「触る」、つまりほかの流派の節回しを取り入れた部分を指しました。

その部分は曲の中で目立つ聞かせどころになることが多かったため、やがて一曲の中のいちばんの聞きどころを「さわり」と呼ぶようになり、芸能全般、さらに話や文章の山場へと意味が広がりました。三味線の弦が棹に触れて出す独特の音も「さわり」と呼ばれ、こちらも「触る」から来ています。

広まった経緯

  1. 江戸時代

    義太夫節で、ほかの流派の節を取り入れた部分を「さわり」と呼ぶ。のちに一曲の聞かせどころを指すようになる。

  2. 2003年度

    文化庁「国語に関する世論調査」で、「話のさわりだけ聞かせる」を「最初の部分」の意味で受け取る人が59.3%、「要点」が31.1%となる。

  3. 2007年度

    同じ調査で、「最初の部分」が55.0%、「要点」が35.1%。

  4. 2016年度

    同じ調査で、「最初の部分」が53.3%、「要点」が36.1%。本来の意味を選ぶ人は少しずつ増えているが、逆転したままになっている。

ズレのポイント

「さわり＝冒頭」ではない

辞書の上では、さわりは話の中心になる部分や、いちばん印象に残る部分です。「最初の部分」の意味は、辞書では本来の意味ではないとされています。

歌の「さわり」はサビに近い

「その曲のさわりを歌って」と言われたら、本来はイントロではなく、いちばん盛り上がるところを歌うことになります。歌謡曲でいうサビに近い部分です。

仕事では言い換えると安全

「概要だけ」「冒頭だけ」「要点だけ」のように言い換えると、相手との取り違えを防げます。どちらの意味で受け取られるか分からない場面では、さわりを使わないのも一つの方法です。

多様な観点

芸能から

義太夫節や三味線の世界では、いまも「さわり」は専門の言葉として使われています。聞かせどころの意味のほか、三味線の弦が棹に触れて出る、うなるような音色もさわりと呼ばれます。

日本語の調査から

文化庁の調査では、2003年度、2007年度、2016年度と繰り返し取り上げられています。本来の意味を選ぶ人は31.1%から36.1%へと少しずつ増えましたが、「最初の部分」を選ぶ人のほうがまだ多い状態です。

言葉のしくみから

「さわる」には「軽く触れる」という意味もあるため、「少しだけ触れる」＝「最初のほうだけ話す」と受け取られやすいと考えられます。語の成り立ちを知らないと、出だしの意味のほうが自然に感じられる言葉です。

使用シーン

世代を問わず、会議、プレゼン、雑談、音楽の話題で使われます。誤用の例として、国語の授業や日本語のクイズでもよく取り上げられます。

関連語
