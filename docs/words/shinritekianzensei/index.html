曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度4/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

チームの中で、質問、反対意見、失敗の報告などをしても、ばかにされたり罰せられたりしないと、メンバーが信じられている状態のことです。ハーバード・ビジネス・スクールのエイミー・エドモンドソン教授が、1999年の論文で示した概念です。

Googleが社内のチームを調べた「プロジェクト・アリストテレス」で、成果を出すチームに共通する最も重要な要素とされたことから、日本の企業にも一気に広まりました。

ところが、「優しい職場」「怒られない雰囲気」「仲がいいチーム」のことだと受け取られることが多く、厳しいことを言わない「ぬるま湯」と混同されがちです。本来は、言いにくいことでも率直に言い合える状態を指します。

あなたはどの意味派？

あなたは「心理的安全性」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    率直に意見や失敗を言える状態

    反対意見、疑問、ミスの報告などを、対人関係のリスクを気にせずに口にできると、チームの皆が感じている状態です。

  2. 拡張広がった使い方

    働きやすい・居心地のいい職場

    「心理的安全性の高い会社」のように、人間関係が良好で働きやすい職場全般を指す使い方です。

  3. 誤用寄り出典から離れた使い方

    厳しいことを言わない・ぬるま湯

    注意や指摘をしないこと、何でも許されることを「心理的安全性」と呼ぶ使い方です。本来の意味とは逆に、率直な意見を言いにくくする方向に働きます。

  4. 誤用寄り出典から離れた使い方

    自分を守る盾としての使用

    指摘を受けたときに「心理的安全性が損なわれた」と言い、意見そのものを封じる使い方です。

語源・成り立ち

英語の psychological safety の訳語です。エドモンドソン教授は、1999年の論文で家具メーカーのチームを調べ、「チームは対人関係のリスクを取っても安全だ」という共有された信念として定義しました。

日本では、2016年ごろにGoogleの「プロジェクト・アリストテレス」の結果が紹介されたことで広く知られるようになりました。

広まった経緯

  1. 1999年

    エイミー・エドモンドソン教授が、チームの学習行動と心理的安全性についての論文を発表する。

  2. 2012〜2016年

    Googleが社内の180のチームを調べる「プロジェクト・アリストテレス」を行い、心理的安全性が最も重要な要素だと発表する。

  3. 2010年代後半〜

    日本の企業の研修や人事施策で取り上げられ、ビジネス用語として定着する。「ぬるま湯との違い」も繰り返し解説されるようになる。

ズレのポイント

「仲がいい」とは違う

仲がよくても、反対意見を言うと空気が悪くなるチームは、心理的安全性が高いとは言えません。むしろ、率直な議論や対立が起きても関係が崩れないことが大切です。

「厳しさがない」ことではない

エドモンドソン教授は、心理的安全性が高く、成果への要求も高い状態を目指すべきだとしています。心理的安全性が高くても要求が低ければ、居心地のいい「ぬるま湯」になってしまいます。

個人の気持ちではなく、チームの状態

心理的安全性は、ある一人が安心しているかどうかではなく、チーム全体で共有されている感覚を指します。「私の心理的安全性が」と個人の感情に使うと、もとの概念からずれます。

多様な観点

組織論から

心理的安全性が高いチームでは、ミスが早く報告され、学習や改善が進みやすいとされています。医療や航空など、ミスの報告が命に関わる分野でも重視されています。

日本の職場文化から

空気を読むことが重んじられる日本の職場では、反対意見を言いにくい雰囲気があるとされ、心理的安全性が特に必要だと語られます。一方で、「優しさ」と訳されてしまいやすい土壌もあります。

言葉の受け止め方から

「心理」「安全」という言葉の響きから、守られる、傷つかない、という意味に引っ張られやすい言葉です。英語の safety にも「傷つかない」の感覚はありますが、本来は「挑戦しても安全」という意味に重点があります。

使用シーン

企業の経営者、管理職、人事担当者を中心に使われます。研修、ビジネス書、ニュースでもよく見かける言葉です。

関連語

  • ゆるブラック働きやすいが成長できない職場を指す言葉。ぬるま湯と心理的安全性の混同と関わる。
  • 静かな退職最低限の仕事だけをこなす働き方。職場の雰囲気と結びつけて語られる。
  • ウェルビーイング心身ともに満たされた状態。働きやすさの文脈で並べて語られる。
