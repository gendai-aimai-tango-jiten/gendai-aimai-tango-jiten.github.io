曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

「サステナブル」は英語の sustainable をカタカナにした言葉で、「持続可能な」と訳されます。デジタル大辞泉は「持続可能であるさま」と説明し、とくに地球環境を保ちながら続けられる産業や開発などについて使う、としています。「サステナブルな素材」「サステナブルファッション」のように、環境への負担が少ないことを表すのが中心の使い方です。

もとになったのは「持続可能な開発」という考え方です。国連の委員会が1980年代に打ち出したもので、将来の世代が必要とするものを損なわずに、いまの世代の必要を満たす開発を指します。環境だけでなく、貧しさをなくすことや経済の続け方も含んだ考え方でした。2015年に国連でSDGs（持続可能な開発目標）が採択されると、日本でも企業や学校で「サステナブル」を目にすることが増えました。

一方で、「サステナブルな働き方」「この節約はサステナブルじゃない」のように、環境とは関係なく「無理なく続けられる」という意味でも使われています。地球環境や将来の世代のための「持続可能」なのか、自分や組織が「続けられる」という意味なのか。同じ言葉で、話の大きさがまったく違うことがあります。

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    環境を壊さずに続けられる

    「サステナブルな漁業」「サステナブルな素材」のように、資源を使い果たさず、環境への負担を抑えながら続けられることです。辞書の説明の中心にある使い方です。

  2. 原義もともとの意味

    社会や経済も含めて持続可能

    「サステナブルな社会」のように、環境だけでなく、暮らしや経済、人権まで含めて将来も続けられることを指します。SDGsの考え方に沿った使い方です。

  3. 拡張広がった使い方

    環境にやさしい、エコ

    「サステナブルな商品」のように、「環境にやさしい」「エコ」とほぼ同じ意味の売り文句として使われます。何がどう持続可能なのかは示されないこともあります。

  4. 拡張広がった使い方

    無理なく続けられる

    「サステナブルな働き方」「サステナブルなダイエット」のように、体や心、お金に無理がなく、長く続けられることを指します。環境とは関係のない使い方です。

語源・成り立ち

英語の sustainable は、「支える、持ちこたえる」という意味の sustain に、「〜できる」の -able が付いた言葉です。日本語では「持続可能な」と訳されます。「サステイナブル」「サスティナブル」と書くこともあります。

環境の分野で広く使われるようになったのは、1987年に国連の「環境と開発に関する世界委員会」が報告書『Our Common Future』（委員長の名前からブルントラント報告とも呼ばれます）で、「持続可能な開発」を中心の考え方にしてからです。2015年9月には、国連サミットで「持続可能な開発のための2030アジェンダ」が採択され、その中にSDGsの17の目標が書かれました。

広まった経緯

  1. 1987年

    国連の「環境と開発に関する世界委員会」の報告書『Our Common Future』が「持続可能な開発」を打ち出す。

  2. 2015年9月

    国連サミットで「持続可能な開発のための2030アジェンダ」が採択され、SDGsの17の目標が示される。

  3. 2010年代後半〜

    企業の発表や商品、学校の授業などで「サステナブル」「サステナビリティ」をよく見かけるようになる。

  4. 近年

    「サステナブルな働き方」のように、環境と関係なく「無理なく続けられる」の意味でも使われる。

ズレのポイント

「エコ」だけではない

もとの「持続可能な開発」は、環境を守ることと、貧しさをなくすことや経済を続けることを、あわせて考える言葉でした。「サステナブル」を「環境にやさしい」だけの意味で受け取ると、もとの考え方の半分が抜け落ちます。

何が続けられるのかが抜けやすい

「サステナブルな商品」と言われても、材料のことか、作る人の働き方のことか、捨てたあとのことかは、言葉だけでは分かりません。売り文句として使われるときは、中身を確かめる必要があります。

個人の「続けられる」と混ざる

「サステナブルな働き方」は、本人が疲れ切らずに続けられることを指すことが多く、地球環境とは関係がありません。どちらの意味かを取り違えると、話がかみ合わなくなります。

多様な観点

国際社会から

国連やSDGsの文脈では、環境・社会・経済の3つをあわせて、将来の世代も困らないようにすることを指します。一つの面だけがよくても「持続可能」とは言いません。

企業から

企業の報告書やウェブサイトでは「サステナビリティ」として、環境への取り組みや人権、働き方などをまとめて示す言葉になっています。範囲が広いぶん、何を指しているかは会社ごとに違います。

日常から

暮らしの中では、「長く続けられる」「無理がない」くらいの意味で使う人が増えています。環境の話をしているつもりの人と、生活の続けやすさの話をしている人とで、すれ違うことがあります。

使用シーン

企業の報告書や広告、ファッションや食品の売り場、学校の授業でよく使われます。SNSや雑誌では、働き方や暮らし方の話にも出てきます。

関連語

  • パーパス企業が社会の中での役割を語るときに、一緒に使われることの多い言葉。
  • ウェルビーイング人の心と体、暮らしがよい状態であることを指し、「続けられる働き方」の話でよく並ぶ言葉。
  • 多様性SDGsや企業の取り組みの中で、よく並べて使われる言葉。
