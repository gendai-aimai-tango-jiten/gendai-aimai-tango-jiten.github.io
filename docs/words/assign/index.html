曖昧メーター

曖昧度3/5

誤用度2/5

どういう意味？

アサインは、英語の assign から来た言葉です。デジタル大辞泉は「物事を割り当てること。あてがうこと。また、任命すること」と説明しています。

会社では、「新しい案件に佐藤さんをアサインする」のように人をプロジェクトに配置する使い方と、「このタスクを田中さんにアサインした」のように作業を担当者に割り振る使い方の両方があります。研修や人材育成の場では、「ストレッチアサインメント」のように、成長のために少し難しい仕事を任せることを指す言葉も使われています。

「この件、あなたにアサインしたので」と言われたとき、頼まれたのは作業一つなのか、その件の責任者になったのか。仕事を「割り当てる」ことと、人を役目に「任命する」こと。どちらで言ったかによって、受けた人が背負う範囲がずれます。

あなたはどの意味派？

あなたは「アサイン」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    割り当てる・あてがう

    「部屋をアサインする」「予算をアサインする」のように、物や仕事を決まった先に割り当てることです。

  2. 原義もともとの意味

    任命する

    「プロジェクトリーダーにアサインされた」のように、人をある役目に就けることを表します。

  3. 拡張広がった使い方

    人をプロジェクトに配置する

    コンサルティング会社や IT 企業などで、社員をどの案件に入れるかを決めることを指します。「次のアサイン先」のように、名詞でも使われます。

  4. 拡張広がった使い方

    作業の担当者を決める

    タスク管理の道具で、作業ごとに担当者を決めることも「アサイン」と呼ばれます。作業一つの担当で、責任者の任命とは限りません。

語源・成り立ち

英語の assign は、「割り当てる」「指定する」「任命する」などの意味を持つ動詞です。名詞は assignment で、「割り当てられた仕事」「任務」の意味になります。

日本語の「アサイン」は、この動詞に「する」を付けて「アサインする」と使います。会社の中で人や仕事の配置を表す言葉として使われ、「ストレッチアサインメント」「ジョブアサインメント」のように名詞の形を使った言葉もあります。

広まった経緯

  1. もとは

    英語の assign（割り当てる、任命する）が外来語として入る。

  2. 現在

    会社の会議やプロジェクト管理で、人の配置や作業の割り振りを表す言葉として使われている。デジタル大辞泉は「割り当てること」「任命すること」の両方を載せている。

ズレのポイント

何を任されたのかを確かめる

「アサインした」とだけ言われると、作業一つなのか、案件全体の担当なのかが分かりません。範囲と期限、誰に報告するかを一緒に確かめると安心です。

社外や年上の人には言いかえる

カタカナの仕事の言葉に慣れていない人もいます。社外の人や、業界の違う人には「担当をお願いする」「担当に決まった」と言ったほうが伝わります。

「アサインされる」の受け止め方

同じ「アサインされた」でも、望んで選ばれたと受け取る人と、押し付けられたと受け取る人がいます。頼む側は、なぜその人に任せたのかを添えると伝わりやすくなります。

多様な観点

人事・育成から

人材育成では、どの仕事を誰に任せるかが成長に関わると考えられています。「ストレッチアサインメント」は、少し難しい仕事を任せて伸ばす方法の名前です。

プロジェクト管理から

タスク管理の道具では、作業ごとに担当者を一人決める機能を「アサイン」と呼ぶことがあります。ここでのアサインは作業の担当で、案件の責任者を決めることとは別です。

任された側から

「アサインされた」と言われた人は、期待されていると感じることも、負担が増えたと感じることもあります。任せる側の言い方で、受け止め方が変わります。

使用シーン

コンサルティング会社や IT 企業、広告会社などのプロジェクトの場、人事の話、タスク管理の道具の中でよく使われます。ホテルや旅行の業界では、部屋や座席の割り当ての意味で使われることもあります。
