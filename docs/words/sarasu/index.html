曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

「晒す（曝す）」は、日光や風に当てる、布を白くする、野菜のあくを水で抜く、といった意味を持つ言葉です。そこから、「恥を晒す」のように「広く人目に触れるようにする」という意味でも使われてきました。

ネットでは、他人の名前や顔写真、住所、メッセージのやりとりなどを、本人に断りなく投稿して広める行為を「晒す」と言います。迷惑な客や失礼なメッセージを「晒して」注意を呼びかける投稿もあれば、特定の人を攻撃するために個人情報を広めるものもあります。

投稿する側は「みんなに知らせる」「注意を呼びかける」つもりでも、晒された側にとっては、消えにくい形で個人の情報が広まることになります。人目に出して知らせることと、個人を見せしめにすること。どこまでを「晒す」と呼ぶかは、使う人や立場によってずれています。

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    日や風、水に当てる

    「布団を日に晒す」「ごぼうを水に晒す」のように、日光や風、水に当てておくことです。布を白くする「晒し木綿」も、ここから来ています。

  2. 拡張広がった使い方

    人目に触れさせる

    「恥を晒す」「醜態を晒す」のように、見られたくないものを広く人の目に触れるようにすることです。「危険に身を晒す」のように、好ましくない状況に置く意味もあります。

  3. 拡張広がった使い方

    ネットで個人の情報を広める

    他人の名前、写真、住所、メッセージなどを本人の同意なく投稿して広めることです。自分の失敗談や昔の写真を、自分から「晒す」と言う軽い使い方もあります。

  4. 誤用寄り出典から離れた使い方

    正しい告発・注意喚起と同じ扱い

    迷惑行為の注意喚起のつもりで、相手を特定できる情報まで投稿することがあります。目的が正しくても、名誉やプライバシーの侵害にあたることがあり、「晒す」と「知らせる」の線引きがあいまいになりやすい使い方です。

語源・成り立ち

「さらす」は奈良時代から使われている古い言葉で、『万葉集』には、多摩川で手作りの布をさらす様子を詠んだ歌があります。布を水で洗い、日に当てて白くすることが、もとの使い方の一つでした。

「広く人目に触れるようにする」という意味も古く、辞書では『竹取物語』の用例が挙げられています。江戸時代には、罪人を道ばたに縛っておいたり、首を人目にさらしたりする「晒し」という刑罰があり、見せしめの意味合いも持つようになりました。ネットで他人の情報を「晒す」という言い方は、この「人目にさらす」の意味を受け継いだものです。

広まった経緯

  1. 8世紀

    『万葉集』に、多摩川で布をさらす様子を詠んだ歌が載る。

  2. 9〜10世紀

    『竹取物語』に、「人目に示す」という意味の「さらす」の用例が見られる。

  3. 江戸時代

    罪人を人目にさらして見せしめにする「晒し」が、刑罰の一つとして行われる。

  4. 2022年7月

    ネット上の誹謗中傷への対応として、侮辱罪の法定刑が引き上げられる。

  5. 2025年4月

    プロバイダ責任制限法が改正され、「情報流通プラットフォーム対処法」として施行される。大規模なSNSなどに、削除の申し出への速やかな対応が求められるようになる。

ズレのポイント

注意喚起でも違法になることがある

迷惑な相手を知らせるつもりの投稿でも、名前や顔、住所など本人を特定できる情報を載せると、名誉やプライバシーの侵害になることがあります。目的が正しいかどうかと、投稿が許されるかどうかは別の問題です。

一度広まると消しにくい

ネットに出た情報は、コピーやスクリーンショットで広がり、元の投稿を消しても残ることがあります。「晒す」は、相手の情報を長く人目に触れる状態に置くことでもあります。

自分のことを晒すのは別の話

「昔の写真を晒します」のように、自分のことを自分で公開する場合にも「晒す」が使われます。他人の情報を本人の同意なく広めることとは、意味も重さも違います。

多様な観点

法律から

法務省は、ネット上の人権侵害として、誹謗中傷、名誉やプライバシーの侵害を挙げています。書き込んだ人が罪に問われることもあり、被害を受けた人は、SNSの運営会社などに削除を求めたり、書き込んだ人の情報の開示を請求したりできます。

SNSから

SNSでは、失礼なメッセージや迷惑行為を「晒す」投稿が、共感を集めて広く拡散されることがあります。一方で、晒された内容が誤解だった場合や、関係のない人が特定された場合、取り返しのつかない被害が出ることもあります。

言葉から

江戸時代の「晒し」は、罪人を見せしめにする刑罰でした。ネットの「晒す」にも、悪いことをした人をみんなの前に出して罰する、という見せしめの響きが残っています。投稿する人が自分を正しい側に置きやすい言葉だとも言えます。

使用シーン

世代を問わず、SNSや掲示板、ネットのニュースで使われます。自分の失敗や昔の写真を「晒す」という軽い使い方は、若い世代のSNSでよく見られます。
