曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度2/5

他の世代や別の界隈にも通じるか

どういう意味？

困難やストレス、予想外の変化に直面しても、しなやかに対応し、回復し、立ち直っていく力のことです。英語の resilience（弾力、回復力）から来ています。

もとは物理学で、物体が外から力を受けて変形しても、もとの形に戻る性質を表す言葉でした。そこから心理学で「逆境から立ち直る力」を表すようになり、さらにビジネスでは企業の危機対応力、防災では地域や社会の回復力を表す言葉として使われるようになりました。

個人の心の話なのか、組織の仕組みの話なのか、社会全体の話なのか。レジリエンスは、使う分野によって対象が大きく変わる言葉です。

あなたはどの意味派？

あなたは「レジリエンス」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    物体がもとに戻る性質

    物理学や工学で、外力を受けて変形した物体がもとの形に戻る性質のことです。「弾性」「復元力」と訳されます。

  2. 拡張広がった使い方

    逆境から立ち直る心の力

    心理学で、つらい出来事やストレスを経験しても、適応し、回復していく力を指します。

  3. 拡張広がった使い方

    組織の危機対応力

    ビジネスでは、災害や経済危機、市場の変化にあっても、事業を続け、立て直す企業の力を指します。

  4. 拡張広がった使い方

    社会や地域の回復力

    防災や環境の分野では、災害から地域社会が回復する力を指します。「レジリエントな街づくり」のように使われます。

語源・成り立ち

英語の resilience は、ラテン語の resilire（跳ね返る）に由来します。物理学の「弾力性」の意味から、20世紀後半に心理学で、逆境にあっても健全に育つ子どもの研究などを通じて「回復力」の意味で使われるようになりました。

日本では、東日本大震災後の防災の議論や、ビジネスの不確実性への対応、心の健康への関心の高まりとともに、2010年代から広く使われるようになりました。

広まった経緯

  1. 昔から

    物理学や工学で、物体の弾力性を表す言葉として使われる。

  2. 1970〜80年代

    心理学で、逆境に負けない子どもの研究などから、回復力を表す言葉として使われるようになる。

  3. 2010年代

    日本でも、防災、ビジネス、心の健康の分野で使われるようになり、研修のテーマにもなる。

ズレのポイント

「我慢強さ」ではない

レジリエンスは、つらさを我慢して耐え続ける力ではなく、一度へこんでも、しなやかに回復する力です。何にも動じない「鋼の心」とは違います。

個人の努力だけの問題ではない

心理学では、レジリエンスは周りの支えや環境によっても大きく左右されるとされます。「レジリエンスが低いのは本人のせい」と考えるのは、本来の考え方からずれています。

分野によって対象が違う

心の話をしている人と、企業の危機管理の話をしている人が同じ「レジリエンス」を使っていても、指しているものは違います。

多様な観点

心理学から

レジリエンスは生まれつき決まっているものではなく、人とのつながり、物事のとらえ方、生活習慣などによって育てられるものだと考えられています。

ビジネスから

予測しにくい時代に、変化に柔軟に対応し、立て直せる組織が強いとされ、企業経営のキーワードになりました。事業を止めないための計画（BCP）とも結びついて語られます。

防災から

災害を完全に防ぐのではなく、被害を受けても早く回復できる社会をつくる、という考え方を表す言葉として使われています。

使用シーン

企業の人事担当者、経営者、心理職、教育関係者、行政などで使われます。研修、ビジネス書、防災の資料などでよく見かけますが、日常会話ではまだあまり使われません。
