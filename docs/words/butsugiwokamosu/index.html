曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

「物議を醸す」は、世間の論議を引き起こすことです。「物議」は世の中の人々があれこれ言い合うこと、「醸す」はある状態を生み出すことを表します。「大臣の発言が物議を醸す」のように、ニュースでよく見かける言い方です。

辞書の説明は「論議を引き起こす」で、よい悪いは含んでいません。ただ、実際に使われるのは、発言や広告、決定などが批判を集めた場面がほとんどです。そのため、「物議を醸した」と聞くと、議論が起きたというより「たたかれた」と受け取る人もいます。

言い方もゆれています。文化庁の2011年度「国語に関する世論調査」では、「物議を醸す」を使う人が58.0%、「物議を呼ぶ」を使う人が21.7%でした。雰囲気を表す「醸し出す」と混ざった「物議を醸し出す」もよく見かけます。賛否の議論が起きたことなのか、批判を浴びたことなのか。さらに「醸す」「呼ぶ」「醸し出す」と、言い方そのものも人によって違います。

あなたはどの意味派？

あなたは「物議を醸す」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    世間の論議を引き起こす

    ある出来事や発言がきっかけで、世の中にいろいろな意見が出ることを表します。辞書が載せている意味です。

  2. 拡張広がった使い方

    批判を浴びる

    「不用意な発言が物議を醸した」のように、反発や非難を集めたことを、やわらげて伝える使い方です。報道では、この使い方がよく見られます。

  3. 誤用寄り出典から離れた使い方

    物議を醸し出す・物議を呼ぶ

    「醸し出す」は雰囲気などを自然に生み出すときの言葉で、辞書のクイズでは「物議を醸し出す」は誤りとされています。「物議を呼ぶ」は、文化庁の調査で本来の言い方ではないとされた形です。

語源・成り立ち

「醸す」は、こうじを発酵させて酒やしょうゆを造ることです。そこから、ある状態や雰囲気を生み出す、という意味が生まれました。「物議」は、世間の人々の議論やうわさを指します。

『日本国語大辞典』は、「物議を醸す」の早い用例として、明治4年（1871）7月の『新聞雑誌』8号の「大藩を存して小藩を廃するときは物議を醸し」を挙げています。辞書編集者の神永暁さんは、「物議を呼ぶ」も昭和のはじめの小説に例があり、「論議を呼ぶ」と混ざった形ではないか、と書いています。

広まった経緯

  1. 1871年

    『新聞雑誌』8号に「物議を醸し」の用例がある（『日本国語大辞典』）。

  2. 1902年

    正岡子規『病牀六尺』に「物議を起こす」の形の用例がある（『日本国語大辞典』）。

  3. 1935〜36年

    大佛次郎の小説に「物議を呼ぶ」の用例があると紹介されている。

  4. 2011年度

    文化庁「国語に関する世論調査」で、「物議を醸す」を使う人が58.0%、「物議を呼ぶ」を使う人が21.7%となる。

  5. 2019年

    デジタル大辞泉のクイズで「物議を醸し出した」は誤りかを問い、77%が正解する。

ズレのポイント

「醸し出す」とは組み合わせない

「醸し出す」は「温かい雰囲気を醸し出す」のように、気分や空気を自然に生み出すときに使います。辞書のクイズでは、「物議」と結びつくのは「醸す」だとしています。

悪い意味だけとは限らない

辞書の意味は「論議を引き起こす」で、批判とは書かれていません。話題作が賛否を呼んだときにも使えます。相手の仕事について「物議を醸しましたね」と言うと、批判されたと受け取られることがあるので、言い方に気をつけます。

「呼ぶ」「起こす」は誤りと言い切れない

「物議を呼ぶ」は文化庁の調査で本来の言い方ではないとされましたが、古い用例もあります。「物議を起こす」は『日本国語大辞典』が見出しに並べています。誤りと決めつけるより、改まった文章では「醸す」を使うと覚えておくと安心です。

多様な観点

日本語の調査から

2011年度の調査では、本来の言い方とされる「物議を醸す」を使う人が6割近くでした。「物議を醸し出す」は選択肢になく、どれくらい使われているかは調査からは分かりません。

報道の言葉から

ニュースでは、強い批判が起きたときにも「物議を醸す」がよく使われます。「批判を浴びる」と書くより角が立たないため、事実をやわらげて伝える言い方として選ばれやすい面があります。

辞書の見方から

デジタル大辞泉は意味を「世間の論議を引き起こす」とし、補足に文化庁の調査の数字を載せています。『日本国語大辞典』は「物議を醸す」と「物議を起こす」を一つの見出しにまとめています。

使用シーン

新聞やテレビのニュース、ネットの記事でよく使われます。日常の会話ではあまり使われず、書き言葉で見かけることが多い言い方です。

関連語

  • 炎上ネットで批判が集中すること。「物議を醸す」より強い言い方。
  • 晒す人目につく場所に出して、批判や笑いの的にすること。
  • 的を射る「的を得る」と言い方がゆれる、同じ型の言葉。
