曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

もともとは「時間にゆとりがある」「心のゆとり」のように、物ごとや気持ちに余裕があることを表す言葉です。良い意味で使われるのがふつうでした。

この言葉が教育の方針に使われ、「ゆとり教育」と呼ばれるようになりました。2002年度からの学習指導要領では、学習の内容が減らされ、学校の完全週5日制が始まりました。この教育を受けた世代を「ゆとり世代」と呼びます。デジタル大辞泉は、1987年以降、2004年ごろまでに生まれた世代と説明しています。

その後、「これだからゆとりは」のように、若い人の失敗や考え方をからかう言葉としても使われるようになりました。余裕があるという良い意味なのか、ある世代をまとめて見下す呼び名なのか。同じ「ゆとり」でも、言う人と場面で受け取り方が大きく変わります。

あなたはどの意味派？

あなたは「ゆとり」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    余裕があること

    「時間にゆとりを持つ」「家計にゆとりがある」のように、時間やお金、気持ちに余裕があることを表します。

  2. 拡張広がった使い方

    ゆとり教育

    詰め込みの教育を見直し、学習の内容を減らして、自分で考える力を育てようとした教育の方針です。

  3. 拡張広がった使い方

    ゆとり世代

    ゆとり教育を受けた世代を指す呼び名です。生まれ年の区切りは、資料によって違います。

  4. 誤用寄り出典から離れた使い方

    若い人をからかう呼び名

    「ゆとりだから仕方ない」のように、世代全体をまとめて「できない」と決めつける言い方です。言われた人を傷つけることがあります。

語源・成り立ち

「ゆとり」は、ゆったりとして余裕があることを表す、古くからある言葉です。

教育の言葉としては、1977年の学習指導要領の改定で「ゆとりと充実」がうたわれたのが始まりとされます。2002年度から実施された学習指導要領で、「総合的な学習の時間」の新設や学習内容の削減が行われ、「ゆとり教育」という呼び方が広まりました。学力の低下が問題になり、2008年の改定で方針が見直されています。

広まった経緯

  1. 1977年

    学習指導要領の改定で「ゆとりと充実」がうたわれる。

  2. 2002年度

    学習内容を減らした学習指導要領が実施され、学校の完全週5日制が始まる。

  3. 2008年

    学習指導要領が改定され、ゆとり教育からの転換が図られる。

  4. 2016年4月

    20〜28歳の働く男女688人への調査で、「ゆとり」と呼ばれるのは嫌だと答えた人が57.7％と報じられる。

ズレのポイント

「ゆとり」はもともと良い意味

「心にゆとりがある」はほめ言葉に近い言い方です。世代の呼び名としての悪い印象は、あとから付いたものです。

生まれ年だけで人を決めつけない

同じ教育を受けても、人によって考え方や力は違います。「ゆとりだから」と一人の失敗を世代のせいにすると、相手を傷つけるうえに、話の中身も見えなくなります。

世代の区切りは一つではない

「ゆとり世代」の生まれ年は、1987年4月〜1996年3月とする説明もあれば、2004年ごろまでとする辞書もあります。どこからどこまでかは、資料によって違います。

多様な観点

教育から

ゆとり教育は、詰め込みの教育や受験競争への反省から生まれた方針です。自分で考える力を育てようとした一方で、学力の低下を心配する声が強まり、見直されました。

職場から

ゆとり世代が社会に出たころ、「打たれ弱い」「指示を待つ」といった見方が広まりました。こうした見方には、世代でひとくくりにすることへの批判もあります。

当事者から

2016年の調査では、自分たちを「ゆとり」だと思う人が68.6％いた一方で、そう呼ばれるのが嬉しい人は9.5％でした。「使えないやつの隠語に聞こえる」という声もありました。

使用シーン

世代を問わず通じます。「ゆとりを持って」は日常やビジネスで広く使われ、世代の呼び名としての「ゆとり」は、職場の会話やネットの掲示板、SNSで見かけます。

関連語

  • Z世代ゆとり世代のあとに続く世代の呼び名。世代でひとくくりにする点が似ている。
  • 意識高い系ある人たちをからかい気味に呼ぶ言葉。呼ばれた側が嫌がることがある点で近い。
  • 生きづらさ世代や環境のせいにも本人のせいにもしきれない苦しさを表す言葉。
