じんてきしほん【人的資本】〔名〕

  1. ①

    もともとの意味教育や訓練で増える個人の力。経済学では、教育や職場での訓練を「人への投資」と考え、それによって身につく知識や技能を人的資本と呼びます。

  2. ②

    開示する人材の情報。「人的資本の開示」「人的資本経営」のように、会社が人材にどう投資しているかを、方針や数字で外に示すことを指す使い方です。

  3. ③

    出典から離れた使い方社員を大事にすることの言いかえ。「わが社は人的資本を重視しています」が、具体的な投資や数字の話をせずに「人を大切にしています」という意味だけで使われることがあります。

→ジョブ型・リスキリング・エンゲージメント・ウェルビーイング

曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

「人的資本」は、働く人が身につけた知識・技能・能力を、資本とみなしていう言葉です。デジタル大辞泉は、教育・訓練・経験によって個人に蓄積され、労働生産性の向上や賃金の上昇などに影響を与えるもの、と説明しています。機械や建物と同じように、お金や時間をかければ価値が増える、という見方から生まれた経済学の考え方です。

この言葉がビジネスの場で広く聞かれるようになったのは、2020年代に入ってからです。2022年8月、内閣官房は「人的資本可視化指針」を公表しました。金融庁は2023年1月に内閣府令を改め、2023年3月31日以後に終わる事業年度の有価証券報告書から、人材育成の方針や社内環境整備の方針、それに関する指標を書くよう求めています。いまの会社で「人的資本」と言うとき、こうした開示の項目や数字を指すことがよくあります。

一方で、「人を資本と呼ぶのは、人をモノのように扱うことでは」と受け取る人もいれば、「社員を大切にする経営」の言いかえとして使う人もいます。教育で増える個人の力を指す経済学の言葉なのか、会社が投資家に示す開示の数字なのか、人を大事にする経営のスローガンなのか。立場によって、思い浮かべるものがかなり違います。

あなたはどの意味派？

あなたは「人的資本」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    教育や訓練で増える個人の力

    経済学では、教育や職場での訓練を「人への投資」と考え、それによって身につく知識や技能を人的資本と呼びます。学歴と賃金の関係などを説明するのに使われてきました。

  2. 拡張広がった使い方

    開示する人材の情報

    「人的資本の開示」「人的資本経営」のように、会社が人材にどう投資しているかを、方針や数字で外に示すことを指す使い方です。研修時間、女性管理職比率、男性の育児休業取得率などが例に挙がります。

  3. 誤用寄り出典から離れた使い方

    社員を大事にすることの言いかえ

    「わが社は人的資本を重視しています」が、具体的な投資や数字の話をせずに「人を大切にしています」という意味だけで使われることがあります。もとの言葉の、投資と見返りという考え方は抜け落ちています。

語源・成り立ち

英語の human capital の訳語です。「資本」は、投資によって価値を増やすことのできる財のことで、この考え方を人に当てはめたものです。

世界大百科事典によると、人を資本とみる考え方そのものはアダム・スミスやアルフレッド・マーシャルにも見られ、人的資本理論として盛んに研究されるようになったのは1950年代以降のアメリカの経済学界です。農業経済学者のセオドア・シュルツは、教育による人の能力の向上が経済成長に大きく働くとする議論を広げ、1979年にノーベル経済学賞を受けました。

広まった経緯

  1. 1950年代以降

    アメリカの経済学界を中心に、人的資本理論の研究が盛んになる（世界大百科事典）。

  2. 1979年

    人的資本理論を展開したセオドア・シュルツが、ノーベル経済学賞を受ける。

  3. 2022年8月

    内閣官房が、企業が人的資本の情報を示すための「人的資本可視化指針」を公表する。

  4. 2023年1月

    金融庁が内閣府令を改め、2023年3月31日以後に終わる事業年度の有価証券報告書から、人材育成の方針などの記載を求める。

ズレのポイント

「人材」の言いかえではない

人的資本は、人そのものではなく、人が身につけた知識や技能を投資の成果として見る言葉です。「人的資本を採用する」のように、人材と入れかえて使うと意味がずれます。

開示の義務は「数字を出すこと」だけではない

有価証券報告書で求められているのは、人材育成の方針や社内環境整備の方針と、それに関する指標や目標です。女性管理職比率などの数字は、その一部です。

受け取り方に差がある

経営の場では前向きな言葉として使われますが、働く人の中には「資本」という言い方に抵抗を感じる人もいます。社内で使うときは、何を指しているかを添えると伝わりやすくなります。

多様な観点

経済学の見方から

人的資本理論では、教育や訓練にかかる費用を投資とみなし、それによって上がる生産性や賃金を見返りと考えます。教育の経済的な効果を測る道具として発展してきました。

投資家と制度の見方から

投資家にとっては、会社が人材にどう投資し、それが将来の価値にどうつながるかを判断する材料です。政府の指針や開示の制度は、こうした情報をそろえて比べやすくするために作られました。

働く人の見方から

研修や学び直しの機会が増えるなら歓迎だと考える人もいれば、人を数字で測られることに違和感を持つ人もいます。同じ言葉でも、自分が投資を受ける側なのか、測られる側なのかで印象が変わります。

使用シーン

経営者、人事、IR（投資家向けの広報）の担当者がよく使います。ニュースや統合報告書で目にする機会は増えましたが、現場の働く人には、何を指すのか説明が要ることも多い言葉です。

関連語

  • ジョブ型人的資本経営とあわせて語られることが多い、雇い方の区分。
  • リスキリング人への投資の例として挙がる、学び直しの言葉。
  • エンゲージメント人的資本の開示で、よく指標として挙がる言葉。
  • ウェルビーイング社員の健康や幸福を大事にする経営の文脈で、一緒に使われる言葉。
