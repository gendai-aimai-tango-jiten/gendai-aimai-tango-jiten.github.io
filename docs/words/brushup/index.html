ぶらっしゅあっぷ【ブラッシュアップ】〔名〕

  1. ①

    もともとの意味知識や技能を磨き直す。「英語をブラッシュアップする」のように、一度身につけた力を学び直したり、さらに伸ばしたりすることです。

  2. ②

    企画や資料を練り直す。「提案書をブラッシュアップする」のように、すでにある案をより良くすることです。

  3. ③

    やり直しの遠回しな指示。「もう少しブラッシュアップしてみて」が、実際には大きな手直しや作り直しを求める言い方として使われることがあります。

曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

通用度4/5

どういう意味？

すでにある企画や資料、技能などに磨きをかけて、より良くすることです。「この案、ブラッシュアップしてもう一度出してくれる？」「語学力をブラッシュアップしたい」のように、仕事の場でよく使われます。

英語の brush up は、ケンブリッジ英語辞典では「すでに学んだが一部忘れかけていることの知識を高める」と説明されています。英語では復習や学び直しの意味が中心で、資料や企画を手直しする意味は、日本のカタカナ語として広がった使い方です。

日本語の中でも、受け取り方に幅があります。言う側は「方向は良いので、もう少し磨いて」という軽い仕上げのつもりでも、言われた側は「このままでは通らない、作り直せ」という指示と受け取ることがあります。どこまで直せばよいのか（細部の仕上げか、大きな作り直しか）が、言う人と言われる人でずれます。

あなたはどの意味派？

あなたは「ブラッシュアップ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    知識や技能を磨き直す

    「英語をブラッシュアップする」のように、一度身につけた力を学び直したり、さらに伸ばしたりすることです。英語の brush up に近い使い方です。

  2. 拡張広がった使い方

    企画や資料を練り直す

    「提案書をブラッシュアップする」のように、すでにある案をより良くすることです。日本のビジネスで最もよく聞く使い方です。

  3. 拡張広がった使い方

    やり直しの遠回しな指示

    「もう少しブラッシュアップしてみて」が、実際には大きな手直しや作り直しを求める言い方として使われることがあります。

語源・成り立ち

英語の brush up から来たカタカナ語です。brush はブラシ、またブラシをかけることで、ほこりを払って磨き直すイメージから「さびついた知識を磨き直す」意味で使われます。ケンブリッジ英語辞典の説明も、すでに学んだが忘れかけている知識を高めることです。

日本では、知識や技能だけでなく、企画、資料、デザイン、商品など、形のあるものを「より良くする」意味に広がりました。All About の解説も、英語本来の意味とは少し異なり「磨きをかける」「すでにあるものの状態をより良くする」意味で使われることが多いと書いています。

広まった経緯

  1. 英語

    brush up は、忘れかけた知識や技能を学び直す意味で使われる（ケンブリッジ英語辞典）。

  2. 日本語に入って

    知識や技能を磨き直す意味のカタカナ語として使われる。

  3. 現代

    企画や資料、商品を練り直す意味で、ビジネスの場で広く使われる。

ズレのポイント

英語では資料の手直しに伝わりにくい

英語で brush up the proposal と言っても、日本語の「提案書を練り直す」の意味では伝わりにくいことがあります。英語では refine や polish などが使われます。

何を直すかを添える

「ブラッシュアップして」だけでは、どこをどこまで直すのかが分かりません。「数字の根拠を足して」「結論を先に」のように、直してほしい点を一緒に伝えると行き違いが減ります。

ゼロから作るときには使わない

ブラッシュアップは、すでにあるものを良くすることです。まだ何もない状態から企画を立てる場合には合いません。

多様な観点

英語から

英語の brush up は、旅行の前にフランス語をおさらいする、といった学び直しの場面で使われます。日本語のように資料や商品を対象にする使い方は、英語とは少しずれています。

職場から

上司にとっては前向きな言葉でも、部下にとっては「ダメ出し」に聞こえることがあります。良い点と直す点を分けて伝えると、言葉の受け取り方がそろいます。

言い換えから

「練り上げる」「磨きをかける」「手直しする」「作り直す」のどれに当たるかを言葉にすると、求めている直しの大きさがはっきりします。

使用シーン

会社員を中心に、企画書、プレゼン資料、デザイン、商品開発などの話でよく使われます。研修や自己啓発の文脈では「スキルをブラッシュアップする」のように、能力を伸ばす意味でも使われます。

関連語

  • スキルアップ能力や技術を高めること。対象が能力に限られる点で、ブラッシュアップより狭い。
  • 練り上げる計画や文章を何度も練り直して、より良く仕上げること。言い換えに使える。
  • フィードバック相手に評価や意見を返すこと。ブラッシュアップの前に行われることが多い。
