曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

ガチは、相撲界の隠語「ガチンコ」を縮めた言葉です。デジタル大辞泉は「がち」を《俗語。「がちんこ」から》とし、意味を「真剣に。まじめに。本気で」としています。ガチンコは、八百長ではない、まじめな勝負のことです。

いまは「本気で」のほかにも、さまざまな意味で使われます。「ガチでうまい」は「本当に」「すごく」、「ガチ中華」は日本風に変えていない「本場の」中華料理、「ガチ勢」は遊びではなく本気で打ち込む人のことです。

「ガチで言ってる？」と聞くときは「冗談じゃなく本当に？」の意味ですし、「ガチの〇〇」は「本物の〇〇」の意味になります。「本気の」と「本物の」と、ただの強調の「すごく」。同じ「ガチ」でも、どれを指しているかは前後の言葉で決まります。

あなたはどの意味派？

あなたは「ガチ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    真剣勝負

    「ガチンコ勝負」「ガチの試合」のように、手加減や筋書きのない本当の勝負を指します。相撲の隠語から来た、もとの意味です。

  2. 拡張広がった使い方

    本気で・真剣に

    「ガチで勉強する」「ガチ勢」のように、遊び半分ではなく本気で取り組むことを表します。

  3. 拡張広がった使い方

    本物の・本場の

    「ガチ中華」「ガチのプロ」のように、手を加えていない本物であることを表します。

  4. 拡張広がった使い方

    本当に・すごく

    「ガチでうまい」「ガチ無理」のように、程度を強める言葉として使われます。「マジ」とほぼ同じ働きです。

語源・成り立ち

もとは相撲の世界の隠語「ガチンコ」です。精選版 日本国語大辞典は「相撲の世界で、真剣勝負をいう」とし、デジタル大辞泉は「真剣に行う組み稽古」の意味も載せています。立ち合いで頭と頭がぶつかって「ガチン」と音がすることから生まれた、といわれています。

その後「ガチンコ勝負」のように一般にも使われるようになり、1999年4月から2003年7月にはTBSのバラエティ番組「ガチンコ!」が放送されました。やがて「ガチ」と縮めた形で、「ガチで頭にきた」のように「本気で」「本当に」の意味でも使われるようになりました。

広まった経緯

  1. （時期不明）

    相撲界で、八百長ではない真剣勝負を「ガチンコ」と呼ぶ。

  2. 1999年〜2003年

    TBSのバラエティ番組「ガチンコ!」が放送される。

  3. 2019年

    デジタル大辞泉のサイト「ことばの総泉挙」のアンケートで、「ガチでうまいラーメン店」という言い方を「使わない」と答えた人が72%になる。

  4. 2022年

    「ガチ中華」が新語・流行語大賞の候補に選ばれる。

ズレのポイント

「本気」なのか「本物」なのか

「ガチの人」と言ったとき、本気で打ち込んでいる人なのか、本物の専門家なのかは、前後を聞かないと分かりません。

使う人と使わない人がはっきり分かれる

若い世代では「マジ」と同じくらい気軽に使われますが、2019年のアンケートでは7割ほどが「ガチでうまい」とは言わないと答えています。改まった場では「本当に」「本格的な」と言い換えたほうが無難です。

「ガチャ」とは別の言葉

「親ガチャ」などの「ガチャ」は、カプセルトイやゲームのくじから来た言葉で、「ガチ」とは成り立ちが違います。

多様な観点

相撲から

ガチンコの反対の言葉は「八百長」で、こちらも相撲から来た言葉です。「ガチ」には、筋書きがないことへの信頼が込められています。

ゲームから

ゲームでは、勝つためにやり込む「ガチ勢」と、楽しむことを大事にする「エンジョイ勢」という分け方がよく使われます。

食から

「ガチ中華」は、日本人向けに味を変えた「町中華」に対して、本場の味そのままの中華料理を指します。ここでの「ガチ」は「本気」より「本物」に近い意味です。

使用シーン

若い世代を中心に、会話やSNSで広く使われます。ゲームやスポーツ、アイドルの応援、グルメの話題で、「ガチ勢」「ガチ恋」「ガチ中華」などの組み合わせの言葉として使われることも多い言葉です。

関連語

  • ガチ恋「ガチ」を使った言葉。推しへの好きが本気の恋になること。
  • ヤバい程度を強める言葉として、いろいろな意味で使われる言葉。
  • 神強い評価を一言で表す、意味の広い言葉。
