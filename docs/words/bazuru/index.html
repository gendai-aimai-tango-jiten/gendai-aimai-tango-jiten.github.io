どういう意味？

SNSや動画サイトなどで、ある投稿や話題が短期間に爆発的に広まり、多くの人の注目を集めることです。「この動画がバズった」「バズる投稿の作り方」のように使います。

英語の buzz は、ハチの羽音のブーンという音や、人々のざわめき、うわさ話を表す言葉です。マーケティングの分野で、口コミで話題が広がることを「バズ」と呼んでいたことから、SNSの時代に「バズる」という動詞が生まれました。

好意的に広まったのか、批判されて広まったのか。一般には良い意味で使われますが、批判が集中して広まる「炎上」との境目があいまいなこともあります。

あなたはどの意味派？

あなたは「バズる」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    口コミで話題になる

    マーケティングで、商品や話題が人々の口コミで広がることを「バズ」と呼んだ使い方です。

  2. 拡張広がった使い方

    SNSで投稿が爆発的に拡散する

    投稿がたくさん共有され、短期間に多くの人に見られることです。いちばん多い使い方です。

  3. 拡張広がった使い方

    世間で大きな話題になる

    「あの曲がバズっている」のように、SNSに限らず世間で流行していることを指す使い方もあります。

  4. 誤用寄り出典から離れた使い方

    批判で広まることも含む

    批判が集中して拡散した場合にも「バズった」と言うことがあります。一般には、こうした場合は「炎上」と呼んで区別されます。

語源・成り立ち

英語の buzz（ブーンという音、ざわめき、うわさ）から来ています。英語では、話題になっていることを buzz と言い、口コミを利用した宣伝は buzz marketing（バズ・マーケティング）と呼ばれます。英語でSNSで話題が広がることは go viral（ウイルスのように広がる）と言うのが一般的です。

日本では、マーケティング用語の「バズ」に、動詞を作る「る」を付けて「バズる」となりました。2010年代にSNSが広まるとともに、日常語として定着しました。

広まった経緯

  1. 2000年代

    マーケティングの分野で、口コミを「バズ」と呼ぶ言い方が使われる。

  2. 2010年代

    SNSの普及とともに「バズる」が広まり、日常語になる。

  3. 2010年代後半〜

    「バズる投稿」「バズらせる」など、SNSでの発信のノウハウを語る言葉として定着する。

ズレのポイント

英語の buzz とは使い方が違う

英語でSNSの投稿が急に広まることは、go viral と言うのが一般的です。「バズる」は日本で生まれた使い方です。

バズと炎上の境目

好意的に広まるのが「バズる」、批判で広まるのが「炎上」と区別されますが、一つの投稿に賛否が集まることも多く、境目ははっきりしません。

バズを狙いすぎるリスク

注目を集めることを優先して過激な投稿をすると、炎上につながることがあります。「バズる」ことと、良い評価を得ることは別です。

多様な観点

SNSの文化から

一般の人の投稿でも、一夜にして何万人もの目に触れる可能性がある、というSNSの特徴を表す言葉です。バズることが、個人の発信の目標のように語られることもあります。

マーケティングから

企業は、広告より口コミで広まる「バズ」を重視するようになりました。お金をかけずに大きな宣伝効果が得られる一方で、思わぬ方向に話題が広がるリスクもあります。

言語学から

英語の名詞に「る」を付けて動詞にする作り方は、「ググる」「サボる（サボタージュ）」など、日本語でよく見られます。バズるもその一つです。

使用シーン

世代を問わず、SNS、ニュース、マーケティングの話題などで広く使われます。いまでは多くの人に通じる言葉です。

関連語

  • 映えSNSで見栄えがすること。映える投稿はバズりやすい。
  • ミームネットで広がる面白いネタや画像。バズの中心になることが多い。
