曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

本来は、人の手が加わっていない、自然のままの状態のことです。「天然水」「天然の鮎」「天然記念物」のように使います。

人について「あの人は天然だ」と言うときは、「天然ボケ」の略です。わざと笑わせようとしているのではなく、本人は大まじめなのに、言い間違いや勘違い、ずれた発言をしてしまい、周りが思わず笑ってしまう人を指します。お笑いの世界から広まった言い方で、「養殖（わざと天然を演じる人）」という対義語もあります。

愛すべき個性としてほめているのか、ぼんやりしている人をからかっているのか。「天然」は、言い方や関係によって受け取られ方が大きく変わる言葉です。

あなたはどの意味派？

あなたは「天然」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    自然のまま・人工でない

    「天然素材」「天然ガス」のように、人の手が加わっていない、自然に存在するものを表します。

  2. 拡張広がった使い方

    悪気のないボケ（天然ボケ）

    「彼女は天然だから」のように、わざとではないのに、ずれた言動で周りを笑わせてしまう人を指します。

  3. 拡張広がった使い方

    飾らない自然体

    「天然の魅力」のように、作らない、ありのままの人柄をほめる使い方です。

  4. 拡張広がった使い方

    癖のない自然な状態

    「天然パーマ」のように、生まれつきの状態を表す使い方もあります。

語源・成り立ち

「天然」は、天（自然）がそのように作った、という意味の漢語です。

人に使う「天然ボケ」は、お笑いの世界から広まった言葉とされます。萩本欽一さんが、ジミー大西さんの、計算ではない天性のボケを表現したのが始まりとする説がよく紹介されます。そこから「天然」だけで、天性のボケ役を指すようになりました。

広まった経緯

  1. 昔から

    自然のまま、人工でないことを表す言葉として使われる。

  2. 1980年代ごろ

    お笑いの世界で「天然ボケ」という言葉が生まれたとされる。

  3. 1990年代〜

    テレビのバラエティ番組を通じて、「天然」だけで人の性格を表す使い方が広まる。

ズレのポイント

からかいに聞こえることもある

「天然だね」は、親しい間ではほめ言葉や愛情表現ですが、相手によっては「ぼんやりしている」「頭が回らない」と言われたように感じることがあります。

わざとなら「養殖」

天然ボケは、計算していないことが前提です。わざとかわいく見せるために天然を演じることは、「養殖」と呼ばれてからかわれます。

仕事の場では評価が分かれる

プライベートでは愛される「天然」も、仕事のミスが続く場面では、からかいや批判の言葉として使われることがあります。

多様な観点

お笑い文化から

お笑いでは、計算されたボケより、本人が気づかずに生まれるボケのほうが面白いとされることがあります。「天然」は、そうした計算のない笑いを表す言葉として広まりました。

人間関係から

天然と呼ばれる人は、周りの空気を和ませる存在として愛される一方、からかいの対象にもなりやすい面があります。

言語学から

「天然」が人の性格を表すようになったのは、「天然ボケ」の後ろ半分が省略された結果です。長い言葉の前半だけで意味が通じるようになる例は、日本語の略語によく見られます。

使用シーン

世代を問わず、日常会話、テレビ、SNSなどで広く使われます。

関連語

  • ギャップ萌え意外な一面に心をつかまれること。天然な一面がギャップとして魅力になることがある。
  • 陰キャ人の性格を分類する言葉。
  • 中二病人の言動を笑いを込めて表す言葉。
