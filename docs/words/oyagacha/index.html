曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

子どもはどんな親のもとに生まれるかを選べず、生まれた家庭の経済力や環境によって人生が大きく左右される、ということを表す言葉です。ソーシャルゲームなどで、何が出るか分からない「ガチャ」にたとえています。

2021年に新語・流行語大賞のトップ10に入り、大きな話題になりました。

使われ方は大きく二つに分かれます。一つは、生まれによる格差は本人の努力ではどうにもならないという社会の問題を指す使い方。もう一つは、自分の親の性格や育て方への不満を「親ガチャ外れた」と言う使い方です。

あなたはどの意味派？

あなたは「親ガチャ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    生まれた家庭で人生が左右されること

    家の経済力、教育環境、住む地域など、自分では選べない条件で将来が決まってしまう、という社会の構造を指します。

  2. 拡張広がった使い方

    親個人の性格や育て方への不満

    「うちは親ガチャ外れた」のように、自分の親の厳しさや考え方への不満を、半分冗談で言う使い方です。

  3. 拡張広がった使い方

    「〇〇ガチャ」への広がり

    「配属ガチャ」「上司ガチャ」「担任ガチャ」のように、自分で選べない組み合わせ全般に「ガチャ」を付ける言い方が広がりました。

  4. 誤用寄り出典から離れた使い方

    努力しない言い訳としての使用

    うまくいかないことを何でも親や生まれのせいにする言葉、として批判的に使われることもあります。もとの言葉が問いかけていた格差の話からは離れています。

語源・成り立ち

「ガチャ」は、カプセルトイ（ガチャガチャ）や、ソーシャルゲームでランダムにアイテムが出る課金方式のことです。中身を選べず、当たりも外れもある、という性質を「親」に当てはめました。

言い出した人ははっきりしていません。ネットのスラングとして広まり、『現代用語の基礎知識』は「子どもは親を選べない」という考えをガチャになぞらえたネットスラングと説明しています。

広まった経緯

  1. 2010年代後半

    ネットの掲示板やSNSで使われ始める。

  2. 2021年

    テレビや新聞でも取り上げられ、議論を呼ぶ。

  3. 2021年12月

    「2021ユーキャン新語・流行語大賞」のトップ10に選ばれる。「大辞泉が選ぶ新語大賞2021」では大賞になる。

  4. 2023年

    子育て世代が「自分は子どもにとって外れなのか」と悩む声が報じられるなど、親の側からの受け止めも話題になる。

ズレのポイント

格差の話か、親個人の話か

社会の格差を問題にしている人と、自分の親への愚痴として言っている人が、同じ言葉を使っています。前者のつもりで話していても、後者として受け取られ「親のせいにするな」と反発されることがあります。

親本人に向けると強く刺さる

冗談のつもりでも、親に向かって「親ガチャ外れた」と言うと、相手を深く傷つけることがあります。子育て中の親が、この言葉に追い詰められるという声も報じられています。

「運命論」として受け取られやすい

「生まれですべて決まる」と言っているように聞こえ、努力の意味を否定する言葉として批判されることがあります。もともとは、本人の努力ではどうにもならない部分があることを指摘する言葉です。

多様な観点

社会学から

親の学歴や収入が子どもの学力や進路に影響することは、教育社会学の調査で繰り返し示されてきました。親ガチャは、こうした研究が示してきたことを、若い世代が自分の言葉で言い表したものとも言えます。

世代論から

「努力すれば報われる」という考えへの違和感が、若い世代に広がっていることの表れとして語られます。一方で、上の世代からは「甘え」と受け取られやすく、世代間の受け止め方の差が大きい言葉です。

ゲーム文化から

ガチャは「何が出るかは運」「引き直せない」という感覚を、多くの人が体で知っている仕組みです。その感覚を人生に重ねたことで、説明しなくても伝わる言葉になりました。

使用シーン

10代から20代を中心に、SNSや会話で使われます。ニュースや論説でも、格差や教育の話題で取り上げられることの多い言葉です。

関連語

  • 生きづらさ社会の中で感じる息苦しさを表す言葉。親ガチャと並べて語られることがある。
  • 毒親子どもに害を与える親を指す言葉。親個人の問題を指す点で、親ガチャの一部の使い方と重なる。
  • 配属ガチャ会社での配属先を選べないことを言う言葉。「〇〇ガチャ」の一つ。
