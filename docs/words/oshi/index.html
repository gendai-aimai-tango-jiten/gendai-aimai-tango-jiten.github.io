曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

特に応援している人やキャラクター、ものごとのことです。動詞の「推す（人に薦める）」から来ています。

もとはアイドルファンの間で、グループの中で特に応援しているメンバーを「推しメン（一推しのメンバー）」と呼んだのが始まりです。2011年には「推しメン」が新語・流行語大賞にノミネートされ、その後「推し」だけで使われるようになりました。いまは俳優、スポーツ選手、アニメのキャラクター、VTuber、さらには食べ物やお店、電車まで「推し」と呼ばれます。

ちょっと気に入っているものなのか、人生をかけて応援する存在なのか。同じ「推し」でも、言葉に込める重さは人によって大きく違います。

あなたはどの意味派？

あなたは「推し」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    グループで一番応援するメンバー

    アイドルグループの中で、特に応援しているメンバーのことです。「推しメン」とも言います。

  2. 拡張広がった使い方

    応援している人やキャラクター全般

    俳優、芸人、スポーツ選手、キャラクターなど、ジャンルを問わず特に応援している対象を指します。

  3. 拡張広がった使い方

    お気に入りのもの

    「推しのパン屋」「推しコスメ」のように、人以外のお気に入りを指す使い方です。「おすすめ」に近い軽い意味で使われることもあります。

  4. 拡張広がった使い方

    人生の支え・生きがい

    「推しがいるから仕事をがんばれる」のように、日々を支えてくれる大切な存在を指します。「好き」よりずっと重い意味で使う人もいます。

語源・成り立ち

動詞「推す（推薦する、人に薦める）」の名詞形です。「一推しのメンバー」→「推しメン」→「推し」と短くなっていきました。

1990年代後半にアイドルファンの間で使われ始めたとされ、2010年ごろにはAKB48の人気とともに広まりました。2011年には「推しメン」がユーキャン新語・流行語大賞にノミネートされています。

広まった経緯

  1. 1990年代後半

    アイドルファンの間で「推しメン」「推し」が使われ始める。

  2. 2010〜2011年

    AKB48の人気とともに広まり、2011年に「推しメン」がユーキャン新語・流行語大賞にノミネートされる。

  3. 2010年代後半〜

    アイドル以外にも使われ、日常語として定着する。2021年には「推し活」が流行語大賞にノミネートされる。

ズレのポイント

「推し」と「好き」は同じではない

推しには「人に薦めたい」「応援したい」という気持ちが含まれます。ただ好きなだけでなく、その存在を広めたい、支えたいという気持ちが、推しという言葉の特徴です。

恋愛感情とは限らない

推しへの気持ちは、恋愛のような感情のこともあれば、尊敬や憧れ、親のような見守りの気持ちのこともあります。「推し＝恋人がわり」と決めつけると、本人の感覚とずれることがあります。

軽い「推し」と重い「推し」が混ざる

「推しのお菓子」程度の軽い使い方が広まった一方で、推しを人生の中心に置く人もいます。言葉の重さの違いが、すれ違いを生むこともあります。

多様な観点

推し文化から

推しという言葉は、応援される側と応援する側の関係を表す言葉です。グッズを買う、配信を見る、魅力を広めるといった行動は、推しを支える「推し活」と呼ばれるようになりました。

社会から

推しという言葉が広まったことで、オタク的な趣味を前向きに語れるようになった、という見方があります。一方で、推しに時間やお金を注ぎすぎる「推し疲れ」も話題になっています。

言語学から

「推し」は名詞として定着し、「推しが尊い」「推しを推す」のように、さまざまな言い方の土台になりました。「推し色」「推し事」など、派生語もたくさん生まれています。

使用シーン

10代から50代以上まで、幅広い世代で使われます。SNS、雑誌、テレビ、企業の広告など、日常的に見かける言葉です。
