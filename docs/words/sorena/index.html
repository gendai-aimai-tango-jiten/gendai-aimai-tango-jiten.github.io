曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

相手の言ったことに対して、「それ、わかる」「まさにそれ」「その通り」と同意や共感を示す相づちです。「月曜って本当にだるいよね」「それな」のように使います。

2015年ごろから女子高生の間で日常的に使われるようになり、SNSを通じて広まりました。2017年には、キーボードアプリの顔文字大賞で「それな ( ᐛ )σ」が大賞に選ばれています。

短く、どんな話にも合わせられるため、心から共感しているのか、とりあえず話を合わせているのかが分かりにくい言葉でもあります。「もっとも残酷な相づちの一つ」と言われることもあります。

あなたはどの意味派？

あなたは「それな」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    強く同意する

    「それな！」と勢いよく言って、相手の意見に心から共感していることを示します。

  2. 拡張広がった使い方

    とりあえずの相づち

    話をよく聞いていなくても、「それな」と返せば会話が続きます。話を受け流すときにも使われる使い方です。

  3. 拡張広がった使い方

    SNSでの共感の表明

    人の投稿に「それな」とコメントして、同じ気持ちだと伝える使い方です。

語源・成り立ち

由来ははっきりしていません。関西弁の「ほんまそれな（本当にそれだね）」から「ほんま」が省略されたという説が有力とされています。ネット掲示板が発祥だという説もありますが、確かではありません。

「それ」に、軽い念押しや同意を表す「な」を付けた形で、「それだよね」という意味になります。

広まった経緯

  1. 2010年代前半

    関西の話し言葉などから、「それな」が若者の間で使われ始めたとされる。

  2. 2015年ごろ

    女子高生の間で日常的に多用されるようになる。

  3. 2017年

    キーボードアプリSimejiの顔文字大賞で「それな ( ᐛ )σ」が大賞に選ばれる。

ズレのポイント

共感しているかどうかは言い方次第

「それな」は便利な相づちですが、使いすぎると「ちゃんと聞いていない」と思われることがあります。大事な話には、具体的な言葉で返すほうが気持ちが伝わります。

目上の人には使わない

くだけた若者言葉なので、上司や目上の人への相づちには向きません。

英語にすると

英語では「I know!」「Right?」「Exactly.」「Same.」などが、「それな」に近い相づちとして紹介されます。

多様な観点

コミュニケーションから

「それな」は、相手の話を否定せずに受け止める、共感を大切にする会話の型を表しています。一方で、議論を深めずに話を終わらせてしまう面もあります。

SNSの文化から

SNSでは、長い感想を書くより「それな」の一言で共感を示すほうが手軽です。短い言葉で気持ちを共有する文化の中で広まりました。

方言から

関西弁が由来とする説が正しければ、それなも、しんどいと同じく、関西の言葉が全国の若者言葉になった例です。

使用シーン

10代から20代を中心に、日常会話、SNS、メッセージアプリなどで使われます。
