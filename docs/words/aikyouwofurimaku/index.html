あいきょうをふりまく慣用句

愛嬌を振りまく

『振りまくのは「愛嬌」か「愛想」か。調査のたびに多数派が入れ替わります。』

誤用の定番
この言葉をシェア

あいきょうをふりまく【愛嬌を振りまく】〔句〕

  1. ①

    もともとの意味かわいらしさを周りに広げる。「子犬が来客に愛嬌を振りまいている」のように、その人や動物が持つかわいらしさ、憎めない雰囲気が周りに伝わる様子を言います。

  2. ②

    誰にでも感じよく接する。「新人が先輩たちに愛嬌を振りまく」のように、意識して明るく、感じよくふるまうことにも使われます。

  3. ③

    出典から離れた使い方「愛想を振りまく」と言う。「愛想」と取り違えた言い方です。

曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度4/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

「愛嬌を振りまく」は、周りの人にかわいらしさや感じのよさを示すことです。デジタル大辞泉は「愛嬌」の意味のひとつに「相手を喜ばせるような言葉・振る舞い」を挙げ、「愛嬌をふりまく」という例を載せています。

同じ場面で「愛想を振りまく」と言う人も多くいます。文化庁の「国語に関する世論調査」では、平成17年度に「愛嬌を振りまく」を使う人が43.9%、「愛想を振りまく」を使う人が48.3%でした。平成27年度には「愛嬌」が49.1%、「愛想」が42.7%で、多数派が入れ替わっています。『三省堂国語辞典』『新明解国語辞典』『明鏡国語辞典』のように、「愛想を振りまく」を例に挙げる辞書も出てきました。

二つの言い方は、ニュアンスにも差があります。デジタル大辞泉は、「愛嬌」はもともと身についたものを言うことが多く、「愛想」は意識的な動作や態度を言うと説明しています。自然ににじむかわいらしさを周りに広げるのか、意識して愛想よくふるまうのか。どちらの言い方を選ぶかで、ふるまいの受け取り方がずれます。

あなたはどの意味派？

あなたは「愛嬌を振りまく」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    かわいらしさを周りに広げる

    「子犬が来客に愛嬌を振りまいている」のように、その人や動物が持つかわいらしさ、憎めない雰囲気が周りに伝わる様子を言います。

  2. 拡張広がった使い方

    誰にでも感じよく接する

    「新人が先輩たちに愛嬌を振りまく」のように、意識して明るく、感じよくふるまうことにも使われます。

  3. 誤用寄り出典から離れた使い方

    「愛想を振りまく」と言う

    「愛想」と取り違えた言い方です。辞書によっては例に挙げていますが、明鏡国語辞典（第3版）は、無理をしてこびる感じがあると説明しています。

語源・成り立ち

デジタル大辞泉によると、「愛嬌」はもと「愛敬（あいぎょう）」と書いて濁って読む言葉でした。のちに「あいきょう」と清音で読まれるようになり、近世以降に「嬌」の字が当てられるようになりました。いまも「愛敬」と書くことがあります。

ジャパンナレッジの連載「日本語、どうでしょう？」は、「愛想」は具体的な動作、「愛嬌」はその人の持つ印象や雰囲気だと整理しています。雰囲気は振りまけても、動作は振りまけないので、本来は「愛嬌を振りまく」になる、という説明です。

広まった経緯

  1. 近世以降

    「愛敬（あいぎょう）」が「あいきょう」と読まれるようになり、「嬌」の字が当てられる（デジタル大辞泉の補説）。

  2. 2005年度（平成17年度）

    文化庁の「国語に関する世論調査」で、「愛嬌を振りまく」を使う人が43.9%、「愛想を振りまく」を使う人が48.3%となる。

  3. 2015年度（平成27年度）

    同じ調査で、「愛嬌を振りまく」が49.1%、「愛想を振りまく」が42.7%となる。

  4. 2021年

    辞書編集者の神永暁さんが、『三省堂国語辞典』『新明解国語辞典』『明鏡国語辞典』が「愛想を振りまく」を例に挙げていると紹介する（文春オンライン）。

ズレのポイント

改まった文章では「愛嬌」を使う

「愛想を振りまく」を載せる辞書もありますが、本来の形ではないと受け取る人もいます。手紙や記事では「愛嬌を振りまく」と書くと安心です。

「愛想」は「尽かす」「よい」と組み合わせる

「愛想」は「愛想を尽かす」「愛想がよい」「お愛想を言う」のように使います。「愛嬌が尽きる」とは言わないので、組み合わせる言葉で使い分けます。

ほめるつもりが皮肉に聞こえることがある

「誰にでも愛想を振りまいている」と言うと、こびている、八方美人だという含みで受け取られることがあります。ほめるなら「誰にでも感じがいい」と言い換えると伝わります。

多様な観点

国語の調査から

平成17年度と平成27年度で多数派が入れ替わり、どちらの年も二つの言い方の差は10ポイントに届きませんでした。どちらか一方に定まらず、揺れ続けている言い方です。

辞書から

「愛想を振りまく」を例に挙げる辞書が出てきた一方で、明鏡国語辞典はこびる感じがあると注記しています。間違いとは言い切らず、ニュアンスの違いとして説明する流れです。

人づきあいから

同じ明るいふるまいでも、生まれつきの人なつこさと見るか、努力して感じよくしていると見るかで、言葉の選び方が変わります。どちらの言葉で言われたかで、言われた側の受け止め方も変わります。

使用シーン

世代を問わず、子どもや動物、店員、新人などの様子を言うときに使われます。「愛想を振りまく」も、日常の会話では広く使われています。

関連語

  • 愛想を尽かす相手に嫌気がさして、好意を持てなくなること。「愛想」はこの形でよく使われる。
  • 八方美人誰にでもいい顔をする人。「愛想を振りまく」の否定的な受け取り方に近い。
  • 二つ返事文化庁の調査で、本来でない言い方が多数派になった年がある言葉。
