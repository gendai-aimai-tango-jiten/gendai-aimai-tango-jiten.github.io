曖昧メーター

曖昧度5/5

人によってその言葉の意味がどれだけ変わるか

誤用度4/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

「微妙」は、もとは、趣が深く、なんとも言えない美しさや味わいがあることを表す言葉です。そこから、一言では言い表せないほど細かく複雑なこと、きわどくてどちらとも言い切れないことも指すようになりました。「微妙な色合い」「微妙な判定」のように使います。

いまは、「ビミョー」と書かれることもある、否定的な気分を遠回しに伝える使い方が広まっています。「テストできた？」「微妙」と答えれば、たいていは「あまりできなかった」という意味です。デジタル大辞泉も、この使い方を俗な用法として載せています。文化庁の2014年度「国語に関する世論調査」では、よいか悪いかの判断がつかないときに「微妙」を使うことがある人が66.2%で、2004年度から増えたと報じられています。

「微妙な味」と言われたとき、繊細でおいしいのか、あまりおいしくないのかは、話し手の世代や場面で変わります。細やかで言い表しにくいことなのか、「よくない」をぼかした言い方なのか。ほめ言葉にも、遠回しな否定にもなる言葉です。

あなたは「微妙」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    なんとも言えない美しさ・味わい

    「微妙な音色」のように、趣が深く、言葉にできないよさがあることを表します。仏教の経典や古い文章で「みみょう」と読む使い方もあります。

  2. 拡張広がった使い方

    細かくて言い切れない・きわどい

    「微妙な違い」「微妙な判定」のように、差がわずかだったり、どちらとも決めにくかったりすることを表します。「微妙に遅れる」のように「少し」の意味でも使います。

  3. 誤用寄り出典から離れた使い方

    「よくない」の遠回し

    「その服、微妙」のように、はっきり否定せずに、よくないと伝える使い方です。辞書は俗な用法として載せていて、明言したくないときのぼかしにも使われます。

語源・成り立ち

「微」は、かすかで小さいこと、「妙」は、言葉にできないほどすぐれていることを表します。中国の古典『老子』に、すぐれた人を形容する「微妙玄通」という言葉があり、仏教の経典にも出てくる言葉です。

『日本国語大辞典』は、「みみょう」と読む用例として、平安時代はじめの『日本霊異記』（810〜824年）の「心経を誦する音、甚だ微妙にして」を挙げています。「びみょう」と読む用例には、江戸時代後期の『江戸繁昌記』（1832〜36年）があります。

広まった経緯

  1. 810〜824年

    『日本霊異記』に、声の美しさを表す「微妙（みみょう）」の用例がある（『日本国語大辞典』）。

  2. 1832〜36年

    『江戸繁昌記』に「びみょう」と読む用例がある（『日本国語大辞典』）。

  3. 2004年度

    文化庁「国語に関する世論調査」で、判断がつかないときに「微妙」を使うかを尋ねる。

  4. 2014年度

    同じ調査で、使うことがある人が66.2%となり、2004年度から増えたと報じられる。

ズレのポイント

ほめたつもりが否定に聞こえる

「微妙な味わいですね」と、繊細さをほめるつもりで言っても、相手は「おいしくない」と受け取ることがあります。ほめるときは「繊細な」「奥行きのある」など別の言葉を選ぶと誤解がありません。

答えをぼかしすぎない

仕事で「その案は微妙です」と言うと、何がよくないのかが伝わりません。どの点が気になるのかを続けて言うと、相手も直しやすくなります。

「少し」の意味もある

「微妙に違う」「微妙に遅れる」は、わずかに、という意味で、よい悪いとは関係ありません。辞書も「少々。やや」の意味を載せています。

多様な観点

日本語の調査から

2014年度の調査は、断定を避けるぼかしの言葉がどれだけ使われているかを尋ねたものです。同じ調査では、「わたし的には」を使う人が19.9%、「やばい」を「とてもすばらしい」の意味で使う人が26.9%でした。

コミュニケーションから

「微妙」は、はっきり「だめ」と言わずに済むので、相手との関係を気にする場面で便利です。その分、言われた側は、どの程度よくないのかを推し量らなければなりません。

辞書の見方から

デジタル大辞泉は、美しさ・細かさ・少々・否定の婉曲と、四つの意味を並べています。もとの意味と新しい意味が、一つの見出しの中に同居している言葉です。

使用シーン

日常の会話からSNSまで、世代を問わず使われます。「よくない」の遠回しとしての使い方は、くだけた会話でよく見られます。

関連語
