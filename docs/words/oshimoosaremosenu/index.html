おしもおされもせぬ慣用句（連体詞的に使う）

押しも押されもせぬ

『「押しも押されもせぬ」か「押しも押されぬ」か。実は後者を使う人のほうが多い。』

誤用の定番
この言葉をシェア

おしもおされもせぬ【押しも押されもせぬ】〔句〕

  1. ①

    もともとの意味実力があって堂々としている。「押しも押されもせぬ実力者」のように、だれと並んでも引けを取らない人を言います。

  2. ②

    地位や人気が固まっている。「押しも押されもせぬ定番商品」「押しも押されもせぬ看板番組」のように、人だけでなく商品や番組にも使われます。

  3. ③

    出典から離れた使い方「押しも押されぬ」という形。「押しも押されぬスター」のように「もせ」を落とした形です。

曖昧メーター

曖昧度2/5

人によってその言葉の意味がどれだけ変わるか

誤用度5/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

実力があって、どこへ出ても圧倒されることがない、という意味の慣用句です。デジタル大辞泉は「押しも押されもせぬ財界の大立て者」という例を挙げ、同じ意味の言い方として「押すに押されぬ」を載せています。「押しも押されもせぬ第一人者」「押しも押されもせぬ人気店」のように、すでに地位が固まっている人や店をほめるときに使います。

意味の取り違えはあまりありません。ずれやすいのは形です。文化庁の「国語に関する世論調査」では、2003年度も2012年度も、本来の形ではない「押しも押されぬ」を使う人のほうが多いという結果が出ました。2012年度は「押しも押されもせぬ」が41.5％、「押しも押されぬ」が48.3％です。

意味はほぼ同じように伝わる一方で、「押しも押されもせぬ」と「押しも押されぬ」のどちらが正しいかについて、使う人の感覚と辞書の判断がずれている言葉です。

あなたはどの意味派？

あなたは「押しも押されもせぬ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    実力があって堂々としている

    「押しも押されもせぬ実力者」のように、だれと並んでも引けを取らない人を言います。

  2. 拡張広がった使い方

    地位や人気が固まっている

    「押しも押されもせぬ定番商品」「押しも押されもせぬ看板番組」のように、人だけでなく商品や番組にも使われます。

  3. 誤用寄り出典から離れた使い方

    「押しも押されぬ」という形

    「押しも押されぬスター」のように「もせ」を落とした形です。使う人は多いものの、多くの辞書や新聞は本来の言い方ではないとしています。

語源・成り立ち

「押しても押されもしない」、つまり押しても動かず、押されても負けない、という意味の言い回しです。辞書編集者の神永曉さんによると、『日本国語大辞典』では、この本来の形の用例は江戸時代から見られます。

一方の「押しも押されぬ」は、『日本国語大辞典』では織田作之助の小説『夫婦善哉』（1940年）の「半年経たぬ内に押しも押されぬ店となった」が最も古い用例です。『明鏡国語辞典』は菊池寛の用例を挙げ、古くから使われていると述べています。

「押しも押されぬ」が広まった理由のひとつは、同じ意味の「押すに押されぬ」と混ざったことだとされています。

広まった経緯

  1. 江戸時代

    「押しも押されもせぬ」の用例が見られる（日本国語大辞典による。ジャパンナレッジ）。

  2. 1940年

    織田作之助『夫婦善哉』に「押しも押されぬ店となった」という一節。日本国語大辞典で最も古い「押しも押されぬ」の例。

  3. 2003年度

    文化庁の「国語に関する世論調査」で、「押しも押されもせぬ」36.9％、「押しも押されぬ」51.4％。

  4. 2012年度

    同じ調査で「押しも押されもせぬ」41.5％、「押しも押されぬ」48.3％。本来の形を使う人のほうが多かったのは60歳以上だけだった。

ズレのポイント

改まった文章では「もせぬ」まで書く

「押しも押されぬ」は使う人が多いものの、辞書や新聞の用語集では本来の言い方ではないとされることが多い形です。履歴書や挨拶文、記事などでは「押しも押されもせぬ」と書くと安心です。

「押すに押されぬ」は同じ意味

デジタル大辞泉は「押すに押されぬ」を同じ意味の言い方として載せています。「押しも押されぬ」とは別の、正しい言い方です。

新人や駆け出しには使わない

すでに実力や地位が認められている人に使う言葉です。「これから期待の新人」に使うと、意味がかみ合いません。

多様な観点

辞書から

デジタル大辞泉は「どこへ出ても圧倒されることがない。実力があって堂々としている」と説明し、補説で2012年度の文化庁の調査結果に触れています。

世代から

2012年度の調査では、20代から50代のどの世代でも「押しも押されぬ」が5割を超えました。差が大きかったのは30代で、「押しも押されもせぬ」30.6％に対して「押しも押されぬ」58.1％でした（神永曉さんの解説による）。

辞書づくりから

『日本国語大辞典』は「押しも押されぬ」を子見出しとして載せていますが、正しいかどうかの判断は示していません。元編集長の神永曉さんは、この扱いを「まずい処理であった」と振り返っています。

使用シーン

世代を問わず、人物の紹介やスポーツ・芸能の記事、商品の宣伝などで使われます。話し言葉では「押しも押されぬ」の形もよく耳にします。

関連語

  • 押すに押されぬ同じ意味の言い方。「押しも押されぬ」が生まれるもとになったとされる。
  • 第一人者その分野でいちばん優れている人。「押しも押されもせぬ第一人者」とよく組み合わせて使われる。
  • 汚名返上「汚名挽回」との混同が話題になる、形の取り違えの定番。
