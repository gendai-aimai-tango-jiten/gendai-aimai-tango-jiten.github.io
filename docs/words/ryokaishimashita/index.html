曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

「了解しました」は、相手の話や頼みごとを理解し、受け入れたことを伝える返事です。デジタル大辞泉は「了解」を、物事の内容や事情を理解して承認すること、と説明し、「お申し越しの件を了解しました」という例を挙げています。言葉の意味のうえでは、目上の人に使ってはいけないという決まりはありません。

ところが、いまのビジネスマナーの解説では、「了解しました」は目上の人には避け、「承知しました」「かしこまりました」を使うようにと書かれることが多くなりました。J-CASTニュースの2024年の記事は、この説が広がったのは2007〜11年ごろとみられると報じています。記事の中で、国語辞典の編集委員は、後から生まれた言説だろうと話しています。

同じ「了解しました」を、ていねいな返事と受け取る人もいれば、目上に対してなれなれしいと受け取る人もいます。失礼のないふつうの丁寧語なのか、目上には使えない言い方なのか。言葉そのものより、受け取る側のマナー観で評価が分かれる言葉です。

あなたはどの意味派？

あなたは「了解しました」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    理解して受け入れる

    「ご依頼の件、了解しました」のように、内容をわかったうえで認めることを伝えます。「了解いたしました」と、へりくだった形でも使われてきました。

  2. 拡張広がった使い方

    短い合図の「了解」

    無線のやりとりや、同僚どうしのチャットの「了解です」「りょ」のように、受け取ったことだけを短く伝える使い方です。気軽な場面では便利ですが、事務的に聞こえることもあります。

  3. 誤用寄り出典から離れた使い方

    目上には失礼な言葉

    「了解は目上が目下に使う言葉だから、上司には失礼」という受け取り方です。マナーの解説では広く書かれていますが、辞書にはこの説明はありません。

語源・成り立ち

「了」は、終わる、はっきりわかること、「解」は、とき明かすことを表します。『日本国語大辞典』は、江戸時代後期の蘭学の入門書『蘭学階梯』に、読み返せば自然にわかる、という意味の「了解」の用例を挙げています。

「了解」は、ドイツの哲学者ディルタイの用語 Verstehen の訳語としても使われました。日常の返事としての「了解しました」が目上に失礼かどうかが話題になるのは、ずっと後の2000年代後半からです。

広まった経緯

  1. 江戸時代後期

    『蘭学階梯』に、よくわかるという意味の「了解」の用例がある（『日本国語大辞典』）。

  2. 2009年3月

    日本経済新聞の記事に、「了解です」は「承知しました」「かしこまりました」が正しいという記述が載ったと報じられている。

  3. 2011年ごろ〜

    「了解」と「承知」を区別すべきだとする記事が増え始めたと報じられている。

  4. 2024年

    J-CASTニュースが、「了解です」はいつから失礼とされたのかを国語辞典の編集委員に取材する。

ズレのポイント

相手の受け取り方に合わせる

辞書のうえでは失礼な言葉ではありませんが、失礼だと感じる人がいるのも事実です。取引先や目上の人には「承知しました」を使うと、余計な気をもませずに済みます。

「承知しました」は謙譲を含む

「承知しました」には、へりくだる気持ちが含まれます。「了解しました」はふつうの丁寧語なので、意味は同じでも、相手を立てる度合いが違うと考えられています。

部下の「了解です」を責めすぎない

「了解しました」を失礼と習っていない人もいます。言葉の誤りとして叱るより、職場での使い分けとして伝えるほうが角が立ちません。

多様な観点

辞書の見方から

J-CASTニュースの記事によると、三省堂国語辞典は「了解」の項で、目上に失礼な語と言う人がいるが、以前から丁重な表現として使われてきたと書いています。辞書は、マナー本よりもゆるやかに見ています。

ビジネスマナーから

マナーの解説記事の多くは、目上には「承知しました」「かしこまりました」をすすめています。理由として、「了解」は上の立場の人が使う言葉だった、と説明するものもありますが、その根拠は示されていないことがほとんどです。

広まった背景から

記事の中で辞典の編集委員は、スマートフォンが広まり、ビジネスメールに触れる時間が長くなったことで、マナーへの関心が高まったのではないかと推測しています。

使用シーン

職場のメールやチャット、電話の返事で毎日のように使われます。目上に失礼だと考えるかどうかは、職場や世代、受けたマナー研修によって違います。

関連語

  • 割愛本来の意味と、ビジネスでの使われ方がずれている言葉。
