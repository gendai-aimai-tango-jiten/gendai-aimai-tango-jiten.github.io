ろうばしん【老婆心】〔名〕

  1. ①

    もともとの意味師が弟子を導く親身な心。禅の言葉としての意味です。

  2. ②

    助言の前置き（へりくだり）。「老婆心ながら」と前に置いて、出過ぎた助言かもしれないと断る使い方です。

  3. ③

    お節介・余計なお世話。人のふるまいを指して「それは老婆心だよ」と言うと、要らない世話という批判の意味になります。

  4. ④

    出典から離れた使い方目上への助言の前置き。上司や取引先に「老婆心ながら」と言う例です。

曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

必要以上に世話をやこうとする自分の気持ちを、へりくだって言う言葉です。「老婆心ながら申し上げますと」のように、助言や忠告の前に置いて「出過ぎたことかもしれませんが」という気持ちを表します。デジタル大辞泉は、もとの意味を「年とった女性が、度を越してあれこれと気を遣うこと」と説明しています。

もとは仏教の言葉です。精選版 日本国語大辞典は、老婆が子や孫をいつくしむように、師が弟子をいつくしみ導く親身な心遣い、と説明しています。この由来を重く見て、「お節介の意味で使うのは誤りで、人を深く思いやる心のことだ」と書くコラムもあります。一方で、辞書は「へりくだっていう語」の意味もあわせて載せています。

言う人は「親身な助言です」と控えめに伝えたつもりでも、聞く人は「これからお節介を言われる」と身構えることがあります。

あなたはどの意味派？

あなたは「老婆心」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    師が弟子を導く親身な心

    禅の言葉としての意味です。老婆が孫をかわいがるように、細かいところまで気を配って教え導く心のことです。

  2. 拡張広がった使い方

    助言の前置き（へりくだり）

    「老婆心ながら」と前に置いて、出過ぎた助言かもしれないと断る使い方です。今はこちらがよく使われます。

  3. 拡張広がった使い方

    お節介・余計なお世話

    人のふるまいを指して「それは老婆心だよ」と言うと、要らない世話という批判の意味になります。

  4. 誤用寄り出典から離れた使い方

    目上への助言の前置き

    上司や取引先に「老婆心ながら」と言う例です。年長の人が目下に言う響きがあるため、相手を下に見ているように聞こえることがあります。

語源・成り立ち

禅の言葉「老婆心切（ろうばしんせつ）」から来ています。精選版 日本国語大辞典は、中国の禅の記録『景徳伝燈録』を文献に挙げています。日本では、道元の教えを弟子がまとめた『正法眼蔵随聞記』（1235〜38年）に「慈悲心・老婆心にて能教訓誘引すべき也」とあり、師が弟子を教え導くときの心として使われています。

江戸時代の読本『椿説弓張月』（1807〜11年）にも「作者の老婆心のみ」という用例があり、書き手が読者に気を配る意味でも使われています。坪内逍遙の『小説神髄』（1885〜86年）にも「老婆心切にいでたる事にて」とあります。

広まった経緯

  1. 1235〜38年

    『正法眼蔵随聞記』に、師が弟子を導く心として「老婆心」が出てくる（日本国語大辞典の初出の例）。

  2. 1807〜11年

    曲亭馬琴の読本『椿説弓張月』に「作者の老婆心のみ」と出てくる。

  3. 1885〜86年

    坪内逍遙『小説神髄』に「老婆心切にいでたる事にて」と出てくる。

ズレのポイント

目上の人には使わない

「老婆心」は年長の人が目下に向けて言う響きがあります。上司や取引先には「僭越ながら」「差し出がましいようですが」と言い換えるほうが無難です。

男性が使ってもよい

「老婆」の字が入っていますが、言う人の性別は問いません。「老爺心」という言葉はありません。

人を責める言葉にしない

自分の気持ちをへりくだって言うのが本来の形です。人の親切を「老婆心だ」と言うと、相手を見下すように聞こえます。

多様な観点

禅の言葉から

もとは、師が弟子を細かく気にかけて教え導くことでした。お節介とは逆の、ほめる意味で使われていた言葉です。

職場の会話から

「老婆心ながら」のあとには、耳の痛い忠告が続くことが多くなります。言われた側は、まずお礼を返すのが角の立たない受け方だと紹介されています。

似た言葉との違いから

「余計なお世話」「おせっかい」は、要らない世話だと突き放す言葉です。「老婆心」は、相手のためを思う親切心が土台にあるぶん、受け取り方が分かれます。

使用シーン

年長者からの手紙やメール、職場での助言、エッセイの前置きなどで使われます。話し言葉より書き言葉で多く見かけます。

関連語

  • ご自愛ください相手を気づかう決まり文句。目上にも使える。
  • 忖度相手の気持ちを推し量ること。気を回す点でつながる。
  • 情けは人のためならず人への親切をめぐる言葉で、意味の取り違えが多い。
