曖昧メーター

曖昧度3/5

どういう意味？

「伏線」は、小説や戯曲などで、あとに述べる事柄の準備として、関連した事柄を前のほうでほのめかしておくことです。その伏線が、物語の終盤などで意味を持って明かされることを「伏線回収」と言います。

2020年代には、ドラマの伏線を視聴者がSNSで予想し合う「考察」が広まり、「伏線回収がすごい」は作品をほめる決まり文句になりました。さらに、昔の出来事が今になって役に立った、ずっと前の会話が思わぬ形でつながった、という日常の場面でも「伏線回収」と言うようになっています。

作者が仕込んだ仕掛けが明かされることなのか、たまたま起きた出来事があとでつながることなのか。物語の言葉として使う人と、日常の偶然を楽しむ言葉として使う人とで、「伏線」が誰かの意図で置かれたものかどうかが違います。

あなたは「伏線回収」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    物語の仕掛けが明かされる

    小説や映画、ドラマで、前のほうに置かれた描写やせりふが、あとで重要な意味を持つことです。作者が意図して仕込んだものを指します。

  2. 拡張広がった使い方

    作品をほめる言葉

    「伏線回収が見事だった」のように、構成のうまさをほめる言葉として使われます。感想やレビューでよく見かけます。

  3. 拡張広がった使い方

    日常の出来事のつながり

    「学生時代のバイト経験がここで伏線回収された」のように、過去の出来事があとで役立ったり、意味を持ったりすることを言う使い方です。

  4. 誤用寄り出典から離れた使い方

    予想どおりの展開

    誰でも先が読める分かりやすい予告が、そのとおりになったことを「伏線回収」と呼ぶ使い方です。こうしたものは「フラグ」と呼んで区別する人もいます。

語源・成り立ち

「伏線」は、もとは文章の技法を指す言葉です。精選版 日本国語大辞典は、曲亭馬琴の『南総里見八犬伝』（1814〜42年）に「伏線」を説明した一節があることを、初出の実例として挙げています。

「回収」は、配ったものや出したものを集めて戻すことです。物語の初めに「張った」伏線を、終盤で「回収する」という言い方が組み合わさり、「伏線回収」という形で使われるようになりました。

広まった経緯

  1. 江戸時代後期

    『南総里見八犬伝』に、文章技法としての「伏線」を説明した一節がある。

  2. 1899年

    福沢諭吉の『福翁自伝』に、後の事に備えて設けておく意味の「伏線」の用例がある。

  3. 2020年代

    ドラマの伏線を視聴者がSNSで予想し合う「考察」が広まり、「伏線回収」が作品の感想でよく使われる。

  4. 2022年

    朝の連続テレビ小説『カムカムエヴリバディ』の終盤の展開が、「伏線回収」として話題になる。

ズレのポイント

偶然と仕掛けは違う

物語の伏線は、作者が意図して置いたものです。日常の出来事を「伏線回収」と言うのは、偶然のつながりを物語にたとえた言い方です。

伏線とフラグは別のもの

伏線は気づかれにくく置かれ、あとで驚きを生むもの、フラグは「この人物はこうなりそう」と予想できる分かりやすい印、と分けて使う人がいます。何でも伏線と呼ぶと、こうした人には違和感があります。

回収されない伏線もある

物語の途中で終わったり、あえて説明しなかったりして、伏線が明かされないまま終わる作品もあります。「伏線が回収されていない」は、不満として言われることも、余韻として受け取られることもあります。

多様な観点

書き手から

伏線は、もともと書き手の腕の見せどころとされる技法です。気づかれにくく置き、あとで意味が分かったときの驚きが大きいほど、作品の魅力になると考えられてきました。

視聴者から

ドラマ評の記事では、最近の視聴者は回収される前の伏線を見抜くことを楽しむ傾向があると指摘されています。SNSで考察を書き合うことが、ドラマの楽しみ方の一つになりました。

日常の言葉から

「人生の伏線回収」という言い方は、過去の経験に意味を見いだす前向きな言い方として使われます。物語の言葉を借りることで、偶然のつながりを少し楽しく語れるようになります。

使用シーン

ドラマや映画、アニメ、漫画の感想を書く人を中心に、SNSやレビューで広く使われます。仕事や人生の振り返りでも、過去の経験が役に立った場面を言うときに使われます。

関連語

  • 沼る作品に深くはまること。考察を楽しむ人がよく使う。
  • 黒歴史過去の出来事をあとから振り返る言葉。
