曖昧メーター

曖昧度5/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度2/5

他の世代や別の界隈にも通じるか

どういう意味？

英語の purpose は「目的」という意味ですが、ビジネスでは、企業が社会の中で「なぜ存在するのか」「何のために事業をするのか」という存在意義を指す言葉として使われます。

2020年前後から、利益を追うだけでなく、社会にどう貢献するかを経営の軸にする「パーパス経営」が日本の大企業で広まりました。多くの企業が自社のパーパスを策定し、ウェブサイトや統合報告書に掲げています。

ところが、ミッション（使命）、ビジョン（目指す姿）、経営理念と何が違うのかは、企業によって説明がまちまちです。言葉を掲げただけで社員に浸透しない「形骸化」も多く指摘されています。

あなたはどの意味派？

あなたは「パーパス」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    目的

    英語の purpose のもとの意味で、何かをする目的や意図のことです。

  2. 拡張広がった使い方

    企業の社会的な存在意義

    「私たちのパーパスは〇〇です」のように、企業が社会に対して果たす役割や、存在する理由を示す言葉です。いまのビジネスでの主な使い方です。

  3. 拡張広がった使い方

    個人の生きる目的

    「個人のパーパスを見つける」のように、働く人一人ひとりの価値観や生きがいを指す使い方も広がっています。

  4. 誤用寄り出典から離れた使い方

    理念やスローガンの言い換え

    従来の経営理念やキャッチコピーを、中身を変えずに「パーパス」と呼び替えるだけの使い方です。形骸化の原因として批判されます。

語源・成り立ち

英語の purpose（目的、意図）から来ています。欧米の経営論で、2010年代後半から企業の存在意義を表す言葉として注目され、2019年にはアメリカの経営者団体が「株主第一主義」を見直す声明を出したことも、流れを後押ししました。

日本では2020年前後から、ESG投資やSDGsへの関心の高まりとともに、大企業を中心に「パーパス経営」が広まりました。

広まった経緯

  1. 2010年代後半

    欧米の経営論で、企業の存在意義を表す purpose が注目される。

  2. 2019年

    アメリカの経営者団体が、株主だけでなく社会全体への責任を重視する声明を出す。

  3. 2020年前後〜

    日本の大企業で「パーパス経営」が広まり、パーパスの策定が相次ぐ。

  4. 2020年代半ば

    パーパスが社員に浸透しない「形骸化」が課題として語られるようになる。

ズレのポイント

ミッション・ビジョンとの違いがあいまい

一般には、パーパスは「なぜ存在するか」、ミッションは「何をするか」、ビジョンは「どんな未来を目指すか」と説明されます。ただし企業によって使い分けが違い、言葉だけ増えて分かりにくくなることがあります。

掲げるだけでは意味がない

パーパスを策定しても、日々の判断や評価制度と結びついていなければ、社員には「壁に貼ってある言葉」にしかなりません。

日本語の「目的」とは響きが違う

英語のままの「パーパス」は、日本語の「目的」より大きく、理念的な意味で使われます。日常の「目的」と混同すると話がかみ合いません。

多様な観点

経営学から

企業の目的は利益を最大化することだ、という考えに対して、社会の課題を解決することこそが企業の存在理由だ、という考えが広まりました。パーパスは、その変化を象徴する言葉です。

働く人から

若い世代ほど、給料だけでなく、仕事の社会的な意味を重視すると言われます。採用の場でもパーパスが打ち出されるのは、そうした価値観に応えるためでもあります。

言葉の流行から

経営の世界では、新しいカタカナ語が数年ごとに流行します。パーパスもその一つで、言葉が先行して中身が追いつかない、という批判は流行語の宿命とも言えます。

使用シーン

大企業の経営者、広報、人事担当者を中心に使われます。統合報告書、採用ページ、ビジネス書、研修などでよく見かける言葉で、一般の人にはまだあまりなじみがありません。

関連語

  • リスキリング新しい仕事のためのスキル獲得。同じ時期に広まったビジネス用語。
  • ウェルビーイング心身ともに満たされた状態。パーパスと並べて語られる。
  • 多様性企業が重視する価値として、パーパスと並べて掲げられることが多い。
