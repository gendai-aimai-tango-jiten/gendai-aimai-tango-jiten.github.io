曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

「失念」は、うっかり忘れることです。デジタル大辞泉は「うっかり忘れること。ど忘れ。物忘れ」と説明し、「約束を失念して失礼しました」という例を挙げています。いまは、ビジネスの謝罪で「失念しておりました」と使うのが、いちばんよく見かける形です。

この「失念しておりました」について、解説記事の説明は分かれています。マイナビニュースの記事は「忘れていた」の謙譲語にあたると説明しています。一方、Precious.jpの記事は、敬語としてのていねいさを生んでいるのは後ろの「しておりました」の部分だと説明しています。辞書の意味を見るかぎり、「失念」という言葉そのものには、へりくだる意味は含まれていません。

そのため、「失念」と言えば謝ったことになる、言いかえれば失礼にならない、と受け取る人もいれば、ただの「忘れた」を硬く言っただけだと受け取る人もいます。うっかり忘れたことを表すだけの言葉なのか、それ自体がへりくだった謝罪の言葉なのか。使う側と受け取る側で、言葉に込める重さがずれやすい言葉です。

あなたはどの意味派？

あなたは「失念」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    うっかり忘れること

    「会議の時間を失念していた」のように、覚えていたはずのことを忘れることを表します。改まった場面や書き言葉で使われることが多い言葉です。

  2. 拡張広がった使い方

    謝罪の決まり文句

    「確認を失念しておりました。申し訳ございません」のように、ビジネスメールの謝罪で使う形です。「忘れていました」よりも改まった印象になるため、取引先や上司への連絡でよく使われます。

  3. 誤用寄り出典から離れた使い方

    言葉自体が謙譲語という理解

    「失念」を「忘れる」の謙譲語と考え、「失念」と書けば謝罪になると受け取る使い方です。マイナビニュースの記事も、謝罪の言葉と一緒に使うよう勧めています。

語源・成り立ち

「失」は失うこと、「念」は心にとどめること、思いのことです。『日本国語大辞典』によると、仏教の言葉としては梵語 muṣita-smṛtiḥ の訳語で、記憶をさまたげる心の働きを指し、二十随煩悩の一つに数えられます。平安時代の源信の『往生要集』（984〜985年）に用例があります。

「うっかり忘れること」の意味でも古くから使われ、『日本国語大辞典』は平安時代末の日記『山槐記』の1167年の記事や、夏目漱石の『坊っちゃん』（1906年）の「只今一寸失念して言ひ落しましたから」を挙げています。

広まった経緯

  1. 984〜985年

    源信の『往生要集』に、仏教の言葉としての「失念」の用例がある（『日本国語大辞典』）。

  2. 1167年

    『山槐記』に、うっかり忘れる意味の「失念」の用例がある（同）。

  3. 1906年

    夏目漱石の『坊っちゃん』で、登場人物が「只今一寸失念して」と話す（同）。

  4. 2020年12月

    マイナビニュースが「失念しておりました」の使い方の記事を載せ、「忘れていた」の謙譲語にあたると説明する。

ズレのポイント

「失念」だけでは謝罪にならない

「失念しておりました」は、忘れていたという事実を伝える言葉です。相手に迷惑をかけたときは、「申し訳ございません」などの謝罪の言葉を添えます。

知らなかったことには使わない

「失念」は、覚えていたはずのことを忘れたときの言葉です。もともと知らされていなかったことに使うと、知っていたのに忘れたという意味になってしまいます。

相手の「忘れた」に使うときは気をつける

「ご失念ですか」のように相手に向けて使うと、言い方はていねいでも、忘れたことを責めているように聞こえることがあります。「念のためお知らせします」のような言い方のほうが角が立ちません。

多様な観点

敬語の見方から

敬語の働きを分けて考えると、「失念」は「忘れる」を漢語にした言い方で、へりくだりを表すのは「おる」の部分です。Precious.jpの記事も、この点を説明しています。

ビジネスの実際から

メールでは「忘れていました」より角が立ちにくく、使いやすい言葉です。ただ、同じ相手に何度も使うと、決まり文句として軽く受け取られることもあります。

仏教の見方から

仏教では、心が散って大事なことを保てない状態を「失念」と呼び、煩悩の一つに数えます。いまの「うっかり忘れ」の意味とは、重さがかなり違います。

使用シーン

ビジネスメールや、改まった謝罪の場面でよく使われます。話し言葉ではあまり使わず、学生や若い世代では、社会人になってから覚える人も多い言葉です。
