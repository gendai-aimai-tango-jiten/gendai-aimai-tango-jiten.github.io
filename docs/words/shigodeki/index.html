曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

「仕事ができる」「仕事ができる人」を縮めた言葉です。「あの先輩、しごできすぎる」「しごでき上司」のように使います。

ここでいう「仕事」は会社の業務に限りません。飲み会の幹事をそつなくこなす、友だちの誕生日会を段取りよく準備する、といった場面でも「しごでき」と言います。

成果を出す人なのか、段取りや気配りが上手な人なのか、仕事ができそうに見える人なのか。ほめているポイントが人によって違うのが、この言葉のあいまいなところです。

あなたはどの意味派？

あなたは「しごでき」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    仕事の能力が高い人

    業務を早く正確にこなし、成果を出せる人。「仕事ができる」をそのまま縮めた意味です。

  2. 拡張広がった使い方

    段取りや気配りが上手な人

    先回りして準備する、相手の求めることに気づく、といった気配りや段取りの上手さを指します。職場以外の場面でも使われます。

  3. 拡張広がった使い方

    ちょっとした行動へのほめ言葉

    「返信が早くてしごでき」「お店の予約ありがとう、しごでき」のように、小さな気の利いた行動を軽くほめるときに使われます。

  4. 誤用寄り出典から離れた使い方

    仕事ができそうな雰囲気

    「しごでき風コーデ」「しごできっぽい人」のように、実際の仕事ぶりではなく見た目や雰囲気を指す使い方です。能力の話からは離れています。

語源・成り立ち

「仕事」の「しご」と「できる」の「でき」をつなげた略語です。「きもかわ（気持ち悪いけどかわいい）」のように、言葉の頭をつなげて縮める、若者言葉によくある作り方です。

2023年版の『現代用語の基礎知識』に掲載され、2024年には三省堂「今年の新語2024」のベスト10にも選ばれました。

広まった経緯

  1. 2020年代前半

    SNSで、仕事ぶりのよい人をほめる言葉として使われ始める。

  2. 2022年11月

    『現代用語の基礎知識2023』に掲載される。

  3. 2024年12月

    三省堂「辞書を編む人が選ぶ『今年の新語2024』」のベスト10に選ばれる（大賞は「言語化」）。

ズレのポイント

目上の人に使うと軽く聞こえる

ほめ言葉ですが、略語のくだけた響きがあります。上司や取引先に「しごできですね」と直接言うと、評価しているような、からかっているような印象を与えることがあります。

「しごでき」の基準は人それぞれ

早さを評価する人もいれば、丁寧さや気配りを評価する人もいます。同じ人を見ても「しごでき」と言うかどうかは分かれます。

雰囲気だけの「しごでき」

SNSでは「しごできそうな見た目」「しごでき風の話し方」のように、実際の能力と関係なく雰囲気を指す使い方も広がっています。ほめているのか、皮肉なのか、文脈で判断が必要です。

多様な観点

職場の文化から

「仕事ができる人」を一言で軽くほめられる言葉が生まれたことで、同僚どうしで気軽に評価し合う空気が生まれた、という見方があります。一方で、評価を短い言葉で片づけてしまう面もあります。

言語学から

「しごでき」は名詞としても「しごできな人」のように形容動詞としても使われます。反対の意味の「しごできない」はあまり使われず、ほめ言葉として定着しているのが特徴です。

SNSの文化から

「〇〇な先輩がしごできすぎる」という投稿は、具体的なエピソードとセットで共有されやすく、職場あるあるの話題として広がりました。

使用シーン

20代から30代の会社員を中心に、XやInstagram、職場の雑談で使われます。テレビ番組や広告のキャッチコピーにも使われるようになりました。

関連語

  • 地頭知識ではなく、もとの頭のよさを指す言葉。「しごでき」と並べて語られることがある。
