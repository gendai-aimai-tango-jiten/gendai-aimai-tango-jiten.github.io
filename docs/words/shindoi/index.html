曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

体が疲れてつらい、気持ちが重くてつらい、手間がかかって大変だ、という意味の形容詞です。「階段がしんどい」「人間関係がしんどい」「この作業、しんどいな」のように使います。

もとは関西の方言でしたが、テレビなどを通じて全国に広まりました。いまでは、体の疲れ、心のつらさ、面倒くささ、体調の悪さまで、さまざまな「つらさ」をまとめて表す言葉になっています。

さらに推し文化では、「推しが尊すぎてしんどい」「このシーンしんどい」のように、好きすぎて、感動しすぎて苦しいという、喜びの表現としても使われます。本当につらいのか、うれしすぎるのかは、文脈で判断する必要があります。

あなたはどの意味派？

あなたは「しんどい」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    体が疲れてつらい

    「一日立ちっぱなしでしんどい」のように、体の疲れや体調の悪さを表します。関西でもとから使われてきた意味です。

  2. 拡張広がった使い方

    心がつらい・気が重い

    「人間関係がしんどい」のように、精神的な疲れやつらさを表す使い方です。

  3. 拡張広がった使い方

    手間がかかって面倒

    「この書類をそろえるの、しんどい」のように、骨が折れること、面倒なことを表します。

  4. 拡張広がった使い方

    好きすぎて苦しい（推し文化）

    「推しの新曲がよすぎてしんどい」のように、感情が大きくなりすぎて苦しいほど、という喜びの表現です。

語源・成り立ち

「しんど」という関西方言に、形容詞の語尾「い」が付いた言葉とされます。「しんど」の語源については、「心労（しんろう）」から来たとする説などがありますが、はっきりしていません。

関西の芸人がテレビで使ったことなどもあり、全国に広まりました。体調が悪いときに使う言葉を調べた調査では、「えらい」に次いで「しんどい」が多いという結果も報じられています。

広まった経緯

  1. 昔から

    関西方言として、疲れてつらいことを表す言葉として使われる。

  2. 昭和〜平成

    テレビなどを通じて全国に広まり、共通語のように使われるようになる。

  3. 2010年代〜

    推し文化で、「好きすぎて苦しい」という喜びの意味でも使われるようになる。

ズレのポイント

本当にしんどい人を見逃さない

「しんどい」は軽い疲れから深刻なつらさまで使われます。口ぐせのように聞こえても、本当に追い詰められている場合もあるので、周りの人は気にかけることが大切です。

推し文化の「しんどい」は喜び

推し活の投稿の「しんどい」は、多くの場合ほめ言葉です。文字どおりに受け取って心配すると、話がかみ合わないことがあります。

改まった場では言い換える

くだけた言葉なので、仕事の場では「負担が大きい」「体調がすぐれない」などと言い換えると伝わりやすくなります。

多様な観点

方言から

しんどいは、関西方言が全国に広まった代表的な言葉の一つです。「めっちゃ」「あかん」なども、テレビを通じて全国で使われるようになりました。

推し文化から

推しへの気持ちを表すとき、「しんどい」「無理」「死ぬ」など、本来はネガティブな言葉が、喜びを表すのに使われます。感情の大きさを強く伝えるための言葉の工夫です。

心の健康から

「つらい」と言うより「しんどい」と言うほうが口にしやすい、という人もいます。弱音を吐きやすい言葉として、心の不調のサインになることもあります。

使用シーン

世代を問わず、日常会話、SNS、推し活の投稿などで広く使われます。

関連語

  • 尊い推しへの最上級のほめ言葉。「尊すぎてしんどい」と一緒に使われる。
  • 詰んだもう打つ手がない、という意味の言葉。
  • ぴえんちょっと悲しい気持ちを表す言葉。しんどいより軽い。
