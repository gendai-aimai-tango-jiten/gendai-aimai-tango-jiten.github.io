曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

人を外見で判断し、外見によって評価や扱いに差をつけることです。英語の looks（見た目）と ism（主義）を組み合わせた lookism から来ていて、「外見至上主義」「外見による差別」と訳されます。

1970年代のアメリカで、太っていることを理由にした差別に抗議する運動の中で使われたのが始まりとされます。日本では2020年代に入って広まり、2022年には新語・流行語大賞にノミネートされました。

容姿をけなすことがルッキズムにあたるのは分かりやすいですが、「かわいいね」「イケメン」といったほめ言葉もルッキズムなのかについては、人によって考え方が分かれます。

あなたはどの意味派？

あなたは「ルッキズム」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    外見による差別

    採用、昇進、扱いなどで、外見が良いか悪いかによって人を差別することです。

  2. 拡張広がった使い方

    外見を重視する社会の価値観

    美しい外見を過度に重んじ、人を外見で評価する社会全体の風潮を指す使い方です。

  3. 拡張広がった使い方

    容姿へのコメント全般

    相手の容姿をけなすことに加え、ほめることも含めて、外見について口にすること全般を問題にする使い方です。

  4. 誤用寄り出典から離れた使い方

    おしゃれや美容を否定する言葉

    外見に気を使うことや、美容を楽しむこと自体を「ルッキズム」と批判する使い方です。問題は外見で人を判断・差別することで、外見を楽しむことではありません。

語源・成り立ち

英語の lookism から来ています。racism（人種差別）や sexism（性差別）と同じように、「〜による差別」を表す -ism を looks（見た目）に付けた言葉です。

1970年代のアメリカで、肥満を理由にした差別に抗議する運動の中で使われたのが始まりとされます。日本では、2021年に三省堂国語辞典に新語として収録され、2022年には新語・流行語大賞にノミネートされました。

広まった経緯

  1. 1970年代

    アメリカで、体型による差別に抗議する運動の中で lookism という言葉が使われる。

  2. 2020年前後

    日本で、ミスコンや広告の表現、容姿いじりへの批判とともにルッキズムという言葉が広まる。

  3. 2021年12月

    三省堂国語辞典 第八版に新語として収録される。

  4. 2022年

    「ルッキズム」が2022ユーキャン新語・流行語大賞にノミネートされる。

ズレのポイント

ほめ言葉はルッキズムか

容姿をほめることも、外見で人を評価している点では同じだ、という考えがあります。一方で、ほめ言葉まで問題にするのは行き過ぎだ、という考えもあり、意見が分かれています。

美容やおしゃれを否定する言葉ではない

ルッキズムが問題にしているのは、外見によって人を判断し、差別することです。自分の外見を整えたり、楽しんだりすること自体を否定する言葉ではありません。

見た目の話を一切しない、ではない

外見について話すことすべてがルッキズムになるわけではありません。相手が望まない評価や、外見による扱いの差が問題になります。

多様な観点

社会から

テレビのお笑いでの容姿いじりや、外見を重視する広告、ミスコンテストなどが、ルッキズムの観点から見直されるようになりました。

心理学から

外見が良い人を、性格や能力まで良いと思い込む傾向（ハロー効果）は、心理学でも知られています。ルッキズムは、こうした無意識の判断とも結びついています。

SNSの文化から

加工された写真があふれるSNSでは、外見への比較や評価が絶えず起きます。ルッキズムという言葉が広まった背景には、SNSでの外見へのプレッシャーがあります。

使用シーン

10代から40代を中心に、SNS、ニュース、テレビ番組の議論などで使われます。

関連語

  • アンコンシャス・バイアス無意識の思い込み。外見への思い込みもその一つ。
  • 多様性さまざまな人が共にいること。外見の多様性も含まれる。
  • 映えSNSで見栄えがすること。外見重視の風潮と結びつけて語られる。
  • メロい相手の魅力にときめく言葉。外見の評価になりやすい点で関わる。
