曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

「ハラスメント（嫌がらせ）」を縮めた「ハラ」の前に言葉を付けて、ある種類の嫌がらせを呼ぶ言い方です。セクハラ（性的な嫌がらせ）、パワハラ（立場を利用した嫌がらせ）、モラハラ（精神的な嫌がらせ）などがよく知られています。

中小企業基盤整備機構の資料によると、ハラスメントという言葉が広まったのは、「セクシャルハラスメント」が流行語大賞になった1989年ごろです。2001年には「パワーハラスメント」が一般の言葉として広まり、そのあとさまざまなハラスメントの呼び名が登場しました。現在では30種類以上あるといわれます。厚生労働省は、パワハラについては2020年6月から、カスタマーハラスメント（客などからの嫌がらせ）については2026年10月から、事業主に対策を義務づけています。

一方で、「〇〇ハラ」は会話の中でも気軽に作られます。法律で対策が決められた深刻なものと、冗談まじりの「〇〇ハラ」が同じ形で並んでいます。人の尊厳や働く環境を傷つける行為なのか、されて嫌だったこと全般なのか。どこまでを「ハラ」と呼ぶかが、人によってずれています。

あなたはどの意味派？

あなたは「〇〇ハラ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    職場などでの嫌がらせ

    セクハラ、パワハラ、妊娠・出産をめぐる嫌がらせなど、働く人の尊厳や環境を傷つける行為です。法律や行政の指針で決められているものもあります。

  2. 拡張広がった使い方

    新しい種類の嫌がらせへの名前

    客からの理不尽な要求を「カスハラ」と呼ぶように、それまで名前のなかった困りごとに名前を付け、問題として見えるようにする使い方です。

  3. 拡張広がった使い方

    冗談まじりの「〇〇ハラ」

    においの「スメハラ」のように、身近な不快を半分冗談で呼ぶ言い方です。行政が定義したものではありません。

  4. 誤用寄り出典から離れた使い方

    気に入らないことへのレッテル

    注意や意見の違いまで「それ〇〇ハラ」と呼ぶ使い方です。反対に、何でもハラスメントだと騒ぐことを「ハラハラ（ハラスメント・ハラスメント）」と呼ぶ言葉まで生まれています。

語源・成り立ち

英語の「harassment（嫌がらせ、悩ませること）」を縮めた「ハラ」に、種類を表す言葉を付けた形です。「セクハラ（sexual harassment）」「パワハラ（power harassment）」のように、前の語も縮めて付けるものが多くあります。

「パワーハラスメント」は、コンサルティング会社の提唱から2001年ごろに広まった言葉とされています。この形が定着したことで、日本語の中で新しい「〇〇ハラ」が作られやすくなりました。

広まった経緯

  1. 1989年

    「セクシャルハラスメント」が新語・流行語大賞に選ばれ、ハラスメントという言葉が広まる。

  2. 2001年

    コンサルティング会社の提唱から「パワーハラスメント」が一般の言葉として広まる。

  3. 2020年6月

    パワーハラスメント対策が事業主の義務になる。

  4. 2026年10月

    カスタマーハラスメント対策が、すべての事業主の義務になる。

ズレのポイント

「ハラ」と付ければ定義があるわけではない

法律や行政の指針で決められているのは、セクハラ、パワハラ、妊娠・出産や育児・介護をめぐる嫌がらせ、カスハラなどです。ネットで作られた「〇〇ハラ」の多くには、決まった定義がありません。

相手が不快に思えば何でもハラスメント、ではない

たとえばパワハラは、立場の優位を背景にした言動で、業務に必要な範囲を超え、働く環境を害するもの、とされています。必要な注意や指導までハラスメントと呼ぶと、話がかみ合わなくなります。

冗談の「〇〇ハラ」で深刻さが薄れることもある

軽い「〇〇ハラ」が増えると、深刻な被害まで軽く受け取られるおそれがあります。どの意味で使っているかを確かめると、すれ違いが減ります。

多様な観点

職場から

会社には、パワハラやセクハラ、カスハラを防ぐための相談窓口や研修が求められています。「〇〇ハラ」という呼び名が、それまで我慢されてきた困りごとを会社で話し合うきっかけにもなっています。

言葉から

「〇〇ハラ」は、短い言葉と「ハラ」をつなぐだけで作れるため、新しい言葉が生まれやすい形です。そのぶん、定義のはっきりしたものとそうでないものが混ざっています。

される側・言われる側から

される側にとっては、名前があることで被害を説明しやすくなります。言われる側にとっては、何がいけなかったのかが分からないまま「〇〇ハラ」とまとめられると、受け止めにくいこともあります。

使用シーン

世代を問わず広く通じます。職場の研修や人事の資料、ニュース、SNSで見かけます。冗談まじりの「〇〇ハラ」は、テレビやSNSで新しく作られることが多い言葉です。

関連語

  • モラハラ言葉や態度による精神的な嫌がらせ。〇〇ハラの代表的な一つ。
  • 心理的安全性職場で安心して発言できる状態。ハラスメント対策と一緒に語られることが多い。
  • マウント相手より上に立とうとする言動。くり返されると嫌がらせとして受け取られることもある。
