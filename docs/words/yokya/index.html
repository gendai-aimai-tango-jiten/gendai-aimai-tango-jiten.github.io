曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

「陽気なキャラクター」を縮めた言葉で、明るく社交的で、人の輪の中心にいるような人を指します。「陽キャラ」とも言います。反対に、内気で目立たない人は「陰キャ」と呼ばれ、二つはたいていセットで使われます。

学生の間では、性格だけでなく、クラスの中で目立つグループにいること、いわゆるスクールカーストの上のほうにいることを指す場合もあります。九州大学の卒業論文では、高校時代のクラスの人間関係を、陰キャ・陽キャという言葉で捉えていた大学生の語りが紹介されています。

明るい性格のことなのか、教室での立ち位置のことなのか、ノリのよさや騒がしさのことなのか。あこがれにも皮肉にもなり、言う人の立場で響きが変わる言葉です。

あなたはどの意味派？

あなたは「陽キャ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    明るく社交的な性格

    初対面の人ともすぐ打ち解ける、場を盛り上げるのが得意、といった外向的な性格を指します。

  2. 拡張広がった使い方

    クラスで目立つ立場

    クラスの中で発言力のあるグループや、スクールカーストの上のほうにいる人を指す使い方です。性格とは必ずしも一致しません。

  3. 拡張広がった使い方

    あこがれ・ほめ言葉

    「陽キャになりたい」「あの人は陽キャだから頼れる」のように、うらやましさや好意を込める使い方です。

  4. 誤用寄り出典から離れた使い方

    騒がしい人への皮肉

    大声で騒ぐ、ノリを押しつける、といった人を「陽キャ」と呼んで距離を置く使い方です。明るさよりも、うるささを指しています。

語源・成り立ち

「陽気（ようき）」と「キャラクター」を縮めた「陽キャラ」を、さらに縮めた言葉です。先に広まった「陰キャ（陰キャラ）」の反対語として使われるようになりました。

ネットの掲示板やSNSで使われ始め、2010年代後半には、若者の会話や漫画、テレビでもよく聞かれるようになりました。似た言葉に「パリピ」や「ウェイ系」があります。

広まった経緯

  1. 2000年代〜2010年代

    ネットで「陰キャラ」「陰キャ」と対になる言葉として「陽キャラ」「陽キャ」が使われ始める。

  2. 2010年代後半

    若者の会話や漫画、テレビなどで広く使われるようになる。

  3. 2022年

    九州大学の卒業論文「陰キャ・陽キャの社会学」で、高校のクラスの人間関係とこの言葉の関わりが調べられる。

ズレのポイント

明るい人がみな陽キャとは限らない

一人で過ごすのが好きでも、人前では明るくふるまう人がいます。性格と、クラスでの立ち位置と、見た目のノリは、それぞれ別のものです。

ほめ言葉にも皮肉にもなる

「陽キャだね」は、言い方や相手との関係によって、ほめているようにも、からかっているようにも聞こえます。

人を二つに分ける言葉

陽キャと陰キャで人を分けると、その間にいる人や、場面によって変わる人が見えにくくなります。分けられた側が窮屈に感じることもあります。

多様な観点

心理学から

人と関わることでエネルギーを得やすい傾向は、心理学で「外向性」と呼ばれます。外向性は性格の特性の一つで、良い悪いの評価は含まれていません。

学校文化から

陽キャ・陰キャという言葉は、クラスのグループ分けやスクールカーストと結びついて使われます。九州大学の卒業論文でも、クラスの人間関係を把握するための言葉として使われていた様子が描かれています。

ネット文化から

ネットでは、自分を陰キャと呼ぶ人が多い一方、陽キャは「自分とは違う人たち」として語られがちです。そのため、陽キャという言葉には、あこがれと距離の取り方の両方が混ざります。

使用シーン

10代から20代を中心に、学校、SNS、動画配信などで使われます。漫画やアニメにもよく出てくるので、上の世代にもある程度知られています。
