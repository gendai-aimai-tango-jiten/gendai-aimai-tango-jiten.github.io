曖昧メーター

通用度4/5

どういう意味？

「ステルスマーケティング」を縮めた言葉です。「ステルス」は「隠れた」「気づかれない」という意味で、広告なのに、見る人に広告だと気づかれないように行う宣伝を指します。企業から頼まれたことを伏せて、個人の感想のように商品をほめる投稿が、よく挙げられる例です。

日本では2023年10月1日から、景品表示法の告示によってステマが禁止されました。消費者庁の説明では、事業者が表示の内容に関わっているのに、見る人が事業者の表示だと分からないものが対象です。「広告」「PR」などと書いてあれば、広告だと分かる表示として扱われます。

一方、SNSでは、もっと広い意味で使われます。「PR」と書いてある投稿や、企業と関係のない人が熱心にほめている投稿まで「ステマっぽい」と言われることがあります。広告であることを隠しているかどうかと、宣伝くさく見えるかどうか。法律の言葉とSNSの言葉で、指している範囲がずれています。

あなたはどの意味派？

あなたは「ステマ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    広告であることを隠した宣伝

    企業が費用を払ったり内容に関わったりしているのに、それを伏せて、個人の感想や口コミのように見せる宣伝です。法律で禁止されているのはこの意味です。

  2. 拡張広がった使い方

    宣伝くさい投稿への疑い

    「これステマでは？」のように、企業との関係が分からないまま、宣伝に見える投稿を疑うときに使われます。実際に広告かどうかは分かっていないことが多い使い方です。

  3. 誤用寄り出典から離れた使い方

    PRと明記した投稿

    「PR」「広告」と書いてある投稿を「ステマ」と呼ぶ使い方です。広告だと示しているので、本来のステマには当たりません。

  4. 誤用寄り出典から離れた使い方

    熱心なファンの推薦

    好きな商品や作品を、頼まれてもいないのに熱心に勧める人を、冗談まじりに「ステマ」と呼ぶ使い方です。

語源・成り立ち

英語の「stealth marketing」から来た言葉です。「stealth」は、レーダーに映りにくい「ステルス戦闘機」と同じ「ステルス」で、気づかれずに行うことを表します。

日本では、2012年12月にペニーオークションのサイトの運営者が詐欺の疑いで逮捕され、複数のタレントが報酬を受け取ってブログでサイトを紹介していたことが報じられました。この出来事をきっかけに、「ステマ」という略し方が広く知られるようになりました。

広まった経緯

  1. 2012年12月

    ペニーオークションのサイトをめぐり、タレントのブログでの紹介が宣伝だったと報じられ、「ステマ」という言葉が広く知られる。

  2. 2023年3月

    消費者庁が、ステマを景品表示法の不当表示に加える告示（令和5年内閣府告示第19号）を公表する。

  3. 2023年10月1日

    告示が施行され、ステマが景品表示法違反になる。違反した事業者には措置命令が出される。

ズレのポイント

「PR」と書いてあればステマではない

消費者庁の説明では、「広告」「PR」などの表示があれば、見る人が広告だと分かるものとして扱われます。宣伝であることを示している投稿は、ステマとは別のものです。

規制されるのは広告主

景品表示法で責任を問われるのは、表示の内容に関わった事業者（広告主）です。投稿したインフルエンサー本人が、この法律で直接の対象になるわけではありません。

疑いだけで決めつけない

「ステマだ」という指摘は、相手が企業から頼まれて投稿したと言っているのと同じです。確かめられないまま広めると、ただ好きで勧めている人を傷つけることがあります。

多様な観点

法律から

ステマの告示は、広告であることを隠す行為そのものを対象にしています。それまでも、品質や価格を実際よりよく見せる表示は景品表示法で取り締まれましたが、内容が正しくても、広告であることを隠せば違反になる、という点が新しいところです。

消費者庁のQ&Aでは、違反には措置命令が出され、課徴金の対象にはならないと説明されています。ただし、品質や価格を偽る表示を伴う場合は、課徴金の対象になることがあります。

広告から

インフルエンサーに商品を紹介してもらう広告は、今では広く使われています。広告であることを示したうえで、本人の言葉で紹介してもらう形が基本になりました。広告と分かる表示をするかどうかが、ステマとの分かれ目です。

SNSから

SNSでは、話題になった商品や作品に対して「ステマでは」と疑う声がよく上がります。広告を見分けたいという気持ちの表れですが、根拠がないまま広がることもあり、言葉の使い方そのものが争いのもとになることもあります。

使用シーン

世代を問わず、SNSやネットのニュースでよく使われます。マーケティングや広告の仕事では、法律の意味で使われます。

関連語

  • インプレSNSの表示回数。注目を集めるための投稿が問題になることがある。
  • バズるSNSで一気に話題になること。ステマが疑われるきっかけにもなる。
  • 炎上ステマが発覚すると、批判が集まることがある。
