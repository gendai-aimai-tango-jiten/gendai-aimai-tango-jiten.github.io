曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

バグるは、「バグ」を動詞にした言葉です。デジタル大辞泉は、意味を二つに分けています。一つはコンピューターが誤動作や不具合を起こすこと、もう一つは、俗に「正常でなくなる。常軌を逸する」ことで、例として「金銭感覚が―・った」を挙げています。

もとはゲームやパソコンの画面がおかしくなったときの言葉でしたが、いまは人の様子や感覚にもよく使われます。「寝不足で頭がバグってる」は頭が回らないこと、「距離感バグってる」はなれなれしすぎること、「かわいすぎて脳がバグる」はうれしくて混乱していることです。

言われた側が「ほめられた」と思うか「おかしいと言われた」と思うかは、場面によって変わります。頭が回らない「不調」と、感覚がずれた「異常」と、驚きを表す「冗談」。どれのつもりで言ったのかが、言葉だけでは伝わりにくい言葉です。

あなたはどの意味派？

あなたは「バグる」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    機械が不具合を起こす

    「アプリがバグった」「画面表示がバグる」のように、プログラムの誤りで機械やソフトが正しく動かなくなることを表します。

  2. 拡張広がった使い方

    頭が回らない・混乱する

    「忙しすぎて頭がバグる」のように、疲れや情報の多さで、ふだんどおりに考えられない状態を表します。

  3. 拡張広がった使い方

    感覚が常識からずれている

    「金銭感覚がバグってる」「距離感がバグってる」のように、人の感覚がふつうから大きく外れていることを表します。相手に向けて言うと、からかいや非難に聞こえることがあります。

  4. 拡張広がった使い方

    驚き・感動の大げさな言い方

    「かっこよすぎて脳がバグる」のように、驚いたり感動したりした気持ちを、冗談めかして大きく言う使い方です。

語源・成り立ち

「バグ」は英語の bug で、もとは「虫」という意味です。デジタル大辞泉は、コンピューターのプログラム上の不具合や誤りのほか、一般に機器類などの欠陥もバグと呼ぶとしています。不具合を探して直す作業は「デバッグ」です。

「バグる」は、この「バグ」に「る」を付けて動詞にした言葉で、「メモる」「サボる」と同じ作り方です。辞書サイト Weblio の実用日本語表現辞典は、2012年3月の時点で「調子がおかしな様子になること」という意味を載せており、機械の不具合から人の調子へと使い方が広がっていたことが分かります。

広まった経緯

  1. （時期不明）

    コンピューターのプログラムの誤りを「バグ」と呼ぶ言い方が日本でも広まり、「バグる」という動詞が生まれる。

  2. 2012年

    Weblio の実用日本語表現辞典に、「調子がおかしな様子になること」などの意味で「バグる」が載る。

  3. 現在

    デジタル大辞泉に、俗に「正常でなくなる。常軌を逸する」の意味が載り、「金銭感覚がバグる」などの言い方が日常で使われている。

ズレのポイント

人に向けると悪口に聞こえることも

「感覚バグってるね」は、言った人は冗談のつもりでも、言われた人には「あなたはおかしい」と聞こえることがあります。目上の人や初対面の人には使わないほうが無難です。

ほめ言葉にもなる

「強すぎてバグってる」のように、すごさをほめる意味で使われることもあります。否定的な意味だけで受け取ると、相手の意図を取り違えることがあります。

仕事の場では言い換えを

システムの話では「不具合が出た」「誤作動した」と言ったほうが、何が起きたのかが正確に伝わります。

多様な観点

ITから

エンジニアにとってのバグは、原因を探して直すべき具体的な誤りです。人の感覚に使う「バグる」には、どこが誤りなのかを示す意味はありません。

ゲームから

ゲームでキャラクターが壁を通り抜けたり、画面が乱れたりする様子を「バグった」と言う経験が、この言葉を身近にしたと考えられます。

言葉の作りから

人を機械にたとえる言い方は、「スペック」「ポンコツ」などにも見られます。「バグる」も、人の状態を機械の故障にたとえて、深刻さを和らげている言い方です。

使用シーン

ゲームやネットに親しんだ世代を中心に、会話やSNSで使われます。IT の現場では、もとの「不具合が出る」という意味で使われます。

関連語

  • ハイスペ機械の言葉を人に当てはめた言葉。
  • エグい程度がふつうでないことを、良い意味にも悪い意味にも使う言葉。
  • 解像度機械や技術の言葉が、人の考え方の話に広がった言葉。
