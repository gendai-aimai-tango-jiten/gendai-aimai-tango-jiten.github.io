曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

コミットは、英語の commit から来た言葉です。デジタル大辞泉は意味を三つに分けています。「かかわり合うこと。関係すること」、「約束すること。誓うこと」、そしてデータベースで処理が成功して完了することです。

古くは、思想や政治の話で「深く関わる」の意味で使われていました。それが、2014年に始まったパーソナルトレーニングジムのCMの「結果にコミットする」で広く知られ、仕事の場でも「結果にコミットする」「プロジェクトの成功にコミットする」のように、成果を約束する意味で使われるようになりました。

「この案件にコミットします」と言われたとき、相手は「本気で関わります」と言っているのか、「必ず結果を出します」と約束しているのか。深く「関わる」ことと、成果を「約束する」こと。どちらの意味で言ったかによって、あとで問われる責任の重さがずれます。

あなたは「コミット」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    深く関わる

    「社会運動にコミットする」のように、ある活動や立場に自分から関わっていくことを表します。思想や政治の話で古くから使われてきた意味です。

  2. 原義もともとの意味

    約束する・誓う

    「目標の達成をコミットする」のように、何かをすると約束することを表します。名詞のコミットメントも「約束」「公約」の意味で使われます。

  3. 拡張広がった使い方

    成果に責任を持つ

    「結果にコミットする」のように、結果を出すことまで引き受けるという意味で使われます。仕事の場では、ただの約束より重い言葉として受け取られます。

  4. 拡張広がった使い方

    本気で取り組む

    「もっとコミットしてほしい」「コミットが足りない」のように、熱意や力の入れ方を表す使い方です。結果の約束までは含まないこともあります。

語源・成り立ち

英語の commit は、「（罪や過失を）犯す」「託す」「任せる」「約束する」など、意味の広い動詞です。名詞の commitment には「約束」「言質」「義務」「責任」「傾倒」などの意味があります。日本語の「コミットする」は、この名詞の意味に近い使い方です。

精選版 日本国語大辞典は、「深くかかわること」の意味の早い例として、1961年の丸山真男の文章にある「われわれはどちらにコミットすべきなのか」を挙げています。IT の分野では、データベースの処理を確定させることや、バージョン管理で変更を記録することも「コミット」と呼びます。

広まった経緯

  1. 1961年

    丸山真男の文章に「どちらにコミットすべきなのか」という言い方が見られる（精選版 日本国語大辞典が早い例として挙げる）。

  2. 2014年

    パーソナルトレーニングジムの「結果にコミットする」というCMが始まり、「コミット」という言葉が広く知られるようになる。

  3. 現在

    仕事の場で「成果にコミットする」「コミットが足りない」などと使われ、約束の意味でも、熱意の意味でも使われている。

ズレのポイント

「頑張ります」のつもりが「約束します」に

本気で取り組むという気持ちで「コミットします」と言っても、聞いた人は「結果を約束した」と受け取ることがあります。成果を約束できないときは、「全力で取り組みます」と言ったほうがずれません。

何にコミットするのかを決める

「コミットする」と言うときは、何を、いつまでに、どこまでやるのかを決めておかないと、あとで「約束と違う」という話になりやすくなります。

IT の「コミット」は別の意味

システム開発の現場で「コミットした」と言えば、変更を記録した、処理を確定させたという意味です。約束や熱意の話ではありません。

多様な観点

仕事の場から

「コミット」は「プロミス」より重く、結果まで責任を持つ言葉として使われることが多いようです。上司から「コミットして」と言われたら、何を求められているのかを確かめておくと安心です。

政治・外交から

国際関係では、コミットメントは主に、条約などにもとづいて同盟国や友好国に示す公約を指します（ブリタニカ国際大百科事典）。ここでは「関わる」と「約束する」が一つになっています。

エンジニアから

エンジニアにとってのコミットは、毎日何度もする作業の記録です。ほかの部署と話すときは、同じ言葉でまったく違うことを指している場合があります。

使用シーン

会社の会議や目標を決める場面、採用や人事の話、政治や外交の話で使われます。IT の現場では、変更の記録という別の意味で毎日使われています。

関連語

  • エビデンス英語から入り、業界によって指すものが違う仕事の言葉。
  • パーパス英語から入り、ビジネスの場で広く使われるようになった言葉。
  • 言語化ビジネスの会話でよく使われ、指す中身が人によって違う言葉。
