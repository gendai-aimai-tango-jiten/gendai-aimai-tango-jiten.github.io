曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

本来は、寒さや恐怖、気持ち悪さなどの強い刺激を受けて、肌の表面が、羽をむしった鳥の皮のようにぶつぶつと粟立つことです。「お化け屋敷で鳥肌が立った」「あの人の話し方は鳥肌が立つほど嫌だ」のように、ぞっとする場面で使われてきました。

ところが、1980年代ごろから、「感動のあまり鳥肌が立った」「鳥肌もののライブ」のように、強く感動したときにも使われるようになりました。文化庁の2001年度の調査でも、40歳以下の世代を中心に、感動の意味で使う人が増えていることが示されています。

いまでは多くの国語辞典が感動の意味を載せています。一方で、「本来は悪い意味の言葉だ」と違和感を持つ人もいます。

あなたはどの意味派？

あなたは「鳥肌が立つ」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    寒さや恐怖で肌が粟立つ

    寒さ、恐怖、嫌悪感などで、肌がぶつぶつになる体の反応です。ぞっとする、という気持ちを表します。

  2. 拡張広がった使い方

    強く感動する

    「名演奏に鳥肌が立った」のように、心が大きく揺さぶられて、体が反応するほど感動したことを表します。いまはこの使い方もとても多くなっています。

語源・成り立ち

「鳥肌」は、羽をむしった後の鳥の皮のように、肌に小さなぶつぶつができる状態のことです。寒さや恐怖を感じたときに、毛穴の周りの筋肉が縮んで起きる体の反応です。

実際には、強い感動を受けたときにも体は同じように反応します。その体験を言葉にしたことで、感動の意味が広まったと考えられています。

広まった経緯

  1. 昔から

    寒さや恐怖で肌が粟立つことを表す慣用句として使われる。

  2. 1980年代ごろ

    感動したときにも「鳥肌が立つ」と言う使い方が広まり始めたとされる。

  3. 2001年度

    文化庁「国語に関する世論調査」で、40歳以下を中心に感動の意味で使う人が増えていることが示される。

  4. 2000年代〜

    広辞苑や三省堂国語辞典など、多くの辞書が感動の意味を載せるようになる。

ズレのポイント

いまは誤用とは言い切れない

多くの辞書が感動の意味を載せており、広く使われているため、感動の意味で使うことを誤用とは言い切れなくなっています。

ほめるつもりで使うと誤解されることも

本来の意味を重んじる人には、「鳥肌が立った」は「ぞっとした」に聞こえることがあります。改まった場では「感動した」「心を打たれた」と言うほうが安全です。

体の反応としては同じ

寒さでも、恐怖でも、感動でも、体には同じ鳥肌が立つことがあります。感動の意味は、体の実感から生まれた、自然な広がりとも言えます。

多様な観点

辞書から

鳥肌が立つは、辞書が規範を示すべきか、言葉の実態を記述すべきかを考えるきっかけになった言葉です。小学生向けの辞典に感動の例文を載せたところ、大人の読者から削除を求める手紙が届いたこともあったと報告されています。

体の科学から

感動で鳥肌が立つのは、音楽などで強い感情が動いたときに、自律神経が反応するためだと考えられています。感動の意味は、科学的にも根拠のある体験に基づいています。

言語学から

悪い意味の言葉が、良い意味にも使われるようになる変化は、「ヤバい」「エグい」にも見られます。鳥肌が立つは、その変化が辞書にまで定着した例です。

使用シーン

世代を問わず、日常会話、ライブやスポーツの感想、テレビなどで使われます。感動の意味は、とくに若い世代で多く使われます。
