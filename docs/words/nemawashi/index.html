ねまわし【根回し】〔名・動〕

  1. ①

    もともとの意味樹木の移植の準備。木を植え替える1〜2年前に、根の周りを掘って太い根を切り、根元近くに細い根を出させておく作業です。

  2. ②

    事前の相談・合意づくり。会議や交渉の前に、関係者に個別に話して意見を聞き、了解を得ておくことです。

  3. ③

    裏工作。反対派が準備する前に味方を増やしたり、非公式の場で結論を決めたりすることです。

  4. ④

    ちょっとした事前連絡。「先方に一言根回ししておく」のように、合意づくりまでいかない軽い事前の連絡を指すこともあります。

曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度1/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

交渉や会議の前に、関係する人へ個別に話をして、了解を取りつけておくことです。デジタル大辞泉は「事をうまく運ぶために、あらかじめ手を打っておくこと。下工作」と説明しています。もとは、木を植え替える前に根を切って、細い根を出させておく園芸の作業でした。

意味そのものはほぼ共通していますが、受け取り方は人によって大きく違います。会議で急に反対が出ないよう、事前に相談して懸念を聞いておく丁寧な準備と考える人がいます。一方で、決まった結論を非公式の場で固め、会議を形だけにするやり方と考える人もいます。

同じ「根回ししておいて」でも、「事前に相談しておいて」の意味で言う人と、「裏で話をつけておいて」の意味で受け取る人がいます。

あなたはどの意味派？

あなたは「根回し」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    樹木の移植の準備

    木を植え替える1〜2年前に、根の周りを掘って太い根を切り、根元近くに細い根を出させておく作業です。植え替えたあと根づきやすくなります。

  2. 拡張広がった使い方

    事前の相談・合意づくり

    会議や交渉の前に、関係者に個別に話して意見を聞き、了解を得ておくことです。職場でいちばんよく使われる意味です。

  3. 拡張広がった使い方

    裏工作

    反対派が準備する前に味方を増やしたり、非公式の場で結論を決めたりすることです。批判的な文脈で使われます。

  4. 拡張広がった使い方

    ちょっとした事前連絡

    「先方に一言根回ししておく」のように、合意づくりまでいかない軽い事前の連絡を指すこともあります。

語源・成り立ち

「根」を「回す」、つまり根の周りをぐるりと掘る作業から来た言葉です。日本大百科全書によると、日本では江戸時代末期ごろからこの技法が使われてきました。マツやケヤキ、ツバキなど、植え替えると根づきにくい木に行います。

ブリタニカ国際大百科事典は、会議や交渉で事前に工作するという意味合いから、この園芸用語が転用されたと説明しています。背景として、日本の村落では全会一致が原則で、意見の対立が村の存立を危うくするものとされてきたことを挙げています。

広まった経緯

  1. 江戸時代末期ごろ

    樹木を移植するための技法として「根回し」が使われるようになる（日本大百科全書）。

  2. 時期不明

    会議や交渉の前に手を打っておく意味に転じ、政治や企業の言葉として定着する。

  3. 2024年

    北陸先端科学技術大学院大学で、根回しによるイノベーション促進を扱った博士論文が出される。

ズレのポイント

相手によって印象が違う

「根回しが上手」はほめ言葉にも、皮肉にもなります。外部の人や若い世代には、裏工作の意味で受け取られることもあります。

会議が形だけになるおそれ

ブリタニカ国際大百科事典は、本音で議論できて決定が速くなる面がある一方、経過が公開されないため疑いを招きやすく、公式の場が儀礼的になりやすいと指摘しています。

園芸の意味もある

植木や造園の話では、今も本来の作業の意味で使われます。

多様な観点

政治学から

世界大百科事典（大嶽秀夫）は、根回しを、争点が公になる前、対立がはっきりしたあと、交渉が決裂したあとの3つに分けています。そのうえで、民主的な統制を排除する傾向をもつ一方、妥協的な合意をつくる手段でもあると説明しています。

経営の研究から

2024年の博士論文は、日本企業の稟議の場面で根回しが頻繁に行われると述べています。新しい事業を社内で正当化し、資源を集める働きがある一方で、失敗する場合もあることを事例から示しています。

園芸から

本来の根回しは、木を弱らせずに新しい場所へ移すための下準備です。ビジネスの意味も、もとは「急に動かして枯らさない」という配慮に近いたとえです。

使用シーン

会社の会議や稟議、政治、自治会、学校の行事まで、合意が必要な場面で広く使われます。造園の現場では本来の意味で使われます。

関連語

  • 忖度言われる前に相手の意向を推し量ること。
  • 腹落ち関係者が心から納得すること。根回しの目的の一つ。
  • アジェンダ会議の議題。根回しは議題が決まる前から始まることもある。
