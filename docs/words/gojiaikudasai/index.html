曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

「ご自愛ください」は、相手に、ご自身を大切にしてください、体に気をつけてください、と伝える言葉です。「自愛」について、デジタル大辞泉は「自分を大切にすること。自分の健康状態に気をつけること」と説明し、「時節柄ご自愛ください」という例を挙げています。

日本国語大辞典は、現代では「御自愛」の形で、手紙の末文などで相手に向けて使うことが多いと書いています。季節のあいさつ状やビジネスメールの最後に、「寒さ厳しき折、どうぞご自愛ください」のように添えるのが典型です。目上の人にも使える言葉として、解説記事でも紹介されています。

よく使われる分、受け取り方には幅があります。相手の体調を本当に心配して書く人もいれば、文面を閉じる合図として毎回同じように書く人もいます。相手の体を気づかう言葉なのか、手紙を終えるための決まり文句なのか。書く側の気持ちと、読む側の受け取り方がずれやすい言葉です。

あなたはどの意味派？

あなたは「ご自愛ください」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れ、右へずれていきます。

もともとの意味出典から離れた使い方
  1. 原義もともとの意味

    体を大事にしてほしいという気づかい

    「季節の変わり目ですので、どうぞご自愛ください」のように、相手の健康を思って伝える使い方です。

  2. 拡張広がった使い方

    手紙やメールの結びのあいさつ

    年賀状、暑中見舞い、ビジネスメールの最後に添える決まった言い方です。中身の用件とは関係なく、文面を締めくくる役割を持ちます。

  3. 誤用寄り出典から離れた使い方

    「お体をご自愛ください」

    「自愛」に体を大切にする意味が含まれるので、「お体を」を付けると意味が重なる、と解説記事では指摘されています。広く使われている言い方でもあり、気にしない人も多い形です。

語源・成り立ち

「自愛」は「自ら愛する」、つまり自分を大切にすることです。中国の『老子』にも「自ら愛して自らは貴しとせず」という一節があります。日本では、奈良時代の藤原氏の伝記『家伝』（760年ごろ）に用例があると『日本国語大辞典』は書いています。

「自愛」には、品行をつつしむこと（自重）や、自分の利益をはかること（利己）という意味もあります。手紙で相手に向けて使う「ご自愛ください」は、そのうち「自分の体に気をつけること」の意味を、相手への願いとして述べたものです。

広まった経緯

  1. 760年ごろ

    『家伝』に、自分を大切にする意味の「自愛」の用例がある（『日本国語大辞典』）。

  2. 1434年

    『椿葉記』に、品行をつつしむ意味の「自愛」の用例がある（同）。

  3. 明治時代

    田口卯吉の『日本開化小史』（1877〜82年）に、自分の利益をはかる意味の「自愛」の用例がある（同）。

  4. 現代

    「御自愛」の形で、手紙の末文で相手に向けて使うことが多くなる（同）。

ズレのポイント

病気やけがの人には使わない

「ご自愛ください」は、元気な相手に、これからも体に気をつけてほしいと伝える言葉です。すでに体調を崩している人には、「お大事になさってください」が合います。

「お体をご自愛ください」は意味が重なる

「自愛」だけで、自分の体に気をつける意味になります。気になる場合は「どうぞご自愛ください」や「お体を大切になさってください」とすると、重なりがなくなります。

決まり文句に聞こえないように

毎回同じ位置に同じ形で書くと、読む側には決まり文句に見えます。「寒い日が続きますので」のように、季節や相手の状況を一言添えると、気づかいが伝わりやすくなります。

多様な観点

敬語の見方から

「ご自愛ください」は、相手の行為に「ご」を付けた尊敬の形なので、目上の人にも使えます。Forbes JAPANの記事は、「お体にはお気をつけください」よりも目上に使いやすい言い方として紹介しています。

受け取る側の見方から

形式的なあいさつとして読み流す人もいれば、体調を気にかけてもらえたと感じる人もいます。直前の一文に何を書くかで、印象が大きく変わります。

言葉の歴史から

「自愛」は、もともとは自分で自分を大切にすること、身をつつしむことを表す言葉でした。それが、相手に向けて「自分を大切に」と願う手紙の言葉として定着しています。

使用シーン

手紙、年賀状、季節のあいさつ状、ビジネスメールの結びで、世代を問わず使われます。話し言葉で使うことは少なく、書き言葉の決まった言い方です。
