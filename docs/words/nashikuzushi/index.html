曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度5/5

本来の意味とずれた使われ方が多いか

通用度4/5

どういう意味？

本来は「済し崩し」と書き、借金を一度に返すのではなく、少しずつ返していくことを指す言葉です。そこから、物事を一度に片付けず、少しずつ済ませていくという意味でも使われるようになりました。

いまは、「約束がなし崩しになった」「なし崩し的に決まった」のように、なかったことにする、きちんと決めないまま、うやむやのうちに物事を進めるという意味で使われることが多くなっています。

「少しずつ」という部分が抜け落ち、「崩れる」「なしになる」という字面の印象から意味が変わっていったと考えられます。

あなたはどの意味派？

あなたは「なし崩し」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    借金を少しずつ返す

    まとまったお金で一度に返すのではなく、少しずつ返済していくことです。いまはあまり使われない、もとの意味です。

  2. 原義もともとの意味

    物事を少しずつ片付ける

    「仕事をなし崩しに片付ける」のように、一度にではなく少しずつ済ませていくことです。辞書に載っている本来の意味です。

  3. 誤用寄り出典から離れた使い方

    なかったことにする・うやむやにする

    「計画がなし崩しになった」のように、決めたことが消えてしまう、ないことにされる、という意味の使い方です。

  4. 誤用寄り出典から離れた使い方

    きちんと決めずに既成事実を作る

    「なし崩し的に残業が当たり前になった」のように、正式な決定のないまま、いつの間にか物事が進んでしまうことを表します。いまはこの使い方がとても多くなっています。

語源・成り立ち

「なし」は「済し（なし）」で、「済す（なす）」は借りたものを返す、という意味の古い言葉です。「崩す」は、まとまったものを少しずつ分けることです。

つまり「済し崩し」は、借金を崩して少しずつ返していく、という組み立てでした。「済す」という言葉が使われなくなり、「なし」が「無し」と受け取られるようになったことで、「なくなる」「崩れる」という意味に読み替えられていきました。

広まった経緯

  1. 江戸時代ごろ

    借金を少しずつ返す意味で「済し崩し」が使われる。

  2. 近代以降

    物事を少しずつ片付ける、という意味が加わる。

  3. 2000年代〜

    文化庁の調査で、「なかったことにする」意味で受け取る人が多数派であることが報じられる。若い世代ほど本来の意味を選ぶ人が少ない。

ズレのポイント

「無し」ではなく「済し」

「なし」を「無し」と読むと、「なしにする」「なくなる」という意味に引っ張られます。もとは「済す（返す）」なので、「なくす」意味は含まれていません。

辞書によって扱いが違う

うやむやにする、既成事実を積み重ねる、といった使い方を新しい意味として載せる辞書もあれば、誤用とする辞書もあります。改まった文章では、意味がはっきり伝わる言い方を選ぶほうが安全です。

「少しずつ」という核がある

本来の意味にも、いまよく使われる「なし崩し的に」にも、「一度にではなく、少しずつ」という感覚は残っています。「一気に約束をなかったことにした」場合に使うと、ずれが大きくなります。

多様な観点

言語学から

「済す」という言葉が日常から消えたことで、語源の感覚が失われ、字面から意味を推測するしかなくなった例です。語の一部が分からなくなると、似た音の別の言葉（無し）に引き寄せられることがあります。

日本語の調査から

文化庁の調査では、なし崩しを「なかったことにする」の意味で受け取る人が6割を超えると報じられています。とくに20代では、本来の意味を選ぶ人がかなり少ないとされます。

社会・組織から

「なし崩し的に決まる」という言い方は、日本の組織の意思決定を批判するときによく使われます。誰も決めていないのに、いつの間にかそうなっている状態を表す、便利な言葉になっています。

使用シーン

世代を問わず、ニュース、論説、ビジネスの場面で「なし崩し的に」の形でよく使われます。本来の意味は、辞書や国語の授業で目にする程度になっています。

関連語

  • 敷居が高い本来の意味からずれた使い方が広まった言葉。
  • 姑息本来は「一時しのぎ」。卑怯の意味で使われることが多い。
  • うやむやはっきりしないままにすること。誤用寄りのなし崩しに近い意味。
