曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

いまこの瞬間に起きている体験に、意図して注意を向け、良い悪いの評価をせずに、ただ観察している心の状態のことです。呼吸や体の感覚、浮かんでくる考えや感情に、とらわれずに気づいている状態を指します。

仏教の修行の一つ「正念」に起源を持ちます。1979年に、アメリカの医学者ジョン・カバット・ジンが、宗教色を取り除いたストレス低減プログラム（MBSR）を開発し、医療の分野に広まりました。その後、心理療法、教育、ビジネスへと広がり、GoogleなどIT企業の研修で取り入れられたことでも注目されました。

日本でも2010年代後半から広まりましたが、心の状態のことなのか、瞑想の方法のことなのか、リラックス法のことなのかがあいまいなまま使われることが多い言葉です。

あなたはどの意味派？

あなたは「マインドフルネス」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    いまに評価せず注意を向ける心の状態

    目の前の体験に、判断を加えずに気づいている心のあり方です。カバット・ジンの定義に沿った意味です。

  2. 拡張広がった使い方

    そのための瞑想や練習の方法

    呼吸に意識を向ける瞑想など、マインドフルネスな状態を育てるための練習を指す使い方です。

  3. 拡張広がった使い方

    ストレス対策・集中力向上の手法

    企業の研修や健康法として、ストレスを減らし、集中力を高める手法として紹介される使い方です。

  4. 誤用寄り出典から離れた使い方

    リラックス・癒やし全般

    アロマ、ヨガ、のんびり過ごすことなどを、まとめて「マインドフルネス」と呼ぶ使い方です。注意を向けるという核が抜け落ちています。

語源・成り立ち

英語の mindfulness（心にとめていること、注意深さ）から来ています。仏教の言葉（パーリ語の sati、漢訳の「念」）の英訳として使われるようになりました。

1979年、マサチューセッツ大学のジョン・カバット・ジンが、慢性の痛みなどに悩む患者のために、8週間のプログラム「マインドフルネスストレス低減法（MBSR）」を開発しました。これが医療や心理学での研究と応用のきっかけになりました。

広まった経緯

  1. 古代

    仏教で、心をいまにとどめて気づく「念（サティ）」の修行が説かれる。

  2. 1979年

    ジョン・カバット・ジンが、マインドフルネスストレス低減法（MBSR）を開発する。

  3. 2000年代

    うつ病の再発予防などの心理療法にも取り入れられる。IT企業の研修でも注目される。

  4. 2010年代後半

    日本でもビジネス書やメディアで取り上げられ、広く知られるようになる。

ズレのポイント

リラックスが目的ではない

マインドフルネスの練習でリラックスすることはありますが、目的は「いまに気づいていること」です。不快な感覚や考えにも、評価せずに気づくことが含まれます。

考えを空っぽにすることでもない

「無になる」ことと思われがちですが、浮かんでくる考えを消すのではなく、考えが浮かんでいることに気づく、というのがマインドフルネスです。

仏教とのつながり

医療やビジネスでは宗教色を除いて使われますが、もとは仏教の修行に根ざした考え方です。その背景が見えにくくなっている、という指摘もあります。

多様な観点

医療・心理学から

マインドフルネスを取り入れた方法は、ストレスの軽減やうつ病の再発予防などで効果が研究されてきました。一方で、効果を大げさに宣伝する商品やサービスへの注意も呼びかけられています。

ビジネスから

集中力や創造性を高め、ストレスを減らすものとして、企業の研修に取り入れられました。ただし、働きすぎの環境を変えずに、社員の心の持ち方だけで解決しようとする使われ方には批判もあります。

宗教・思想から

仏教の修行が、宗教色を除いて世界中に広まったことは、伝統の現代的な活かし方として評価される一方、「商品化されたマインドフルネス」への批判もあります。

使用シーン

企業の研修担当者、医療・心理職、健康や自己啓発に関心のある人などに使われます。ビジネス書、雑誌、アプリなどでよく見かけます。

関連語
