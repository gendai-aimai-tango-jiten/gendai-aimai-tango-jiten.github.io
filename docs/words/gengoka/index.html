曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度4/5

他の世代や別の界隈にも通じるか

どういう意味？

頭の中にある考えや感覚、気持ちを、言葉にして表すことです。

もとは心理学や哲学などで使われる硬い言葉でしたが、2020年代に入って日常語として急に広まりました。「推しの魅力を言語化したい」「モヤモヤを言語化してくれてありがたい」「言語化能力を鍛える」のように、仕事でも趣味でも使われます。2024年には三省堂「今年の新語」の大賞に選ばれました。

自分の考えを整理することなのか、人に伝わるよう説明することなのか、気持ちにぴったりの言葉を見つけることなのか。同じ「言語化」でも、何をしているかは場面によって違います。

あなたはどの意味派？

あなたは「言語化」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    言葉になっていないものを言葉にすること

    感覚や経験、イメージなど、まだ言葉になっていないものを、言葉で表せる形にすること。心理学や哲学などで使われてきた意味です。

  2. 拡張広がった使い方

    考えを整理して人に伝わる形にすること

    「企画の狙いを言語化して」のように、仕事で、あいまいな考えを整理し、相手に分かるよう説明することを指します。

  3. 拡張広がった使い方

    モヤモヤに名前を付けること

    「この気持ちを言語化してくれた投稿」のように、自分がうまく言えなかった感情を、誰かがぴったりの言葉で表してくれたときに使われます。

  4. 誤用寄り出典から離れた使い方

    話す・書くこと全般

    単に意見を言う、文章を書く、といったことまで「言語化」と呼ぶ使い方です。「言葉にしにくいものを言葉にする」という核が薄れています。

語源・成り立ち

「言語」に、「〜の状態にする」という意味の「化」を付けた言葉です。「可視化」「数値化」と同じ作りです。

三省堂の選考では、かつては学術用語・硬い文章語として使われていた言葉が、新聞などでの出現件数が2020年代に入って急増したことが指摘されています。

広まった経緯

  1. 昔から

    心理学、哲学、教育学などの分野で、学術的な用語として使われる。

  2. 2010年代後半

    ビジネス書や自己啓発の分野で、「言語化力」「言語化能力」という言い方が広まる。

  3. 2020年代

    SNSや推し活の場で、気持ちや魅力を言葉にすることを「言語化」と呼ぶ使い方が広がる。

  4. 2024年12月

    三省堂「辞書を編む人が選ぶ『今年の新語2024』」で大賞に選ばれる。

ズレのポイント

「説明して」の言い換えとして使うと圧になる

職場で「もっと言語化して」と言うと、相手には「あなたの説明は分かりにくい」と聞こえることがあります。何を、どこまで言葉にしてほしいのかを添えないと、伝わりにくい指示になります。

言語化できないものもある

感覚や感情には、言葉にすると抜け落ちてしまう部分もあります。「言語化できないのは考えていないから」と決めつけると、言葉にしにくい経験を軽く扱うことになります。

うまい言葉が見つかれば正しいわけではない

SNSでは、ぴったりの言い回しが「言語化がうまい」とたくさん共有されます。言葉の気持ちよさと、内容の正しさは別のものです。

多様な観点

心理学から

自分の感情を言葉にすることで、気持ちが落ち着いたり整理されたりすることは、心理学でも研究されてきました。モヤモヤに名前が付くとほっとする感覚は、こうした働きと重なります。

ビジネスの文化から

リモートワークで、顔を合わせずに文字で伝える場面が増えたことが、言語化が重視される理由の一つとして挙げられます。阿吽の呼吸が通じにくい環境ほど、言葉で伝える力が求められます。

推し文化から

推しの魅力を細かく言葉にして共有することは、推し活の楽しみの一つになっています。「言語化オタク」という言い方も生まれました。

使用シーン

会社員から学生まで、世代を問わず使われます。ビジネス書や研修、SNSの投稿、推し活の感想など、使われる場面が非常に広い言葉です。

関連語

  • エモい言葉にしにくい感情をまとめて言う言葉。言語化とは逆向きの言葉とも言える。
