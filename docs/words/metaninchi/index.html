曖昧メーター

曖昧度3/5

人によってその言葉の意味がどれだけ変わるか

誤用度2/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

「メタ認知」は認知心理学の用語です。「メタ」は「より高次の」という意味で、記憶する、考える、理解するといった自分の認知の働きを、もう一段上から見て認知することを指します。たとえば「この問題は自分には難しそうだから、先に図を描こう」と考えるとき、人は自分の理解の具合を点検し、やり方を調整しています。

心理学の事典では、メタ認知を2つに分けて説明しています。自分の認知の進み具合を点検し（モニタリング）、調整する（コントロール）働きと、自分の得意・不得意や、どんなやり方が効くかについての知識です。教育の分野では、自分で学び方を見直す力として重視され、文部科学省の学習指導要領をめぐる議論でも取り上げられました。

一方、ビジネス書や研修、SNSでは、「メタ認知が高い人」のように、「自分を客観的に見られること」「冷静に振り返れること」くらいの広い意味で使われることが多くなっています。研究の用語としての「認知を点検し調整する働き」と、日常語としての「自分を客観視すること」全般。どこまでを指すかがずれています。

あなたはどの意味派？

あなたは「メタ認知」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    自分の認知を点検し調整する働き

    「理解できているか確かめながら読む」「覚え方を変えてみる」のように、自分の考えや学び方を見張り、やり方を直す働きです。心理学や教育学での使い方です。

  2. 原義もともとの意味

    自分の認知についての知識

    「自分は耳で聞くほうが覚えやすい」「この種類の問題は時間がかかる」のように、自分や課題、やり方について知っていることです。研究ではメタ認知的知識と呼びます。

  3. 拡張広がった使い方

    自分を客観視すること

    「メタ認知して、感情的になっている自分に気づく」のように、自分の気持ちや振る舞いを一歩引いて見ること全般を指す使い方です。ビジネスや自己啓発の場面でよく見かけます。

  4. 拡張広がった使い方

    一段上から状況を見ること

    「議論をメタ認知する」のように、自分の頭の中に限らず、話し合いや状況そのものを外から眺める意味で使われることもあります。

語源・成り立ち

「メタ認知」は英語の metacognition の訳語です。心理学事典によると、研究の直接の起こりは、1970年にアメリカの心理学者フラベル（J. H. Flavell）が唱えたメタ記憶（自分の記憶についての認知）の研究です。

「メタ認知」という言葉そのものは、フラベルの1976年の論文で初めて使われたとされています。その後、学習や問題解決、批判的思考の研究に広がりました。日本では、教育の分野で「メタ認知能力を育てる」という言い方が広まり、そこからビジネスや自己啓発の場面にも入ってきました。

広まった経緯

  1. 1970年

    フラベルがメタ記憶の研究を始め、メタ認知研究の直接の起こりとなる（心理学事典）。

  2. 1976年

    フラベルの論文で「メタ認知（metacognition）」という言葉が初めて使われたとされる。

  3. 2016年12月

    中央教育審議会の答申が、学習指導要領の改訂に向けて、いわゆる「メタ認知」に関わる力に触れる。

  4. 近年

    ビジネス書や研修、SNSで、「自分を客観視すること」の意味でも使われるようになる。

ズレのポイント

「客観視」だけではない

研究の用語としてのメタ認知は、自分を眺めるだけでなく、眺めた結果をもとにやり方を調整するところまでを含みます。「客観的に見る」だけでは、半分しか言い表せていません。

性格や人柄の評価ではない

「あの人はメタ認知が高い」と言うと、冷静で大人びた人柄のように聞こえます。ただ、研究でいうメタ認知は、課題や場面ごとに働く認知のしくみで、人柄そのものを指す言葉ではありません。

「メタ視点」「俯瞰」と混ざりやすい

「メタ的に見る」「俯瞰する」は、状況全体を外から見ることを指して使われます。メタ認知は、もともとは自分の認知が対象の言葉なので、話し合いや状況を眺めることまで含めるかは人によって違います。

多様な観点

心理学から

研究者のあいだでも呼び方や定義は完全には一致していませんが、「認知についての知識」と「認知の点検と調整」の2つに分けるという点では、おおむね見方がそろっています。

教育から

自分の学び方を振り返り、見直す力として、授業づくりや学習評価の議論で取り上げられています。「わかったつもり」に気づくことが、メタ認知の分かりやすい例としてよく挙げられます。

ビジネスから

感情に流されずに振り返る力、自分の思い込みに気づく力として、研修や自己啓発の本で使われています。便利な言葉なので、「冷静さ」「自己理解」など、もっと広い意味をまとめて指していることもあります。

使用シーン

心理学や教育の専門家、学校の先生のあいだで使われてきました。いまはビジネス書や研修、SNSの自己啓発の投稿などでも見かけます。

関連語

  • 言語化自分の考えを外に出して見直すという点で、一緒に語られることが多い言葉。
  • 自己肯定感心理学の用語から、日常の広い意味へ広がった言葉。
  • 解像度ビジネスの場面で、考えの細かさを表す言葉として広まった言葉。
