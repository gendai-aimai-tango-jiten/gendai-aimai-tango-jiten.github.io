曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度3/5

他の世代や別の界隈にも通じるか

どういう意味？

新しい職業に就くため、または今の仕事で求められるスキルが大きく変わることに対応するために、必要なスキルを身につける、または身につけさせることです。デジタル化で仕事の中身が変わる中、企業が社員に新しい技術を学ばせる取り組みとして注目されました。

2022年10月、岸田首相が所信表明演説で、個人のリスキリング支援に5年間で1兆円を投じると表明したことで、一気に広まりました。同じ年の新語・流行語大賞にもノミネートされています。

仕事を変えるための学びなのか、大人の学び直し全般なのか、趣味の勉強も含むのか。言葉が広まるにつれて、指す範囲がぼやけてきています。

あなたはどの意味派？

あなたは「リスキリング」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    新しい仕事のためのスキル獲得

    デジタル化などで仕事が変わる中、新しい職業や役割に就くために必要なスキルを身につけることです。企業が主導して社員に学ばせる場合を指すことが多くあります。

  2. 拡張広がった使い方

    国の転職・労働移動の支援

    政府の政策では、学び直しから転職までを一体で支援する取り組みとして使われています。

  3. 誤用寄り出典から離れた使い方

    大人の学び直し全般

    大学院に通う、資格を取る、教養を身につけるなど、仕事との結びつきが薄い学びまで「リスキリング」と呼ぶ使い方です。本来は「リカレント教育」などと呼ばれてきたものです。

  4. 誤用寄り出典から離れた使い方

    育休中の学び直し

    2023年に、育休中のリスキリングを支援するという政府の発言が「育休は休みではない」と批判されたように、場面によっては言葉が反発を呼ぶこともありました。

語源・成り立ち

英語の reskilling（スキルを再び身につけること）から来ています。2018年の世界経済フォーラム（ダボス会議）で、「リスキル革命」として打ち出されたことで国際的に広まりました。

日本では2020年代に入ってから、企業のDX（デジタルトランスフォーメーション）の取り組みとともに使われるようになり、2022年の政府の方針で一般にも知られるようになりました。

広まった経緯

  1. 2018年

    世界経済フォーラム（ダボス会議）で「リスキル革命」が打ち出される。

  2. 2020年代前半

    日本企業のDXの取り組みの中で、社員のリスキリングが注目される。

  3. 2022年10月

    岸田首相が所信表明演説で、個人のリスキリング支援に5年で1兆円を投じると表明する。

  4. 2022年

    「リスキリング」が2022ユーキャン新語・流行語大賞にノミネートされる。

ズレのポイント

リカレント教育との違い

リカレント教育は、仕事と学びを繰り返す、大人の学び直し全般を指す言葉です。リスキリングは、それより「新しい仕事に就く・仕事の変化に対応する」ことに焦点を当てた言葉です。

個人の勉強だけではない

本来のリスキリングは、企業が戦略として社員に新しいスキルを身につけさせる取り組みを含みます。個人の努力だけに任せると、本来の意味からずれてしまいます。

流行語で終わらせないために

国の支援が注目されたことで、中身のない「リスキリング研修」も増えたと指摘されています。何のスキルを、どの仕事のために身につけるのかがはっきりしないと、言葉だけが先走ります。

多様な観点

労働政策から

日本の政府は、リスキリングを、成長分野への労働移動や賃上げにつなげる政策として位置づけています。一方で、支援額が足りない、転職を前提にしすぎている、といった批判もあります。

企業から

人手不足やデジタル化の中で、外から人を採るより、いる社員に新しいスキルを身につけてもらうほうが早い、という考えが広がりました。リスキリングは人材戦略の一部として語られています。

働く人から

仕事の傍ら学ぶ時間をどう確保するか、学んだことをどう仕事や待遇に結びつけるか、という課題があります。学ぶ意欲があっても、職場の理解がないと続けにくいのが現実です。

使用シーン

企業の経営者、人事担当者、会社員を中心に使われます。ニュース、政府の文書、研修、ビジネス書などでよく見かける言葉です。
