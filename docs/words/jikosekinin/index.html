曖昧メーター

曖昧度4/5

人によってその言葉の意味がどれだけ変わるか

誤用度3/5

本来の意味とずれた使われ方が多いか

通用度5/5

他の世代や別の界隈にも通じるか

どういう意味？

辞書では「自分の行動の責任は自分にあること」と説明される言葉です。デジタル大辞泉は「投資は自己責任で行うのが原則だ」という例を挙げています。リスクがあると知ったうえで自分で選んだのなら、その結果も自分で引き受ける、という考え方です。

この言葉が一気に広まったのは2004年です。イラクで日本人3人が人質になった事件で、政府の勧告に反して現地へ行ったのだから「自己責任だ」という声が上がりました。この年の新語・流行語大賞では「自己責任」がトップテンに入り、選考の解説には、最近は責任を転嫁するときにしばしば使われている、と書かれています。

いまでは、仕事を失った人や生活に困っている人に「それは自己責任」と向ける使い方もよく見かけます。自分の選んだ結果を自分で引き受けることなのか、困っている人に「助けなくてよい」と告げることなのか。誰が誰に向けて言うかで、意味が大きく変わります。

あなたは「自己責任」を、どの意味で使っていましたか？

意味の変遷

もともとの意味から、いまの使われ方までを順に並べています。下にいくほど出典から離れます。

  1. 原義もともとの意味

    自分の行動の責任は自分が負う

    「投資は自己責任で」のように、リスクを知ったうえで選んだ結果は自分で引き受ける、という意味です。

  2. 原義もともとの意味

    自分の過失の分だけ責任を負う

    辞書の2つ目の意味です。他人の過失まで背負う必要はない、という考え方に近い使い方です。

  3. 拡張広がった使い方

    自分で引き受ける覚悟

    「自己責任でやります」のように、周りに迷惑をかけず自分で結果を受け止める、という決意として使われます。

  4. 誤用寄り出典から離れた使い方

    困っている人を突き放す言葉

    「貧しいのは自己責任」のように、本人の選択とは言いにくい事情まで本人のせいにして、助けなくてよいという意味で使う言い方です。

語源・成り立ち

「自己」と「責任」を組み合わせた言葉です。辞書には「自分の行動の責任は自分にあること」と「自己の過失についてのみ責任を負うこと」の2つの意味が載っています。

2004年の新語・流行語大賞の解説は、本来はリスクをとって行動した人が自ら「結果責任」をとることを言う、としたうえで、最近は責任を転嫁するときにしばしば使われている、と指摘しています。

広まった経緯

  1. 古くから

    「自分の行動の責任は自分にある」という意味で、投資などの場面で使われる。

  2. 2004年4月

    イラクで日本人3人が人質になる事件が起き、人質に「自己責任」という言葉が向けられる。

  3. 2004年

    新語・流行語大賞のトップテンに「自己責任」が選ばれる（受賞者は該当者なし）。

ズレのポイント

「助けなくてよい」という意味ではない

自己責任は、自分で選んだことの結果を自分で引き受けるという考え方です。困っている人を助けない理由として使うと、もとの意味から離れます。

本人が選べないことには使いにくい

病気や災害、生まれた家庭の事情など、本人が選んだとは言えないことまで「自己責任」と呼ぶと、言葉の前提が成り立たなくなります。

言う側の責任が見えなくなることがある

流行語大賞の解説が指摘したように、「自己責任」は責任を相手に押しつけるときにも使われます。誰が誰の責任を問うているのかを見ると、使い方のずれが分かります。

多様な観点

お金から

投資や金融商品の説明では、「損をしても自己責任」という意味で使われます。リスクの説明を受けたうえで自分で選んだ、という前提がある使い方です。

社会から

2004年の人質事件をきっかけに、個人の行動を社会が責める言葉として広まりました。貧困や失業の話でも「自己責任論」として議論になります。

自分の生き方から

「自己責任で好きなことをする」のように、人のせいにせず自分で決めたいという前向きな気持ちを表すこともあります。言う人が自分に向けるか、他人に向けるかで印象が変わります。

使用シーン

世代を問わず広く使われます。投資やスポーツ、旅行の注意書きのほか、ニュースのコメント欄やSNSで、事件や貧困の話題が出たときによく見かけます。

関連語

  • 炎上ネットで一斉に責められること。「自己責任」の声が集まって炎上することもある。
  • 他力本願他人の力に頼ることを指して使われがちな言葉。自己責任と反対の態度として持ち出される。
