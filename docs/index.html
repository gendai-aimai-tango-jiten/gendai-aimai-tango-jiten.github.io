メーターの見方

各項目を5段階で示しています。数値は調べた資料をもとにした編集部の目安です。

  • 曖昧度人によって指す範囲がどれだけばらつくか
  • 誤用度本来の意味や出典とずれた使われ方がどれだけ多いか
  • トゲ度人に向けて使ったときに攻撃的・失礼に響くおそれ
  • 定着度一部の界隈を越えて広く通じるか
