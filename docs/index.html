収録語

かえるかげんしょう蛙化現象もともとは「好かれたら冷める」話だった。曖昧度5恋愛心理学由来意味が変わった言葉どぱがきドパガキよく見かけるのに、口に出す人は少ない言葉。曖昧度4ネットスラング脳科学っぽい言葉SNS・動画めろいメロいとろける。でも、色気をどこまで含むかは人それぞれ。曖昧度3恋愛推し文化オノマトペ由来

この辞典の読み方

各ページでは、言葉の意味を「もともとの意味」「広がった使い方」「出典から離れた使い方」に分けて整理。正解を一つに決めるのではなくどこでズレが生まれたかを知ることができます。

この辞典について詳しく

  • 通用度他の世代や別の界隈にも通じるか
