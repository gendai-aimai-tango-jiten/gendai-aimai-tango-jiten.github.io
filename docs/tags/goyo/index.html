誤用されやすい言葉・意味を間違えやすい言葉の一覧

文化庁の「国語に関する世論調査」などで、本来とは違う意味で使う人が多いとされる言葉です。
31語を、内容が充実していて今よく使われている順に並べています。

につまる煮詰まる「行き詰まる」ではない。本来は「もうすぐ結論が出る」。曖昧度5誤用の定番意味が変わった言葉ビジネスやくぶそく役不足「私には役不足です」は、謙遜どころか自慢になる。曖昧度5誤用の定番意味が変わった言葉ながれにさおさす流れに棹さす逆らうのではない。本来は「流れに乗って勢いをつける」。曖昧度5誤用の定番意味が変わった言葉なさけはひとのためならず情けは人のためならず「甘やかすと本人のためにならない」ではない。本来は「巡り巡って自分のため」。曖昧度5誤用の定番意味が変わった言葉たざんのいし他山の石見習うお手本ではない。本来は「よその悪い例も役に立つ」。曖昧度4誤用の定番意味が変わった言葉なしくずしなし崩し「なかったことにする」ではない。本来は「少しずつ返す」。曖昧度4誤用の定番意味が変わった言葉きがおけない気が置けない「油断できない」ではない。本来は「遠慮がいらないほど親しい」。曖昧度5誤用の定番意味が変わった言葉しきいがたかい敷居が高い高級店に入りにくい、ではない。本来は「不義理をして行きにくい」。曖昧度4誤用の定番意味が変わった言葉おもむろにおもむろに「急に」ではない。本来は「ゆっくりと、落ち着いて」。曖昧度5誤用の定番意味が変わった言葉あめもよう雨模様降っているのか、降りそうなのか。人によって空が違う。曖昧度4誤用の定番意味が変わった言葉しっしょう失笑「あきれて笑うしかない」ではない。本来は「思わず吹き出す」。曖昧度4誤用の定番意味が変わった言葉せけんずれ世間ずれ「世間とずれている」ではない。本来は「世間にもまれてずる賢い」。曖昧度4誤用の定番意味が変わった言葉ぶぜん憮然「むっとしている」ではない。本来は「がっかりして、ぼうぜんとする」。曖昧度4誤用の定番意味が変わった言葉しおどき潮時「やめどき」ではない。本来は「ちょうどいいタイミング」。曖昧度4誤用の定番意味が変わった言葉かくしんはん確信犯本来は「悪いと分かっていて」ではなく「正しいと信じて」。曖昧度3誤用の定番意味が変わった言葉こはるびより小春日和春の言葉ではない。晩秋から初冬の、春のような暖かい日。曖昧度3誤用の定番とりはだがたつ鳥肌が立つ寒さや恐怖でぞっとするのが本来。いまは感動にも使う。曖昧度3意味が変わった言葉誤用の定番いちひめにたろう一姫二太郎「女の子1人、男の子2人」ではない。本来は生まれる順番の話。曖昧度4誤用の定番意味が変わった言葉てんちむよう天地無用「上下どちらでもいい」ではない。「上下を逆にするな」。曖昧度3誤用の定番おんのじ御の字「まあ合格点」ではない。本来は「大いにありがたい」。曖昧度3誤用の定番意味が変わった言葉げきをとばす檄を飛ばす「激励する」ではない。本来は「主張を広く知らせて同意を求める」。曖昧度3誤用の定番意味が変わった言葉たりきほんがん他力本願「人まかせ」ではない。本来の「他力」は、他人ではなく仏の力。曖昧度3誤用の定番意味が変わった言葉こそく姑息「卑怯」ではない。本来は「その場しのぎ」。曖昧度3誤用の定番意味が変わった言葉きんせんにふれる琴線に触れる「怒らせる」ではない。本来は「心の奥に響いて感動させる」。曖昧度3誤用の定番意味が変わった言葉はてんこう破天荒「豪快で型破り」ではない。本来は「誰もなし得なかったことをする」。曖昧度3誤用の定番意味が変わった言葉ごうきゅう号泣「涙が止まらない」ではない。本来は「大声を上げて泣く」。曖昧度3誤用の定番意味が変わった言葉ばくしょう爆笑「一人で大笑い」ではない。本来は「大勢がどっと笑う」。曖昧度3誤用の定番意味が変わった言葉かつあい割愛「いらないから省く」ではない。本来は「惜しいけれど手放す」。曖昧度3誤用の定番意味が変わった言葉ビジネスすべからく須らく「すべて」ではない。本来は「当然〜すべきだ」。曖昧度3誤用の定番意味が変わった言葉まとをいる的を射る「的を得る」は誤用か？ 辞書の判断が変わった言葉。曖昧度2誤用の定番意味が変わった言葉おめいへんじょう汚名返上「汚名挽回」は誤用か？ 取り戻したいのは汚名ではなく名誉。曖昧度2誤用の定番意味が変わった言葉
